## 三、轮次预算复盘:选项 B 的效果

试点(15 轮上限)6 题**无一**自然停;正式批把上限提到 18 轮并把 bulk 扫库 / 引文图前移到第 2-4 轮后:

- **62/70 题仍然打满 18 轮**,自然停(最后连续 ≥2 轮零新增)的只有 **7 题**;
- 但**模态前移确实生效**:bulk + 引文图合计 944 次,占总检索 25%(试点仅 44 次、占 8%),多题的最大单轮收获来自这两类(如 Q053 第 2、4 轮 venue 扫库合计 90 条);
- 结论:该题域的文献空间在 18 轮内**仍未穷尽**,继续加轮数的边际收益是外围文献。**GT 的完备性上限不在轮数,而在检索模态的编排**——这条对后续 benchmark 打分设计比"技能跑几轮"更有价值。

## 四、引用核验(2774 条)

判定基于:S2 batch 官方标题比对 → arXiv API → doi.org 解析 → 落地页标题(含 GBK 解码、双语标题包含规则、重定向/人机校验页过滤)→ PDF HEAD → S2 题名匹配。

| 判定 | 条数 | 含义 |
|---|---|---|
| OK | 2748 (99.06%) | 链接指向的论文与表内标题一致 |
| DOI_RESOLVES | 19 (0.68%) | DOI 解析正常但出版方拒绝脚本读标题(Elsevier / INFORMS / AEA / 牛津 / MDPI / NIST / 中文刊),链接可用 |
| NEAR | 3 (0.11%) | 同一论文的标题变体,**已逐条人工确认**(见下) |
| MISMATCH | 2 (0.07%) | 中英双语标题,**已逐条人工确认为同一篇** |
| PDF_OK | 1 (0.04%) | Grieves 2014 数字孪生白皮书 PDF,HTTP 200 可下载(PDF 无 <title> 可比) |
| EXISTS_ONLY | 1 (0.04%) | OpenReview 人机校验页拦截脚本;论文经 S2 题名匹配确认存在(相似度 1.0) |

**本轮修掉的 3 处**:

1. `Q022[35]` 工程科学学报论文原链接(cje.ustb.edu.cn)整站 502 不可达 → 换成可解析的 DOI 链接;
2. `Q021[32]` 表内标题是 agent 的转述 → 订正为出版方官方标题;
3. (试点阶段)`Q006[9]` 自动化学报 2014 综述的印刷 DOI 从未注册 → 换刊物官网文章页。

**人工确认过的 5 条**(不必再看):Q033[34]、Q044[41] 为中英双语标题同篇;Q021[32][33]、Q048[42] 为标题变体同篇(Q048 是 arXiv 改题:CheXagent → 期刊版标题)。

**核验器本身也修了 4 类误判**(已入库,后续批次可复用):重定向/人机校验页当成标题、中文刊 GBK 页解码乱码、中文标题因长度阈值不触发包含规则、PDF 链接无标题被判死链。

## 五、给人工复核的重点

1. **19 条 DOI_RESOLVES**:链接本身没问题(DOI 解析通),只是脚本读不到标题。若你要抽查,优先看 `Q041`(平台算法定价治理,占 6 条)与 `Q036`(中文刊 2 条)。
2. **题内一致性**:CSV 只含标题与链接;论述与引用的对应关系在 `answer.md` 里,复核某题结论时对照该文件更快。
3. **agent 自报的存疑项**(散落在各题 notes / answer.md,已在正文标注):Q006[25] 出处存疑;Q012[21]、Q031[24][40] 为付费墙论文,数值取自摘要;Q021 两篇 1990-2000 年代会议摘要特征表不可公开获取。
4. **中文文献是系统性弱项**:S2 对中文期刊索引极差,各题的中文文献靠网页检索 + 出版方页面救回;多题 notes 明确写了"中文检索只找到博客/政策文件,未达引用门槛"。若你认为某些题必须有中文文献支撑,这些题需要单独补采。
5. **跨题重复**:153 条文献被多题引用(如经典综述),属正常。

## 六、GT 里的"负结论"(benchmark 打分的高价值锚点)

多题给出了"该对比/该研究不存在"的判断,技能若在这些点上编造文献,可直接判错:

- `Q012`:没有任何论文在同一真实数据集、同一协议下正面对比 GNN 与序列 Transformer;规则引擎几乎从不作为调优基线出现。
- `Q018`:没有公开研究对比同一批模型的榜单排名与实路闭环排名。
- `Q031`:没有通用地理基础模型 benchmark 把"季节"作为一等评测轴。
- `Q036`:没有论文把 Assmann 文化记忆理论形式化为知识图谱本体。
