# 非遗数字化传播中的多模态检索、知识图谱与文化记忆理论：跨学科论文链条、概念映射与研究空白

## 0. 直接结论（先给判断）

**三者已经"两两结合"，但还没有"三者贯通"。**

- 知识图谱 × 多模态检索：结合最成熟，已经形成完整技术链条（实体抽取 → 多模态图谱 → 图谱增强检索/问答），2022—2026 年有连续可追的代表作 [6][7][17][16][18]。
- 文化记忆理论 × 数字传播：结合最成熟的人文侧，记忆研究已完成"数字转向"并发展出平台记忆、连接性记忆等概念工具 [19][20][21][22]，非遗短视频研究也普遍以文化记忆为解释框架 [32][31]。
- 文化记忆理论 × 知识图谱：**这是最薄弱的一环**。我在本次检索中没有找到任何把阿斯曼（Jan Assmann）的"交往记忆／文化记忆"框架形式化为图谱本体、并给出可验证建模方案的研究。最接近的只有把"社会文化记忆"作为动机而非建模对象的少数论文 [9][10][30]，以及把记忆／身份实践建模为本体的社交平台研究（非遗领域外）。
- 因此，问"有没有跨学科论文梳理"的答案是：**有综述，但都是两两式的**——技术侧有知识图谱驱动非遗保护的中西范式比较 [1] 与中文文献计量梳理 [2][3]，传播侧有非遗数字传播策略的系统综述 [5]，数字人文侧有非遗文献与档案化的方法梳理 [4]，记忆研究侧有数字记忆研究的理论盘点 [20][22] 与遗产×社交平台的整合性综述 [23]。**没有一篇同时覆盖"多模态检索 + 知识图谱 + 文化记忆理论"三者的综述。**这本身就是最大的空白。

## 1. 三条学科主线的论文链条（按时间）

### 1.1 主线 A：知识图谱线（信息科学 / 语义网 / 数字人文）

这条线的问题意识是：非遗数据"有量无序"，需要把散落的文本、图像、传承人、技艺流程连成可推理的语义网络。

| 节点 | 论文 | 关键推进 |
|---|---|---|
| 前置 | Linked Open Data / CIDOC-CRM 本体族综述 [11] | 给出遗产领域语义建模的既有标准盘点，是非遗本体的"上游工具箱" |
| 2022 | ICH 知识图谱构建与属性值抽取（图注意力网络）[6] | 第一批把 NER + 关系抽取 + GAT 系统用到中文非遗语料上的高影响力工作，确立"抽取—构图—服务"范式 |
| 2023 | CICHMKG：大规模中文非遗多模态知识图谱 [7] | 把图像正式纳入非遗图谱，成为"多模态知识图谱"进入非遗领域的标志性数据资源 |
| 2024 | 传统武术本体化知识表示 [9] | 少数明确以"社会文化记忆载体"为出发点的本体研究，试图表示身体化、过程性知识 |
| 2025 | 刺绣非遗本体（庆阳香包）[8] | 针对多模态非遗资源的细粒度语义关联挖掘，把纹样—工艺—象征义连成链 |
| 2026 | 东巴象形文字"仪式感知—认知自适应"知识图谱 [10] | 以"仪式事件"为组织单位的神经符号四层框架，正面处理专家—新手认知落差 |
| 2026 | 藏羌彝非遗舞蹈多模态知识图谱建模与质性评价路径 [30] | 明确以短视频传播导致的"去语境化、碎片化"为问题起点，是三线交汇处最近的一次尝试 |

方法上游：多模态知识图谱的构建—补全—应用综述 [12] 是这条线的通用方法学参照，非遗侧的图谱基本是它的领域化实例。

### 1.2 主线 B：多模态检索线（计算机视觉 / 自然语言处理 / 信息检索）

这条线的问题意识是：文化对象的检索不能只靠关键词，要在图像—文本—视频之间建立语义可对齐的共享空间。

| 节点 | 论文 | 关键推进 |
|---|---|---|
| 2021 | 文化物件细粒度跨模态检索（焦点注意力 + 层级编码）[13] | 较早把图文对齐任务专门定义在文化遗产域，处理"艺术品局部片段 ↔ 描述短语"的细粒度匹配 |
| 2024 | 文化常识型多语视觉问答基准 CVQA [35] | 提供了"文化多样性"作为多模态评测维度的公共基准，非西方文化图像开始被系统性评估 |
| 2025 | 中文文化遗产文献跨模态检索：数据集与方法 [14] | 首个面向丝绸纹样、敦煌壁画及其历史叙述的中文遗产跨模态检索数据集与基线，补上了"没有中文遗产检索基准"的缺口 |
| 2025 | 跨模态检索中的视角偏差评测 [36] | 证明跨模态检索结果会系统性偏向特定语言/文化视角，把"文化偏见"从生成模型推进到检索环节 |
| 2025 | 面向遗产跨模态检索的数据增强完整性与一致性 LLM 评测 [15] | 直面遗产文本"残缺、不一致"这一领域特有病灶，用 LLM 做增强并给出质量评估 |
| 2026 | MLLM + 视觉 RAG 用于非遗图像识别（皮影戏）[16] | 把"多模态大模型 + 检索增强"落到具体非遗门类，是检索线与图谱线正式合流的代表作 |

### 1.3 主线 C：文化记忆理论线（记忆研究 / 传播学 / 档案学）

这条线的问题意识是：数字化不只是保存，而是改变了"什么被记住、由谁记住、以什么形态记住"。

| 节点 | 论文 | 关键推进 |
|---|---|---|
| 理论基座 | 阿斯曼《交往记忆与文化记忆》[19] | 区分"交往记忆"（三代人以内、日常互动）与"文化记忆"（制度化、仪式化、有固定载体），并提出"凝聚性结构"。这是几乎所有中文非遗记忆研究引用的原点 |
| 2022 | 车陂龙舟：短视频中的文化记忆叙事 [32] | 较早把"非遗 + 短视频 + 文化记忆"三要素放在同一个案例里，属于本题最早的可追溯交叉节点之一 |
| 2022 | 社交平台上的"困难遗产"整合性综述 [23] | 记忆研究与遗产研究在社交平台上的正式合流，梳理了争议性遗产、边缘群体遗产的平台化再现 |
| 2023 | 记忆研究的数字转向 [20] | 系统论证数字记忆不是"新种类的记忆"，而是既有集体记忆概念在新媒介条件下的延展，为跨学科对话划定了理论边界 |
| 2024 | 平台化记忆的多重性 [21] | 提出平台不是中立容器，其可供性与排序机制本身参与记忆的生产 |
| 2024 | 人工智能是集体记忆的未来吗？[24] | 记忆研究领域正式把生成式 AI 当作"记忆行动者"来讨论 |
| 2025 | 集体记忆与社交媒体（数字记忆研究综述）[22] | 把连接性记忆、记忆生态、平台化记忆等概念谱系整理成一条清晰的理论链 |
| 2025 | 为记忆研究祛魅人工智能 [25] | 方法论层面告诉人文学者如何有节制地使用 AI，避免"技术炒作驱动的记忆研究" |

## 2. 三线到底是怎么"结合"的：四种真实存在的耦合方式

现有文献里，三者的结合不是一种，而是**四种性质完全不同的耦合**。分清这四种，是读这块文献不迷路的关键。

### 耦合 A：知识图谱作为检索的语义骨架（技术侧，最成熟）

路径：图谱补上向量检索缺失的显式关系与可解释性。
- 云锦知识图谱 + 检索增强生成问答系统 [17]：非遗领域第一批 KG-RAG 系统，用图谱抑制大模型幻觉。
- mKG-RAG [18]：把多模态知识图谱正式引入 RAG 管线，解决知识密集型视觉问答。
- 皮影戏视觉 RAG [16]：检索到的不是文本片段，而是带文化标签的视觉证据。

**这条耦合里文化记忆理论是缺席的**——评价指标全是准确率／召回率，没有任何"记忆效度"维度。

### 耦合 B：多模态检索作为知识图谱构建的输入（技术侧，双向）

路径：跨模态对齐 → 图像实体链接 → 图谱补全。CICHMKG [7] 与刺绣本体 [8] 都依赖图文对齐把纹样图像挂到语义节点上；遗产跨模态检索数据集 [14] 与数据增强评测 [15] 则反过来为这类对齐提供训练与评测资源。

### 耦合 C：文化记忆理论作为知识图谱本体的概念来源（最薄弱，也最有机会）

现状是**"引用了但没建模"**：多数非遗图谱在引言里写"非遗是文化记忆的载体"，随后建的却是"项目—传承人—技艺—区域"的资源型本体，记忆理论没有进入本体的类与关系设计。真正往前走了半步的只有三类：
- 以"文化记忆载体"为出发点的武术本体 [9]；
- 以"仪式事件"而非"物件"为组织单位的东巴图谱 [10]——这最接近阿斯曼所说的"仪式性凝聚"；
- 明确把短视频造成的去语境化作为建模动因、并提出质性评价路径的藏羌彝舞蹈图谱 [30]。

数字人文侧的非遗档案化方法梳理 [4] 提示了这条路的另一半：文献与档案学的著录传统本来就与"记忆机构"概念同源，但它与语义建模的接口尚未打通。

### 耦合 D：文化记忆理论作为传播效果的解释框架（人文侧，最成熟）

抖音／TikTok 上的非遗传播研究几乎清一色采用阿斯曼式框架 [31][32]，讨论重复展演如何形成"凝聚性结构"、如何把日常技艺转译成符号系统；平台化记忆理论 [21] 与数字记忆综述 [22] 则提供了更锋利的批判工具：**算法可见性分配本身就是一种记忆筛选**。传播效果的量化尝试见非遗传统技艺数字传播效果评价指标体系 [33]，制度与话语权层面见基于沉浸式原型的政策—设计分析 [34]。

## 3. 概念映射：跨学科读这块文献必须先拆的同名异义

这是本题最容易踩坑的地方。同一个词在不同学科里指的是完全不同的东西。

| 词 | 计算机 / 信息科学的意思 | 人文 / 传播学的意思 | 后果 |
|---|---|---|---|
| **多模态** | 跨模态表征对齐，图文共享嵌入空间、对比学习（CLIP 式）[13][14] | 视觉语法框架下的多模态话语分析，图像—文字—声音的意义协同 | 两边论文都自称"多模态非遗研究"，但技术侧做检索、人文侧做符号分析，几乎不互引 |
| **知识图谱** | 语义知识图谱（实体—关系—属性，可推理）[6][7] | 中文文献里常指 CiteSpace 科学计量可视化图谱 [2][3] | **中文检索这个题目时最大的噪声源**：搜"非遗 知识图谱"返回的大量结果其实是文献计量综述，不是语义图谱 |
| **记忆** | 存储、索引、上下文窗口 | 交往记忆／文化记忆／集体记忆 [19]，社会性、选择性、建构性 | 技术论文写"记忆载体"时通常只是修辞，不构成建模承诺 |
| **传承 / inheritance** | 数据继承、类继承 | 活态传承，强调传承人的身体实践与社群语境 | 技术方案容易把"传承"简化为"存下来 + 检索得到" |
| **文化空间** | 地理坐标 / GIS 图层 | 联合国教科文组织语境下的"文化空间"，是仪式与社群共在的场所 | 空间化图谱容易把仪式性场所降维成经纬度 |

**方法迁移的方向也值得单独看清：**

- CV/IR → 遗产：对比学习与细粒度对齐迁到纹样—文本检索 [13][14]。
- NLP/KG → 遗产：NER + 关系抽取 + 图注意力迁到非遗语料 [6]；LLM + RAG 迁到遗产问答 [17][16][18]。
- 语义网/数字人文 → 遗产：CIDOC-CRM 与关联开放数据传统迁到非遗本体 [11][9]。
- **计算社会科学 → 记忆研究（反向迁移，常被忽略）**：共现网络被用来识别"记忆共同体" [27]，"可伸缩阅读"被写成记忆研究者的数字方法入门 [26]。这是人文侧主动吸收计算方法的证据。
- **人文方法 → 计算流程（最新、最少）**：把细读嵌入 RAG 全流程的"人文在环" [29]，把数字叙事嵌入数字人文项目的上海记忆项目 [28]。这两篇是目前把人文方法真正写进技术管线的少数样本。

## 4. 研究空白（按可操作性排序）

1. **文化记忆理论没有被本体化。** 缺少把"交往记忆／文化记忆""凝聚性结构""回忆形象""仪式重复"翻译成类与关系的本体工程工作。现有非遗本体是资源本体而非记忆本体 [7][8]；[9][10][30] 只是零星尝试，彼此不引用，也没有共享词表。

2. **检索评测缺文化语义指标。** Recall@K 无法回答"检索结果是否保留了文化语境"。跨模态检索的视角偏差已被证实存在 [36]，遗产数据的完整性与一致性刚开始被系统评测 [15]，但还没有"文化语境保真度"这类指标。

3. **三线从未在同一个系统里被共同评价。** KG + 检索的系统 [17][18][16] 只报技术指标；传播效果研究 [33][31] 从不接触图谱；两类研究互不引用。一个显而易见的空位是：以文化记忆理论推导评价维度，去评一套 KG-RAG 非遗系统。

4. **数据与基准的结构性偏斜。** 现有资源集中在汉族、器物类、头部名录项目；表演类（动作、声音、时序）与少数民族非遗几乎没有公开的多模态检索基准。更根本的是，联合国教科文组织非遗名录元数据本身就带语义偏差 [37]——分类基础设施决定了什么"可被检索"。

5. **中西方形成了两套平行的实施范式。** [1] 用文献计量与 CiteSpace 分析直接比较了中西方在知识图谱驱动非遗保护上的实施路径差异；中文侧的梳理 [2][3] 与英文侧的综述 [5] 关注重心也明显不同。[2] 更直接指出中文研究"缺研究框架、技术边界不清、重技术描述轻体系建构"，并把"加强跨学科合作"列为首要建议。

6. **大模型作为"文化档案"的记忆权力尚未与遗产治理对接。** LLM 正被用来抽取文化常识知识图谱 [39]，记忆研究已在讨论 AI 作为记忆行动者 [24][25]，但"谁的非遗知识进入模型、谁被抹除"这一问题在非遗数字化文献里几乎空白。非遗领域大模型的能力评测已有起步 [38]，但它与记忆研究关于"AI 作为记忆行动者"的讨论 [24] 之间没有引用往来。

7. **算法可见性对"凝聚性结构"的影响缺因果证据。** 平台化记忆理论提供了机制假设 [21][22]，非遗短视频研究提供了描述 [31][32]，但没有把推荐算法暴露量作为自变量、把记忆固化作为因变量的实证设计。

8. **传承人与社群在系统中的主体位置缺失。** 图谱把传承人建模成实体，检索把他们建模成结果，但谁来定义本体、谁来审核检索排序，几乎无人讨论；[34] 从政策—设计角度提出了"再现、受众、权威"三重问题，是这一空白目前最明确的问题化表述。

## 5. 建议的阅读路线

- **想快速建立全局图景（3 篇）**：知识图谱驱动非遗保护的中西范式比较 [1] → 记忆研究的数字转向 [20] → CICHMKG [7]。
- **想做系统（技术路径）**：[6] → [7] → [17] → [16] → [18]，再用 [15][36] 补评测意识。
- **想做理论（人文路径）**：[19] → [20] → [21] → [22] → [23]，再用 [24][25] 接住 AI 议题。
- **想做真正的交叉研究**：先读 [30]（离三线交汇最近）与 [29]（人文方法进技术管线），再读 [37]（分类基础设施的偏差）——这三篇合起来基本勾勒出了尚未有人填的那块空地。
