# 作物病虫害识别：CNN、ViT 与多模态模型在真实田间环境下谁更靠谱

## 一、直接结论（先看这段）

**有对比论文，而且是近两年才开始出现方法学上站得住的头对头比较。综合现有证据，答案不是"某一族全面胜出"，而是三条相当稳固的判断：**

1. **在真实田间条件下，"换架构"带来的收益远小于"换数据/换评测协议"带来的落差。** 一项覆盖苹果、马铃薯、番茄 14 种病害的评测显示：同一批模型从实验室条件（98.22%）到混合条件（91.76%）再到田间条件（71.55%）逐级下滑，而 DenseNet / ResNet / MobileNetV3 / EfficientNet / VGG 这些不同架构、不同参数量之间的差异极小（田间条件下全部落在 68.56%–73.81% 区间）[2]。也就是说，田间掉点主要由域偏移和数据代表性决定，不是由 CNN 还是 ViT 决定。

2. **纯 CNN 与纯 ViT 各有明确的失效模式，田间落地目前最稳的是 CNN–Transformer 混合（以及新出现的 Mamba/状态空间混合）。** 在统一可复现协议下同时比较 CNN、ViT 与 MambaVision 的研究给出了机理性结论：CNN 在以局部病斑纹理为主的病害上有竞争力，但对需要全局空间解释的症状稳健性不足；ViT 受益于全局依赖建模，却在小样本条件下明显不稳定；混合型 MambaVision 数据效率与稳健性最好，在仅用 1% 训练样本的极端稀缺下仍保持约 60–80% 准确率，且精度—算力权衡优于前两者 [1]。混合架构在自建田间数据上的直接对照也支持这一点：ConvTransNet-S 在 10,441 张复杂田间图像上达到 88.53%，比 EfficientNetV2 高 14.22 个百分点、比 ViT 高 2.75 个百分点、比 Swin Transformer 高 0.34 个百分点 [3]。

3. **"多模态"必须拆成两类来回答，结论完全相反。**
   - **多模态大模型 / 视觉语言模型（VLM、MLLM）零样本目前不靠谱**，还替代不了有监督模型：在 27 个农业图像分类数据集、162 类、24.8 万张图上，零样本 VLM 全面低于有监督基线 YOLO11，最好的 VLM 多选题设置下平均约 62%，开放式提问常低于 25% [15]。
   - **多传感器 / 图像＋非图像信息的多模态融合则是当前田间最可靠的增益来源**：把"作物种类"这种非图像上下文元数据在嵌入层与图像特征拼接，10 万余张手机真实田间图像上的平衡准确率从 0.93 提升到 0.98，消除了 71% 的误分类 [4]；高光谱相对 RGB 在番茄真菌病早期检测上把感染后第 1 天的准确率从 65% 提到 86%、第 11 天从 87% 提到 98% [23]。

## 三、分方法族的关键实证证据

### 3.1 CNN：田间证据最扎实，也是目前的"默认基线"

- **真实手机图像大规模验证**：Picón 等在 10 万余张手机田间实拍图像（小麦、大麦、玉米、水稻、油菜，17 种病害，病程阶段近似均匀分布）上比较作物专用模型与统一多作物模型，BAC 分别为 0.92 与 0.93；再把作物这一非图像上下文元数据在嵌入向量层拼接后，BAC 提升到 0.98 [4]。这既是 CNN 田间可用性的最早大规模证据，也是"图像＋元数据多模态"优于纯图像的最干净证据。
- **跨农场外部验证**：一项针对害虫识别的研究用 27 个农场、334K 图像（黄瓜、番茄、草莓、茄子的叶正面/叶背面/果实/花，20 种害虫）系统回答了三个方法学问题，最重要的一条是**测试集不能包含训练图像所在农场的图像**；其两阶段 ROI 检测＋CNN 框架在完全未见农场的 12,223 个实例（21 类）上取得 91.0% 平均准确率、88.5% macro F1，单图 476 ms [5]。这是本领域少见的、评测协议本身就经得起推敲的工作。
- **CNN 在多光谱分割上仍占优**：UAV 多光谱水稻白叶枯严重度分割的统一流程对比中，U-Net++ 搭 EfficientNet-B3 取得最高 mIoU 97.62%，SegFormer 精度更低而推理速度相当；作者明确建议田间业务化监测优先使用轻量 CNN 主干，植被指数（NDVI/NDRE）带来小而稳定的提升 [6]。
- **CNN 也可能直接赢过 ViT**：在孟加拉 Dhan-Shomadhan 水稻叶病数据上同时比较多个 CNN、ViT 与传统 SVM，ResNet50 表现最好 [7]。

### 3.2 ViT：跨域泛化理论优势成立，但田间头对头结论并不一致

- ViT 与 CNN 的结合是本领域被引最多的方向之一 [8]；纯 ViT 的头对头结果则高度依赖数据集：自建巴基斯坦小麦病害数据上 ViT-B32 达 99.2%，高于 VGG-19 的 98.4% [9]；但换到水稻数据上 CNN 反超 [7]。
- **面向"in the wild"的改造是有效的**：ViT 主干＋Mixture of Experts＋熵/正交正则，相对纯 ViT 提升 20%，PlantVillage→PlantDoc 跨域达到 68%，超过 InceptionV3、EfficientNet 等基线 [10]。这说明 ViT 的田间优势需要额外机制（专家路由、正则化）才能兑现，而不是开箱即得。
- **实时检测环节 ViT 并不占优**：16 个植物物种、5,611 张田间图像上比较 YOLOv8/v9/v10 与 RT-DETR，整体表现接近；YOLOv9e 召回 72.36%、mAP50 79.86%、mAP50-95 47.00%，RT-DETR-l 精确率最高 82.44%，而最小的 YOLO 推理约 7 ms 最快 [11]。（该研究对象是杂草而非病虫害，属于同一采集条件下的邻近证据。）
- **通用视觉领域的重要警示**：ViT"比 CNN 更稳健"的说法在控制训练配方后会显著缩水 [12]，而在同样的训练配方下 CNN 甚至可以比 Transformer 更稳健 [13]。农业论文里大量"ViT 更强"的结论没有对齐训练配方、增广与预训练权重，需要打折看待。

### 3.3 混合架构与新范式：目前田间综合表现最好的一档

- **ConvTransNet-S**（局部感知单元＋轻量多头自注意力＋倒残差前馈网络）在 PlantVillage 上 98.85%，在自建 10,441 张田间复杂场景数据上 88.53%，相对 EfficientNetV2 / ViT / Swin 分别高出 14.22 / 2.75 / 0.34 个百分点，同时只有 25.14M 参数、3.762 GFLOPs、7.56 ms 推理 [3]。这是少数把"田间精度＋算力预算"一起报出来的对照。
- **范式级评测**给出了三族的分工与边界，并把混合状态空间模型（MambaVision）列为数据稀缺场景的最优解 [1]；ViT 与 Vision Mamba 在作物管理中的走向也已有专门综述 [14]，CNN→ViT→CNN-Transformer 混合的演进脉络及小样本、复杂背景干扰、轻量化三大挑战见 [33]。

### 3.4 多模态之一：视觉语言 / 多模态大模型

- **最直接的对照**：在 AgML 的 27 个农业图像分类数据集（162 类、24.8 万图，涵盖植物病害、虫害与损伤、作物与杂草物种识别）上系统评测开源与闭源 VLM，结论是零样本 VLM 全面低于有监督专用基线 YOLO11；多选提示下最佳 VLM 平均约 62%，开放式提问原始准确率常低于 25%；引入 LLM 语义判分后开放式从约 21% 升到约 30%，并且**改变了模型排名**——说明评测方法本身会左右结论；开源模型中 Qwen-VL-72B 最好，受限提示下接近闭源但仍有差距 [15]。
- **专家标注基准同样指向差距**：AgroBench 由农艺专家标注，覆盖 203 个作物类别与 682 个病害类别，评测显示 VLM 在细粒度识别上仍有明显提升空间，杂草识别中多数开源 VLM 接近随机 [16]。AgMMU 从 116,231 条真实种植者与美国农业部推广专家的对话中蒸馏出 746 道多选题与 746 道开放题，12 个主流 VLM 在细粒度感知与事实落地上差距明显，开源大幅落后闭源，用配套的 AgBase 语料微调后开放题最多提升 11.6% [17]。
- **少样本上下文学习能大幅改善**：AgEval 在 12 项植物胁迫表型任务上显示，最佳模型 8-shot 后 F1 从 46.24% 升到 73.37%，但类间波动很大（变异系数 26.02%–58.03%），同类示例选择平均带来 15.38% 的 F1 提升 [18]。
- **微调后可以追平专用 CNN**：在 PlantVillage 上把 GPT-4o 与 ResNet-50 放在同一实验中比较，跨三种分辨率、两种作物，微调后的 GPT-4o 在苹果叶最高 98.12%，略高于 ResNet-50 的 96.88%，训练损失接近零、泛化更好；但零样本表现显著偏低，跨分辨率与跨作物迁移仍有明显限制 [19]。**注意这仍是实验室数据集上的结论，不能直接外推到田间。**
- **多模态的独有能力在于"开放词表"与"可解释交互"**，而不是刷准确率：PDC-VLD 用图文对实现番茄叶病开放词表检测，无需人工标注即可识别新病害类别，mAPnovel50 61.2%、mAPnovel75 56.4%、mAPbase50 87.7%、mAPall50 81.0% [21]；CDDM 提供 13.7 万张作物病害图像与 100 万问答对及 LoRA 微调策略，支撑"识别＋管理建议"一体化 [20]。CLIP 类零样本模型能直接用自然语言描述分类，在域偏移下相对 CNN 展现出更好的适应性与可解释性，同一研究中 CNN 稳健性有限、ViT 靠全局上下文更好、CLIP 提供了另一条实用的域适应路径 [22]。

### 3.5 多模态之二：多传感器与异构数据融合（这一支才是田间可靠性的真实增量）

- **高光谱 vs RGB 的直接对照**：番茄四种真菌病（灰霉、尖孢镰刀菌、链格孢两种）在接种后第 1–11 天用 RGB 与高光谱（400–950 nm）同步成像并训练随机森林，RGB 从第 1 天 65% 升到第 11 天 87%，高光谱从第 1 天 86% 升到第 11 天 98%，灰霉最早在第 3 天即可与健康株区分 [23]。早期/隐症阶段的差距最大，正是田间预警最需要的窗口。
- **多光谱下的架构比较**：自采六个 50 mm 滤光片（可见光＋近红外）数据上比较 CNN 与 ViT，ViT-B16 在所有滤光片上准确率、精确率、召回率、F1 均最高（平均 83.3% / 90.1% / 90.75% / 89.5%），同时强调数据平衡性对波段与模型选型的决定作用 [24]。注意这里绝对精度只有八十几，与 PlantVillage 上的九十九形成鲜明对比。
- **图像＋环境数据**：小麦叶片图像与温度、湿度等传感器数据融合，达到 96.5% 准确率、94.8% 精确率、97.2% 召回、95.9% F1、MCC 0.91 [25]。
- **图像＋文本语义**：PlantIF 针对"纯图像方法在含噪声、有干扰的复杂田间环境中性能下滑"的问题，用图学习做图文语义交互融合 [26]。
- **系统综述层面的共识**：遵循 PRISMA 2020 的系统综述指出，作物病虫害检测正从单传感器监测转向智能感知与多模态融合，并把轻量 CNN、具备长程依赖建模能力的 ViT、以及高效计算的状态空间模型 Mamba 一并纳入架构演进主线，同时讨论空谱联合学习、异构数据融合与 VLM 对鲁棒性和可解释性的贡献 [27]。

## 四、田间落差有多大、来自哪里（回答"靠不靠谱"的根本）

1. **实验室数据集本身有捷径可走**：只用 PlantVillage 图像背景中的 8 个像素训练一个模型，就能在留出测试集上达到 49.0% 准确率，而随机猜测只有 2.6% [28]。这意味着大量"99% 准确率"包含了对背景伪相关的利用。
2. **大量文献结果被系统性高估**：对番茄病虫害检测的专门综述发现，真正使用真实农田数据（如 PlantDoc）的研究很少，而海量基于实验室条件下 PlantVillage 的研究结果过于乐观——统一背景使检测与分类变得容易，指标虚高，但模型在农业实践中用处不大 [29]。
3. **数据集本身在"迎合"深度学习方法**：现有植物病害数据集远离真实场景，需要一套分类法与面向挑战的构建方向来纠正 [34]；FieldPlant 因此直接从种植园采集 5,170 张图像并逐叶由植病专家标注，同时指出 PlantVillage 训练的模型在复杂背景、多叶片的田间图像上准确率很低，而 PlantDoc 混入了实验室图像且标注过程缺少植病专家参与 [30]。
4. **落差的量级有了明确数字**：实验室 >95% 的模型在真实农业条件下掉超过 30 个百分点；DDAN-RGAL 通过域不变特征解耦、跨域原型学习与现实落差感知元分类，把实验室 98.7% / 田间 94.8% 的组合做出来，将现实落差从 27.9 个百分点压缩到 3.9 个百分点（七倍以上改善），期望校准误差 0.042，GPU 推理 21.6 ms、树莓派 4 上 285 ms，仅用 10% 训练数据仍有 85.3% [31]。
5. **无监督域适应的真实天花板**：跨域方法 MSUN 在 PlantDoc 上 56.06%、Plant-Pathology 72.31%、玉米叶病 96.78%、番茄叶病 50.58% [32]。同一方法在不同目标域上从 50% 到 97% 的巨大跨度，说明"田间是否靠谱"高度依赖具体作物与病害，不能一概而论。

## 五、选型建议（按场景）

| 场景 | 推荐 | 理由与依据 |
|---|---|---|
| 手机端/边缘端实时田间诊断，标注有限 | **CNN–Transformer 轻量混合**（次选轻量 CNN） | 田间 88.53% 且 7.56 ms / 25M 参数 [3]；数据稀缺下混合状态空间模型退化最慢 [1]；纯 CNN 部署最成熟 [5] |
| UAV 多光谱/遥感尺度的病害制图 | **轻量 CNN 分割主干＋植被指数** | U-Net++/EfficientNet-B3 mIoU 97.62% 优于 SegFormer，且推理速度相当 [6] |
| 症状前期 / 隐症早期预警 | **高光谱或多光谱多模态融合** | 感染第 1 天高光谱 86% vs RGB 65% [23]；多光谱下 ViT-B16 表现最好 [24] |
| 病害种类持续新增、无法逐类标注 | **视觉语言模型（开放词表检测 / CLIP 零样本）** | 无需人工标注即可识别新类，mAPnovel50 61.2% [21]；CLIP 零样本作为域适应策略 [22] |
| 需要"识别＋防治建议＋可解释交互" | **多模态大模型（须领域微调）** | 微调后可追平专用 CNN [19]；CDDM/AgBase 提供领域语料 [20][17] |
| 直接拿通用 VLM 零样本替代已有有监督系统 | **不推荐** | 全面低于 YOLO11；最佳 VLM 多选约 62%、开放式 <25% [15]；专家标注基准上细粒度识别仍有明显差距 [16] |
| 已有 CNN 系统想提升田间可靠性 | **优先补数据与上下文元数据，而不是换架构** | 架构间田间差异仅 68.56%–73.81% [2]；加入作物元数据 BAC 0.93→0.98、消除 71% 误分类 [4] |

## 六、证据强度总结与阅读这类论文的注意事项

**证据强度分级：**

- **强（可作为决策依据）**：CNN 在真实田间的可用性与其量级 [4][5][2]；实验室—田间落差的存在与大小 [2][31][29][28]；零样本 VLM 尚不能替代有监督模型 [15][16][17]。
- **中（方向可信、数值待复现）**：混合架构在田间优于纯 CNN / 纯 ViT [3][1]；ViT 在数据充足时跨域更好 [10][22]；多传感器融合的早期检测增益 [23][24][25]。
- **弱（单点结果，勿外推）**：单一自建数据集上的 ViT vs CNN 胜负 [9][7]；微调 MLLM 略胜 CNN 的结论（仅在 PlantVillage、两种作物上验证）[19]。

**读这批文献时必须警惕的五个陷阱：**

1. **数据集陷阱**：在 PlantVillage 上得到的任何架构排名都不可信，背景伪相关足以支撑 49% 的准确率 [28]；真正的田间比较应使用 PlantDoc、FieldPlant、Tomato-Village 一类实拍数据或自采数据 [30][29]。
2. **划分陷阱**：测试集若包含训练农场/地块的图像，指标会被系统性高估；应按农场、季节或地块划分 [5]。
3. **训练配方混淆**：ViT 的"稳健性优势"在对齐增广、预训练与训练轮次后会大幅缩水 [12]，同配方下 CNN 甚至更稳健 [13]；农业论文极少报告这些控制变量。
4. **评测方式左右结论**：VLM 的开放式与多选式提示、是否使用 LLM 语义判分，会同时改变绝对数值和模型排名 [15]。
5. **"多模态"一词歧义**：图文大模型与多光谱/环境数据融合是两件事，结论方向相反，引用时必须区分 [15] 与 [23][4]。

**尚未被回答的问题：** 目前几乎没有在同一批田间数据、同一训练预算下同时比较 CNN、ViT、混合模型与（微调后）多模态大模型的公开研究；也缺少跨季节、跨产区的多点外部验证。范式级评测 [1] 与 AgML 大规模 VLM 评测 [15] 分别覆盖了"视觉架构"和"VLM vs 有监督"两半，把两者拼在同一田间数据上的工作仍是空白。
