# 深度学习地震相识别与断层解释的跨盆地泛化：公开数据集、实验证据与证据等级

## 一、结论速览

**能不能跨盆地泛化？——目前的公开证据支持一个有条件的"部分能"，而不是"能"。**

1. **同工区内插（train/test 取自同一三维数据体）表现很好，但这不是泛化。** 学界主流评测（F3、Parihaka 等公开数据集）绝大多数是"同数据体切分"，天然高估了迁移能力 [1][9][32]。
2. **换工区、换盆地时性能普遍显著下降，且已被系统量化。** 迄今最系统的一次跨域评测（断层解释，>200 组实验设置、8 种网络、3 个跨大洲数据集）明确报告：常规微调在源域/目标域不相交时会发生**灾难性遗忘**；大模型（SegFormer）比小模型更耐域移；域自适应在域差距大时优于直接微调，但在域差距小时反而不如微调 [11]。
3. **公开数据集是有的，而且已经形成了可跨盆地组合的小型"benchmark 家族"**：断层侧有 FaultSeg3D（合成）、Thebe（澳大利亚 Carnarvon 盆地，专家标注）、CRACKS（众包+从业者+专家三级标注）；地震相侧有 F3（荷兰北海）、Parihaka（新西兰 Taranaki 盆地，SEG 2020 公开赛）、Penobscot（加拿大 Scotian 盆地）、cigFacies（大规模合成+野外+真实混合）[1][2][4][5][6][7][8][9]。
4. **工业案例确实存在，而且规模不小**，但绝大多数是"厂商/作业者自证式"的单方报告，缺少第三方盲测与统一指标：北海 Groningen、新西兰 Taranaki、塔里木超深走滑断裂、国内 34 个工区的规模化推广、SLB 的 PRISM 基础模型等 [23][25][26][27][28][29][30]。
5. **最大的方法学缺口不是模型，而是"金标准"本身。** 断层解释的人工标签自身就带 5%~42% 的重复性误差，且受概念模型锚定效应影响 [33][34]；这决定了任何跨盆地评测的**精度上限**和指标的可信区间。

|---|---|---|---|---|---|

**读数据集清单时要注意的三点**
- F3、Parihaka、Penobscot、Thebe 全部是**海相/被动陆缘为主**的数据，陆相断陷、前陆冲断带、碳酸盐岩缝洞体系在公开集里几乎是空白，"跨盆地"的实测覆盖面远小于名义覆盖面。
- 合成集（FaultSeg3D、cigFacies 的合成部分）与实测数据在**主频、信噪比、断层产状分布**上系统性不同，这正是迁移失效的主因 [16]。
- 多数公开集只有**单一标注版本**，无法给出标注不确定度；CRACKS 是例外 [8]。

## 三、跨盆地/跨工区泛化的直接实验证据

> 断层方向的整体研究现状与方法谱系，可先看 Earth-Science Reviews 的系统综述 [35]；下面只挑**真正做了跨数据集/跨工区检验**的工作。

### 3.1 断层解释

**（1）目前最强的一次系统性跨域评测 [11]**
- 实验设计：>200 组"架构 × 数据集 × 训练策略"组合；8 种网络；3 个数据集（FaultSeg3D 合成、CRACKS、Thebe），覆盖不同地质、采集与处理条件。
- 评测方式：除常规分割指标外，额外引入**断层特征描述子**，用于度量模型从训练数据中吸收了多少"结构性偏置"。
- 主要结论：① 常见微调做法在源域与目标域不相交时会导致灾难性遗忘；② 大容量模型（SegFormer）泛化性优于小模型；③ 域自适应方法在域移显著时优于普通微调，但在域相近时反而拖后腿；④ 现有评测协议不一致本身就是部署障碍。
- 证据等级评价：这是本问题下**最接近"多中心外部验证"**的研究，是回答该问题时的首选引用。

**（2）合成→实测的域差距被反复独立复现**
- 合成与实测在信噪比、地震分辨率、断层方向分布上的差异，使纯合成训练模型在野外数据上不可靠；用未标注实测数据做迁移可缓解 [16]。
- FaultSeg3D plus 明确指出 CNN 方法"在野外地震图像上存在泛化差的潜在问题"，并进一步指出**从自然图像分割借来的逐像素指标无法合理评价断层分割**，提出基于距离的指标 [15]。
- 半监督路线（合成 + 少量二维标签 + 大量未标注野外数据，PNC/PTC 双代理任务）被提出专门用于提升"结构复杂工区"的泛化 [17]。
- 一项系统文献回顾 + 对照实验表明：合成数据集是最常用的源域，但此前没人系统检验"哪种源域最有利于断层解释迁移"，并证实换到特征不同的地震数据上性能会显著下降 [18]。

**（3）训练数据分布必须被"证伪"，而不是默认可用**
- 在海上三角洲储层案例中，作者用**先验证伪（prior falsification）**检验合成训练分布与真实地震的一致性，并展示 CNN 对合成训练分布过拟合，需要专门的正则化 [19]。这条方法学要求在跨盆地部署时尤其关键。

### 3.2 地震相识别

- **F3（荷兰）→ Penobscot（加拿大）的无监督深度域自适应**：选取两工区中反射样式相似的三个地质类，提出 EarthAdaptNet；这是地震相领域少见的**显式跨盆地源→目标**实验 [12]。注意其做法本身透露了一个限制——必须先挑"反射样式相似"的类别，说明类体系不一致时迁移无从谈起。
- **类别体系不一致是跨数据集迁移的硬约束**：已有小样本分割方法固定目标类数，导致在 A 相集上训练的模型无法迁移到相数不同的 B 相集；AdaSemSeg 通过自适应相数来支持跨数据集联合训练 [13]。
- **同一盆地内的"留一测线/留一工区"交叉验证**：墨西哥湾东部盐体解释使用 9 个数据集做九折交叉验证（每次留一个数据集做测试）来度量泛化；作者同时明确指出，只有当采集参数与成像算法**相近**时，机器学习模型才具备可用性 [14]。这是把"泛化边界"讲得最诚实的一篇工业向研究。

### 3.3 预训练/基础模型路线（近三年的主要希望，但证据等级偏低）

| 模型 | 预训练数据 | 跨工区证据 | 局限 |
|---|---|---|---|
| **SFM** | 全球收集的 192 个三维地震数据体 → 2,286,422 张二维图像，自监督 ViT | 在地震相分类、地质体识别、插值、去噪、反演等多任务、多工区上验证通用性 [20] | 下游评测仍以公开集为主，缺乏第三方盲测 |
| **多模态提示基础模型** | 自然图像 VFM 预训练 + 地震微调 + 多模态提示引擎 | 明确以**跨工区（across surveys）**为目标，报告可泛化到训练中未见的地质体类型、2D→3D 可扩展 [21] | 提示需要人工介入，"零人工"泛化未证实 |
| **NCS-Model** | 挪威大陆架公开 DISKOS 库的大批全叠加数据体，MAE+ViT，权重开源 | 直接量化**"盆地定向预训练"**与 token 维度对下游解释性能的影响 [22] | 单一陆架，跨盆地外推未验证；预印本 |
| **PRISM（SLB）** | 自监督地震基础模型，编码器-解码器 | 面向盐体、断层、层位等多下游工作流的工业级快速解释 [23] | SPE 会议论文，公开报道注明**未经同行评审**；数据与权重不公开 |
| **GEM 3D** | 统一生成式架构，提示条件推理 | 声称统一且**零样本**的地下理解 [24] | 预印本，零样本主张缺少独立复现 |

| Groningen 气田 | 荷兰 | CNN 断层预测 + 三维断层面自动提取，接入构造格架建模、静态建模与井位设计 | 提取环节的效率提升被作为部署价值主张 | [26] |

**如何读这些工业案例（重要）**
- [29][30] 是**目前公开文献里最接近"多工区外部验证"的工业证据**：前者给出 34 个工区的横向对比与规模化采用统计，后者给出跨工区一次迁移后的可用性与量化提升。但两者的对照基线是传统属性（相干、曲率）或迁移前网络，而非独立第三方模型，也没有盲评。
- 其余案例基本是"单工区、单方报告、无预注册指标"，证据形态接近医学里的**病例系列**，不是外部验证。

## 五、指标与评测协议：目前最容易出错的环节

1. **指标本身选错**：从自然图像分割搬来的逐像素 IoU/F1 对断层这类**细长、稀疏、拓扑敏感**的目标不公平；建议采用基于距离的指标 [15]。
2. **划分方式不透明导致不可比**：对五种主流模型在 F3 与 SEAM AI 上做统一复现的研究发现，大量论文没有交代数据划分、超参与实现细节，而这些细节会显著改变结果，使跨论文比较失效 [32]。
3. **缺少权威协议**：为此已有工作提出在 F3 + Penobscot + Parihaka 上的统一 benchmark 与标准指标 [9]。
4. **推荐的最小实验设计**（把上面几条合起来）：
   - 至少两个**不同盆地**的真实数据体，源域/目标域完全不相交；
   - 报告三档结果：零样本（不看目标域标签）、少样本微调（明确标注预算）、全量微调；
   - 同时报逐像素指标与距离/拓扑指标，并给出断层特征描述子层面的偏置分析 [11][15]；
   - 报告标注不确定度或至少两名解释员的重复解释差异 [8][34]；
   - 公开划分、随机种子与超参 [32]。

## 七、主要局限性与给读者的实操建议

**局限性（按影响大小排序）**

1. **金标准不可靠。** 同一批断层的两次重复解释，落差（throw）平均差 5%~15%，水平断距（heave）差 11%~42%，位移差 9%~31%，倾角差 7%~27%；当解释测线与断层走向斜交超过 20°，落差不确定度升至 14%~24% [34]。161 人参与的受控实验进一步显示，解释者会被最初的概念模型**锚定**，垂向拉伸比例等显示参数会系统性改变解释结果 [33]。任何声称"跨盆地 F1 提升 x%"的结论，都必须放在这个噪声水平上读。
2. **公开数据的地质多样性严重不足。** 现有跨盆地实验主要在荷兰北海、新西兰 Taranaki、加拿大 Scotian、澳大利亚 Carnarvon 之间做，全部偏海相被动陆缘；陆相断陷、前陆冲断、碳酸盐岩缝洞、深层-超深层等在公开集里基本缺位（塔里木案例 [28] 属于私有数据）。
3. **"跨盆地"常被"跨采集/跨处理"混淆。** 墨西哥湾盐体研究明确指出，采集参数与成像算法的差异本身就会改变地震纹理与分辨率，只有采集/处理相近时模型才可用 [14]。很多所谓"跨工区失败"其实是处理流程不一致造成的。
4. **微调不是免费的。** 源域/目标域不相交时的常规微调会引发灾难性遗忘；域自适应也不是万能，域相近时它反而不如直接微调 [11]。不存在一个"默认正确"的迁移策略。
5. **评测协议与指标尚未统一，跨论文数字不可直接比较** [9][15][32]。
6. **工业侧证据链最弱的一环是独立性。** 迄今没有看到第三方在多个盆地、用统一盲测集、对多家商业方案做对比评测的公开报告。

**实操建议**

- 选型阶段：把 [11] 的结论当作先验——优先选大容量骨干（如 Transformer 系），并对"源域是否与目标域相交"做显式判断，再决定用微调还是域自适应。
- 数据阶段：先做训练数据分布的**先验证伪** [19]，确认合成/借用数据与本工区地震在主频、信噪比、断层产状统计上可比；不可比就先做资料调理 [27] 或风格迁移类数据合成。
- 标注阶段：至少两名解释员独立解释一个子体，量化分歧作为指标的误差棒 [8][34]。
- 评测阶段：目标工区留出完全独立的盲测块；同时报逐像素与距离指标 [15]；公开划分与超参 [32]。
- 落地阶段：不要期待"零样本可用"。当前更可靠的路径是"合成/公开数据预训练 + 少量本工区实测标签迁移"，[30] 报告的 73.45% → 95.54% 与 [29] 报告的 34 工区规模化推广均属这一范式；[22] 关于"盆地定向预训练"的量化结论也指向同一方向。
