## 一、一句话结论

2025 年以来这一方向出现了明显的分层：**上层**由 VLA / 多模态大模型接管任务理解与长程规划，**下层**仍靠力/触觉闭环、残差强化学习与 sim-to-real 保证亚毫米精度；两者之间通过“技能库 + 残差策略 + 失败恢复”缝合。真实机器人验证已成为标配，但**真正的产线（factory floor）部署报告目前仅有个位数**，其中最明确的一篇是西门子 Erlangen GWE 工厂的包装任务部署研究 [1]。通用 VLA 在工业高精度任务上仍显著不足：π0 微调后简单抓取成功率约 60%，高精度放置位置误差最高达 2.2 cm / 12.4° [2]。

## 二、主题分类与代表论文

### 主题 1：工业场景的 VLA / 具身大模型落地与工程化（含唯一明确的产线部署案例）

| 工作 | 载体与验证 | 关键结果 |
|---|---|---|
| Factory-Floor Deployment Case Study [1] | **西门子 Erlangen GWE 真实工厂产线**，包装工位（从杂乱堆料中抓透明附件袋并塞入纸箱余腔） | 在线采集 2535 条 episode / 10 小时现场数据，对预训练 π0.5 做迭代微调 + 定向恢复数据回灌；论文核心贡献是**复现性失败模式清单与部署工作流**，而非稳定 KPI |
| Transferring VLA to Industry Applications [2] | 工业场景横评多个 SOTA VLA | π0 微调后简单抓取 ≈60% 成功率；高精度放置位置误差达 **2.2 cm / 12.4°**；指出数据采集与架构两大瓶颈 |
| LoRA Fine-Tuning for VLA in Industrial Manipulation [3] | **UR5e** + 4 项精密装配任务 | LoRA 在 r=32 处性能饱和且与全量微调无统计显著差异；峰值显存 36.2 GiB → **10.8 GiB**；冻结 VLM 或限制视觉编码器会显著掉点 |
| IEI-TIA [4] | 工业分拣与码垛，真机 | 不直接出低层动作，而是做**可信监督智能体**：监控执行、诊断关键阶段失败类型、调用技能给出纠正指令；配对视觉-语言数据的对齐增强 PEFT |
| CIPHER（Nature Communications）[5] | 真实制造工艺回路 | 系统级 VLA：过程专家做定量状态刻画 + 检索增强的工艺物理推理，可解释决策并直接生成机器指令，对分布外任务泛化 |
| RL-100（Science Robotics）[6] | 8 项真机任务（含拧松、多阶段榨汁、长程折箱） | 扩散视觉运动策略 + PPO 式在线改进 + 一致性蒸馏单步控制器；预定义评测协议下 **1000/1000 episode 全部成功** |
| ConRFT [7] | 8 项真实世界接触密集任务 | 离线 BC+Q 学习、在线一致性策略 + 人工干预；**45–90 分钟在线微调后平均成功率 96.3%**，较监督微调提升 144%，episode 长度缩短 1.9× |

### 主题 2：接触密集装配（peg-in-hole / 连接器 / 线束 / 3C）——sim-to-real 与残差 RL 是主流

**通用装配策略与技能复用**
- **SRSA** [8]（ICLR 2025）：面向装配技能库的技能检索与适配，用“零样本迁移成功率预测器”挑选最值得微调的技能，显著优于最强基线。
- **SPARR** [9]：仿真训练基座策略（低层状态 + 稠密奖励）+ **真实世界视觉残差策略**（稀疏奖励）。真机多类两件装配接近满成功率，较 SOTA 零样本 sim2real **成功率 +38.4%、节拍 −29.7%**，且无需人工监督。
- **Refinery** [10]：贝叶斯优化引导微调 + 部署期 GMM 初始条件采样。相对 SOTA **平均成功率 +10.98%**，仿真达 **91.51%** 且真机相当；策略串接可完成**最多 8 个零件**的多步装配。
- **Fabrica** [11]：双臂端到端多件装配系统（优先级/序列/抓取/运动分层规划 + 自动工装生成 + 轻量 RL 局部策略），策略零样本迁移真机，**接触密集步骤成功率 80%**；提出工业与日用多件装配评测套件。
- **Foresight Residual RL** [16]：指出冻结 VLA 上做残差 RL 时“单子任务变好、串起来不涨”的症结在于交接状态质量不可控，用离线估计的 foresight value 作为交接质量奖励。

**面向真实工业件的力/触觉闭环**
- **SHaRe-RL** [12]：面向中小企业**多品种小批量（HMLV）**装配。技能原语化 + 人类示范与在线纠正 + 逐轴柔顺力限幅，在 **Harting 工业连接器模块（0.2–0.4 mm 间隙）** 插装上可在可接受时间预算内安全在线学习。
- **ForceVLA** [13]（NeurIPS 2025）：把 6 轴力反馈作为一等模态，用力感知 MoE 在动作解码时融合；相对 π0 基线**平均成功率 +23.2%**，插头插入任务最高 **80%**。
- **VT-Refine** [14]：真机演示训练视触扩散策略 → 迁移到带触觉仿真的数字孪生 → 大规模 RL 精调，用于精密**双臂**装配。
- **From Reach to Insert** [15]：两阶段 IL+RL，触觉分组采样 + 触觉 critic；覆盖 **5 种孔型 × 3 种间隙**，在保持低接触力的前提下提升插入成功率。
- **Geometry and Force Guided Robotic Assembly** [21]（IEEE TASE）：面向狭小空间、光照复杂、视觉遮挡的**电气连接器**，处理大初始偏差的几何+力引导装配。

**线束 / 柔性线状体（DLO）——公认最难的工业环节**
- **AI-based Connector Mating for Wire Harness Installation** [17]（IEEE CASE 2025）：力控 + 深度视触学习，多模态 Transformer 上做一阶优化搜索-插入策略；在**汽车中控台装配**任务上显著改善节拍与鲁棒性，且输出的机器人程序可原生跑在标准工业控制器上、可被人工审核认证。
- **Behavioral Cloning for Robotic Connector Assembly** [18]：UR5e + SpaceMouse 遥操作采集最多 **300 条**人类示范，融合力/力矩与固定位相机；在 **5 种连接器几何**、位姿变化下总体插入成功率 **>90%**。
- **SILO** [19]：GPU 并行仿真训练多阶段**线缆布线** RL 策略 + “仿真在环”部署框架与线缆状态估计；真机成功率更高且**节拍降低 2×**。

**3C / 电子装配**
- **Manipulation Skill Representation and Knowledge Reasoning for 3C Assembly** [20]（IEEE TMECH）：面向 3C 产线的五层三级知识表示（任务/区域/对象/动作/智能体 × 本体/模板/实例）+ 知识增强的任务到动作推理，提升跨场景可迁移性。

### 主题 3：工业抓取 / 上下料（bin picking、6D 位姿、开放词表）

- **XYZ-IBD** [22]：工业级 6D 位姿与检测基准，**75 个多视角真实场景、约 273k 标注实例**，金属/对称/高反光件，高密度随机堆叠，亚毫米标注精度 + 配套大规模合成训练集。SOTA 方法相较家用基准**性能显著退化**，说明工业视觉远未解决。
- **2025 Bin-Picking Perception Challenge 复盘** [23]（ICCVW）：冠军方案分析给出两个反直觉结论——（1）在“未见物体”数据上训练反而优于对象专用数据集训练；（2）评测结论强依赖指标选择。
- **Region-Aware 6D Grasping for Industrial Bin-Picking** [26]（IROS 2025）：Sim2Real 标签自生成 + Semantic-GraspNet 把 6D 位姿预测转成语义分类，配合“位姿评估 + 机械抓取性能分析”的混合评测，提升抓取成功率与分拣效率。
- **GraspVLA** [24]：完全用十亿帧级合成动作数据（SynGrasp-1B）预训练的抓取基座模型，自回归感知 + flow-matching 动作生成统一为 CoT，具备零样本迁移与少样本后训练能力。
- **Towards intelligent object handling** [25]（IJAMT 2026）：面向**电柜装配**的新型末端执行器，真空 + 平行抓取一体，集成自研压阻式压力传感器判定夹持位姿精度，打通“杂乱料箱抓取 → 在手调整 → 面板装配”。

### 主题 4：多步骤 / 长程操作与任务规划（LLM/VLM 智能体 + 装配序列）

- **Learn-Gen-Plan** [27]（IEEE TASE）：VLM 驱动的真实世界长程灵巧操作，解决新任务上的高效规划。
- **Video-to-BT** [28]：VLM 把**人类演示视频**拆成子任务并生成行为树，行为树既是规划输出也是执行结构；执行失败触发 VLM 重规划，形成闭环。
- **AssemLM** [29]：面向装配的空间推理多模态大模型，融合装配说明书 + 点云 + 文本预测关键 6D 装配位姿；配套 **AssemBench**（>90 万多模态样本，含精确 6D 位姿标注）。
- **Manual2Skill++** [30]：把“连接关系”提升为装配表示中的一等实体，由 VLM 解析说明书符号图生成分层图（节点=零件/子装配，边=连接关系）。
- **One-shot LfD 自主装配** [31]（npj Advanced Manufacturing）：RGB-D 第三人称观察 + 动能变点检测自动分段 + DA-DMP 轨迹适配，真机多工序装配平台上**单次示范即可学会序列，成功率 93.3%**。
- **From insight to action** [32]（Journal of Manufacturing Systems 2026）：VLM 驱动的具身多智能体系统 + 数字孪生，用于人机协作装配。
- **IMR-LLM** [33]：工业多机器人任务规划与程序生成，LLM 辅助构建析取图 + 确定性求解得到高层计划，再用过程树引导生成可执行低层程序；配套 IMR-Bench 三档难度。

### 主题 5：拆解 / 再制造（逆向装配，真实产品验证最扎实的一类）

- **RAISE** [35]：面向**报废手机**的低成本可部署自动选择性拆解分拣系统（自适应切割 + 视觉机器人分拣 + 电池取出）。**>120 台/小时，平均拆解成功率 98.9%**，把原本亏损的工序转为单位重量净盈利。
- **Vision-Guided Dual-Arm Humanoid Disassembly of 18650 Packs** [36]：仅用通用平行夹爪 + RGB-D + 预训练抓取检测器，从任意初始位姿拆解 **21 电芯**电池包，双臂中途交接支撑以扩展工作空间；**端到端 8/10 成功，电芯定位 RMSE 2.4 mm，平均节拍 6.0 分钟**，无需外部夹具。
- **SELF-VLA** [34]：面向报废电子产品的技能增强 agentic VLA 拆解框架，直面拆解“长程 + 接触密集 + 产品差异大”的痛点。
- **Robotic Disassembly Skill Acquisition with External Knowledge Injection** [37]（IEEE TII）：把拆解领域知识注入控制策略与奖励设计，显著提高真实场景 RL 效率，并在多类间隙配合件上验证可迁移性。

## 四、研究空白与建议关注方向

1. **“真实产线”验证严重稀缺。** 绝大多数论文的“真实机器人”是实验室工作站或单机工位；能称为产线部署的目前只有 [1]（西门子 GWE 包装工位），且其贡献是失败模式与工程流程，而非稳定良率/节拍 KPI。[35] 的报废手机拆解与 [36] 的电池包拆解是少数给出吞吐与经济性的系统级工作。
2. **通用 VLA 的工业精度断层。** [2] 量化了这一断层（60% 抓取 / cm 级放置误差）；当前主流补偿路径是残差 RL [9][16]、力/触觉一等模态 [13][14][15] 与分层解耦。何时能不靠残差直接达到工业公差，仍无答案。
3. **评测口径不统一，缺产线级 KPI。** 成功率定义、试验次数、初始条件分布差异极大；几乎无人报告节拍稳定性、MTBF、良率、换型时间、首次通过率。[41]（48 试验/配置）、[39]（阶段化打分）、[10]（初始条件方差）是少数认真处理评测方差的工作，值得作为方法论参考。
4. **数据缺口在“工业侧”。** [38][40][42] 已是最好的公开资源，但仍偏台架/仿真；缺跨工厂、跨批次、跨光照、含长期磨损与来料波动的真实数据，也缺失败/恢复数据的规范采集（[1] 明确指出定向恢复数据是关键）。
5. **柔性件与线束仍是硬骨头。** [17][18][19][42] 说明连接器插配已有 90%+ 的点解，但多分支线束的全流程（理线—走线—卡扣—插配—检测）尚无端到端真机方案。
6. **可信、可解释、可认证。** [4] 的监督式可信智能体与 [17] 的“输出可审核工业控制器程序”是两条务实路线；面向 ISO 10218 / ISO/TS 15066 的安全论证与形式化验证基本空白。
7. **长程技能串接的失败恢复。** [16] 揭示了子任务最优 ≠ 串接最优；[28] 用行为树 + VLM 重规划做闭环。“交接状态质量”与“在线失败检测/恢复”是最有价值的短期突破口。
8. **边缘算力与实时性。** VLA 推理频率与工业伺服控制频率的错配是硬约束（[3] 的显存问题、多篇工作采用感知/控制异步双流），尚无公认的工业级部署形态。
9. **人形机器人进产线仍处早期。** [36] 是少数给出量化端到端结果的双臂人形工业应用，其余多为可行性演示。
