# 精准农业如何形成"遥感监测—物联网传感—农机自动化—决策反馈"闭环

> 覆盖文献时间范围:2023 年至今(含少量 2026 年在线发表成果)。

## 一、结论先行:闭环不是一条链,而是两条速度不同的回路

把精准农业理解成"遥感看一眼、机器干一遍"是不完整的。2023 年以来的系统性工作一致把它描述为**感知—决策—执行—反馈**的循环结构:感知层获取田块状态,数据层完成融合与互操作,决策层把状态量转成可执行的作业量,执行层由自动化农机落地,作业实况与产量结果再回流校准模型 [1][4]。真正让系统"闭合"的,是同时运行的两条回路:

- **快回路(秒级到分钟级,机上闭环)**:传感器直接驱动执行机构,不经过人。典型如机载近地光谱边走边测边施氮 [21]、机器视觉识别杂草后毫秒级控制微喷嘴 [22]、激光除草机器人 [24]。这条回路解决"空间分辨率细到厘米、响应必须实时"的问题。
- **慢回路(天到季到年,管理闭环)**:遥感与传感数据同化进作物模型 [6][7],生成管理分区与处方图 [14][15],由自动导航农机按图作业 [20][25],作业实况(as-applied)与产量数据回流,校准下一轮模型与经济最优参数 [18][33]。这条回路解决"农学最优在哪里、经济上是否划算"的问题。

两条回路缺一不可:只有快回路,系统学不会跨年积累;只有慢回路,处方精度受限于遥感重访周期与云雨窗口。中国大田无人农场的建设实践把这套结构归纳为"数字化感知—智能化决策—精准化作业—智慧化管理"四层,并在水稻等作物上完成了耕种管收全环节的端到端验证 [2][3]。

## 二、环节一:遥感监测——把田块空间变异转成可计算的状态量

**能力边界**。卫星与无人机遥感的核心价值是"面上的变异",而不是绝对精度。UAV 多光谱/热红外已能稳定反演作物水分胁迫,并已形成成套的作业规范与误差来源清单 [8];多传感器协同(光谱+热+结构)比单一载荷更能区分胁迫类型,但对辐射定标、飞行时间窗与冠层几何的要求也更高 [8]。

**从"图像"到"状态量"的关键一步是数据同化**。遥感本身给不出根区含水量、氮素吸收速率这类决策真正需要的过程量,必须与作物生长模型耦合。2023—2024 年的两篇系统评估分别梳理了同化算法族(集合卡尔曼滤波、变分同化、代价函数优化等)的适用条件 [6],以及"模型+遥感"产量估算在不同作物、尺度、同化变量下的表现差异 [7]。二者的共同结论是:同化能显著降低模型在区域尺度的偏差,但收益高度依赖同化变量的选择(LAI、生物量、含水量)与观测频次,盲目同化反而引入噪声 [6][7]。

**这一层的输出**应当是带不确定度的状态场(叶面积指数、氮营养指数、水分胁迫指数、产量潜力分布),而不是一张彩色图片。不确定度必须往下传,否则决策层无法判断该不该动作。

## 三、环节二:物联网传感器——补齐时间连续性与"点上真值"

遥感的短板是时间不连续、且几乎测不到地下。物联网传感网络正好互补。

- **土壤水分传感器**是目前唯一大规模落地的一类。美国的系统综述指出,传感器驱动的灌溉决策在节水上证据充分,但采用率长期偏低,瓶颈不在硬件而在标定、埋设深度代表性、以及"读数—阈值—动作"这条链条缺乏可信规则 [9]。
- **土壤养分与 pH 的原位快速分析**近年进展明显,但综述明确区分了"可直接测定植物有效养分"的少数方法与大量只能做相关推断的方法,后者若直接进处方,误差会被执行环节放大 [10]。
- **植物本体传感(可穿戴/植入式)**代表把测点从土壤搬到作物本身,可实现茎流、水势、挥发物的连续原位监测 [11]。但同一领域的批判性评估提醒:目前绝大多数植物可穿戴传感器仍停留在温室与短期验证,长期田间稳定性、供电、规模化部署成本都未过关,现阶段不宜作为闭环的唯一触发源 [12]。
- **算力与连接的架构问题**同样属于这一层。云—边—端协同计算的综述给出了明确分工:边缘承担实时推理与本地闭环,云端承担模型训练与跨场协同,端侧只做低功耗采集;这一分层是保证田间断网时快回路仍能运行的前提 [13]。

**这一层的输出**是高频时间序列与点位真值,用于给遥感状态场做同化观测、做偏差订正、并作为执行环节的实时触发信号。

## 四、环节三:决策——从"状态场"到"处方量"

这是闭环中技术最不成熟、但价值最集中的一环。目前有四条成型的技术路线。

**路线 A:管理分区 + 作物模型自动标定。** 用遥感生成管理分区,在每个分区上自动标定作物模拟模型的参数,再用模型搜索最优氮肥量,已在大田上完成验证 [14]。这条路线的优点是把农学机理显式写进决策,可解释、可外推。

**路线 B:遥感—模型联合优化。** 在水稻上,遥感反演的氮营养状态与作物模型联合驱动,给出分期追肥的时间与用量,比单纯的光谱阈值法更稳定 [15]。

**路线 C:遥感与地面传感互为校验的灌溉决策。** 无人机热红外/多光谱给出全田块的水分胁迫空间格局 [8],土壤水分传感网络给出根区的连续真值与标定基准 [9],二者结合才能同时定"在哪儿浇"和"浇多少"。单靠其中之一,前者缺时间连续性,后者缺空间代表性。

**路线 D:直接从传感反馈学策略(免模型)。** 深度强化学习可以直接以高维传感器序列为状态、以灌溉量为动作学习调度策略,在仿真与部分田间验证中优于固定规则 [17]。这条路线绕开了模型标定,但可解释性差、对分布外年份的鲁棒性仍是公开问题。

**人必须留在回路里。** 一个把人显式建模进控制回路的灌溉 DSS 表明:让农户能够覆盖、修改并解释系统建议,反而提升了整体执行率与最终水分利用效率 [16]。这一点在闭环设计上比算法精度更关键。

**经济最优,而非农学最优。** 田间精准试验(OFPE)结合机器学习,可以直接估计每个位置的**经济**最优氮肥量(EONR),把价格、投入成本纳入决策 [18];对处方本身盈利性的对比研究显示,不同处方生成方法之间的收益差异往往小于人们预期,处方能否赚钱高度依赖田块内变异程度 [30]。

**必须正视的失败证据。** 对发展中国家点位化养分管理决策支持工具的分析发现,大量工具在试验中有效、在推广中失效,原因集中在数据获取成本、与实际农事日历不匹配、以及缺乏与农机执行端的对接 [19]。这说明"决策"若不与执行层和反馈层同时设计,注定停在示范田。

## 五、环节四:农机自动化——把处方真正落到地面

**自动导航是底座。** 农机自动导航技术(GNSS-RTK、机器视觉、多源融合、路径跟踪控制)已进入工程成熟期,是所有变量作业的定位与重复性保障 [20]。没有厘米级可重复的行走轨迹,处方图的空间精度就没有意义。

执行层有两种范式,应当组合使用:

**范式一:图控(map-based)。** 事先生成处方图,农机按位置执行。工程上的关键是格式与语义的互通——按 ISO 11783(ISOBUS)标准生成的葡萄园变量喷雾处方图,可直接被商用终端读取执行,这是把"决策"与"机器"焊接起来的现实途径 [25]。

**范式二:感知即控制(sensor-based real-time)。** 农机自带传感器,边走边测边调:液态氮肥的在线感知与变量施用系统已完成整机验证,证明"感知—决策—执行"可以压缩到单台机器内部完成 [21];机器视觉驱动的高分辨率微喷嘴喷雾机可在行进中对单株杂草定点喷施 [22]。

**机器人化执行正在把分辨率推到单株级。** 地面机器人在点位化杂草管理上的综述系统梳理了感知、定位、执行末端(机械、激光、电击、定点喷雾)的技术现状与产业化差距 [23];更硬的证据来自跨三种蔬菜生产系统的对比试验:基于深度学习的激光除草与常规化学除草在防效上可比,给出了"机器替代化学品"的量化基准 [24]。

**多机协同是规模化的必需品。** 面向作业幅宽不同、转弯特性不同、且任务之间存在先后依赖的农机群,已有启发式协同覆盖路径规划方法可用 [35];中国大田无人农场的机群调度实践则给出了工程侧的完整样本 [2][3]。这是无人农场从单机演示走向整场运营的关键一步。

## 六、环节五:决策反馈——闭环真正"闭上"的地方

大多数所谓"智慧农业系统"断在这一环:处方下发了,但没人把作业实况和产量结果收回来。要闭合,需要三样东西。

**其一,作业实况与产量数据的自动回流。** 农机执行完成后产生的 as-applied 数据、产量监测数据,应当与当初的处方逐格对比,量化"执行偏差"。这是校准下一季模型的最重要输入,也是评估处方是否值得的唯一依据 [18][30]。

**其二,把田块变成常设试验平台。** 农户主导的田间试验(OFE/OFPE)配合数字工具,可以在不打断正常生产的前提下持续产出因果证据,是慢回路的"学习引擎" [33][18];更进一步,把自动化试验平台与"活体实验室"(living labs)结合,可以显著加快知识产出与跨学科协作速度 [34]。

**其三,数据必须能流动、且农户愿意让它流动。** 农业数据空间的参考架构给出了在保证**数据主权**前提下实现跨系统互操作的工程方案 [26];而对智慧农业数据治理的系统综述则指出,所有权界定、共享激励、责任归属仍是主要空白,治理缺位会直接导致反馈数据拿不到,闭环从数据层断裂 [27]。

**数字孪生是这一环的高阶形态。** 柑橘个体化管理的农业数字孪生工作展示了完整闭环的可能上限:每棵树都有持续更新的虚拟体,可用于预测、干预模拟与个体化管理决策 [5]。这也提示,闭环的最终形态未必是"田块级",而可能下沉到单株级。

## 七、闭环常见的断点(设计时必须预判)

| 断点位置 | 表现 | 证据 |
| --- | --- | --- |
| 感知→决策 | 遥感/传感数据没有不确定度,同化变量选择不当,反而增噪 | [6][7] |
| 传感器成熟度 | 植物可穿戴传感器田间长期稳定性不足,不宜单独触发动作 | [12] |
| 决策→执行 | 处方图格式/语义不通,商用终端读不了 | [25][26] |
| 决策工具本身 | 试验有效、推广失效,与农事日历和农机不匹配 | [19] |
| 遥感驱动灌溉 | 直接用卫星土壤水分定灌溉时机与水量,收益与风险并存,需明确适用条件 | [31] |
| 执行→反馈 | 作业实况与产量数据不回流,模型无法迭代 | [18][30] |
| 数据治理 | 所有权与共享激励不清,反馈数据拿不到 | [27] |
| 经济性 | 变量作业收益低于预期,采用率上不去 | [28][29][30] |

**整体成效证据**:美国精准农业的综合元评述系统汇总了各类技术的采用率、收益与研究缺口 [28];全球证据的元分析显示,农场层面精准农业技术采用总体带来正向的经济与环境收益,但效应量因技术类型与作物差异很大 [29]。这两项结果共同说明:闭环的价值是真实的,但不是自动兑现的,取决于闭合程度。

## 八、典型应用场景(端到端串通版)

**场景 1:大田氮肥变量施用(小麦/玉米/水稻)**
卫星/无人机反演氮营养指数 [8] → 与土壤近地传感、历史产量图融合生成管理分区 → 分区上自动标定作物模型并求解最优氮量 [14][15] → 处方图下发到自动导航拖拉机 [20] → 或改用机载在线感知的边走边调方案 [21] → 作业实况回流,结合 OFPE 更新经济最优氮率 [18] → 次年用盈利性口径复核处方方法 [30]。

**场景 2:精准灌溉(葡萄园 / 中心支轴大田)**
冠层温度与气象数据在线计算作物水分胁迫指数,由物联网 DSS 驱动灌溉阀门 [32] → 土壤水分传感网络提供根区真值与标定 [9] → 遥感提供空间分区,但需注意卫星土壤水分直接定时定量的适用边界 [31] → 决策端可采用人在回路的自适应预测型 DSS [16],或用深度强化学习直接从传感反馈学策略 [17]。

**场景 3:点位化杂草管理与靶向施药**
UAV/机载视觉生成杂草分布 [23] → 实时视觉驱动微喷嘴定点喷施 [22],或用激光除草机器人替代化学除草 [24] → 药剂用量与除草效果回流,评估经济与环境收益 [29]。

**场景 4:果园/葡萄园变量喷雾**
LiDAR/立体视觉三维重建冠层体积 → 生成符合 ISO 11783 的变量喷雾处方图 → 商用变量喷雾终端直接执行 [25],实现"树形几何—药量"的一一对应。

**场景 5:无人农场(全环节闭环的现实样本)**
中国大田无人农场把感知、决策、作业、管理四层集成,机库到田间转移、避障停车、生产过程实时监控、无人化精准作业全部打通 [2];水稻无人化智慧农场自 2020 年起持续验证,并已扩展到多省份、多作物 [3]。这类实践是目前少数能完整展示"数据—决策—执行—反馈"全链路的公开样本,同时也暴露了处方生成仍偏经验参数、缺乏动态修正模型的共性短板 [4]。

**场景 6:个体化管理(数字孪生)**
柑橘树级数字孪生持续吸收传感与影像数据,支持逐株的干预模拟与管理决策,是闭环向单株尺度下沉的代表 [5]。

## 九、落地建议:按闭合难度分三步走

1. **先闭"快回路"**:在单台农机内部完成"感知—控制"闭环(在线氮素感知变量施肥 [21]、视觉靶向喷雾 [22]),不依赖云端与跨系统互通,投入产出最确定。
2. **再闭"处方回路"**:打通遥感/传感 → 管理分区 → 模型求解 → ISO 11783 处方图 → 自动导航农机执行 [14][15][20][25],并从第一天就把 as-applied 与产量数据回收纳入设计。
3. **最后闭"学习回路"**:用 OFPE/活体实验室把田块变成持续产出因果证据的试验平台 [33][34],配合数据空间参考架构与治理规则保障数据可流动、农户可信任 [26][27]。

需要强调的一点:上述三步中,**第 2 步和第 3 步之间的数据回流才是"闭环"与"单向自动化"的分界线**。缺了回流,再高级的遥感与再自动的农机,合起来也只是一条更长的开环流水线。
