# 城市 NOA 感知的三条路线（纯视觉 / 激光雷达融合 / 4D 毫米波雷达融合）在论文里是怎么被比较的

## 0. 结论速览

- **学术界几乎没有"一篇论文、一个数据集、一套训练配方，把三条路线同时摆上台"的三方对比。** 真正的对比是分散在四类证据里的：同框架模态消融、同数据集跨方法排行、受控退化/鲁棒性基准、效率与成本口径。读这些数字时最大的坑是跨数据集横向相减。
- **常规城市工况下的精度排序**（同数据集、同标注协议内）稳定为：激光雷达（+相机）融合 > 纯视觉 ≈ 4D 雷达+相机融合 > 单 4D 雷达。VoD 数据集上 64 线激光雷达仍明显优于 3+1D 成像雷达，但补上高度维和多帧累积后差距在收窄 [2]。
- **退化工况下排序会翻转**：nuScenes-C 的 24 模型大规模评测明确给出"纯相机模型对图像损坏极度脆弱、激光雷达-相机融合模型更鲁棒"的结论 [30]；而在雨雪雾里激光雷达自身也会退化 [32][33]，K-Radar 用同构网络对比证明 4D 雷达在恶劣天气下比激光雷达更鲁棒 [4]。
- **4D 雷达路线近两年的主要论证方式是"追赶叙事"**：从 RCFusion/LXL 建立 4D 雷达+相机基线 [17][19]，到 MSSF 宣称在 VoD 上"已超过经典激光雷达方法" [20]，再到 CVFusion 在 VoD/TJ4DRadSet 上分别再涨 9.10% / 3.68% mAP [21]。这些结论目前只在 VoD、TJ4DRadSet 这类**中小规模、前视为主**的数据集上成立，缺乏 nuScenes 量级的环视验证。
- **对城市 NOA 最有工程意义的结论**是"冗余优先"而非"谁替代谁"：FUTR3D 用统一框架证明"4 线激光雷达+相机（58.0 mAP）可以超过 32 线纯激光雷达方案（56.6 mAP）"[14]；MetaBEV/UniBEV 证明模态缺失时的性能塌陷可以靠架构设计而非堆传感器来缓解 [15][16]；ASF 在 K-Radar 上把相机、激光雷达、4D 雷达放进同一 canonical 空间，在天气与传感器退化条件下取得 AP_BEV 87.2%、AP_3D 73.6% [24]。

## 1. 论文是用哪四类证据在做比较的

| 证据类型 | 做法 | 代表工作 | 可比性强度 | 主要局限 |
|---|---|---|---|---|
| **A. 同框架模态消融** | 一个网络吃不同传感器组合，只换输入 | FUTR3D [14]、UniBEV [16]、MetaBEV [15]、ASF [24] | **最强**（训练配方、backbone、评测完全对齐） | 统一框架往往对某一模态不是最优实现，会低估该模态上限 |
| **B. 同数据集跨方法排行** | 同一 benchmark 上不同路线的 SOTA 对比 | nuScenes [1]、VoD [2]、TJ4DRadSet [3]、K-Radar [4]、OmniHD-Scenes [5]、OpenOccupancy [29] | 中等 | 各方法 backbone/分辨率/预训练/帧数不同，差值含大量与模态无关的因素 |
| **C. 受控退化与鲁棒性基准** | 人为注入损坏或采集真实恶劣天气 | nuScenes-C [30]、RoboBEV [31]、Seeing Through Fog [32]、雪天仿真 [33]、K-Radar [4] | **对"适用条件"最强** | 合成损坏与真实退化的分布差距；真实恶劣天气数据规模仍小 |
| **D. 效率/成本口径** | FPS、参数量、延迟、传感器成本论述 | CRN 20 FPS [25]、RCBEVDet 21~28 FPS [26]、SMURF ≤0.05 s [18]、BEVFusion 视角变换延迟降 40× [13] | 弱到中等 | 硬件平台不统一；传感器价格多为定性论述，学术论文很少给可验证的成本数字 |

**必须记住的三条可比性边界：**

1. **nuScenes 上的"雷达"不是 4D 雷达。** nuScenes 配的是 5 个传统 3D 毫米波雷达（距离+方位+多普勒，无高度）[1]，所以 CRN [25]、RCBEVDet [26] 在 nuScenes 上的成绩是"相机+传统毫米波雷达"的水平，只能当作 4D 雷达路线的**下界**参考。真正的 4D 雷达证据集中在 VoD [2]、TJ4DRadSet [3]、K-Radar [4]、OmniHD-Scenes [5]。
2. **VoD/TJ4DRadSet 与 nuScenes 的指标不可直接比。** 前者用 KITTI 式 AP/mAP 并分"整个标注区域 / 驾驶走廊"两种统计口径，后者用 NDS/mAP 与 10 类平均，数值体系完全不同。
3. **融合方法在干净基准上的增益可能被高估。** "Detecting As Labeling" 指出激光雷达-相机融合的算法研发存在系统性过拟合，其根源在于数据标注环节的规则被违反 [34]——这直接影响我们如何相信"融合 > 单模态"的那几个百分点。

## 3. 分路线的实证证据细节

### 3.1 纯视觉：靠 BEV 表征与时序把差距压到"可比"，但退化工况是硬伤

- **精度轨迹清晰。** BEVFormer 用时空 Transformer 统一 BEV 表征，nuScenes test 达 56.9% NDS [6]；BEVDepth 指出多视角 3D 检测的核心瓶颈是深度不可靠，需要显式深度监督 [7]；StreamPETR 用对象中心的长时序传播把 nuScenes 推到 67.6% NDS / 65.3% AMOTA，论文自陈为"首个达到可与激光雷达方法相比水平的在线多视角方法" [8]。**注意这句话的措辞是"comparable"而不是"超过"，且是在干净数据集上。**
- **下游任务同样支持纯视觉可行。** UniAD 把感知-预测-规划全栈以规划为导向统一进一个网络 [10]；在线矢量化建图方面 MapTR 明确宣称"在 nuScenes 上，仅用相机输入即在现有矢量化建图方法中取得最好的性能与效率"，nano 版可实时 [11]——这两点直接支撑城市 NOA "去高精地图 + 纯视觉"的技术叙事。
- **鲁棒性是被反复实锤的短板。** nuScenes-C 设计 27 类相机/激光雷达损坏、评测 24 个模型后给出三条结论：运动级损坏威胁最大；激光雷达-相机融合模型更鲁棒；**纯相机模型对图像损坏极度脆弱，说明激光雷达点云不可或缺** [30]。RoboBEV 在 33 个 BEV 模型上进一步指出：分布内性能与分布外韧性正相关，预训练、免深度 BEV 变换、以及充分利用长时序都能提升鲁棒性 [31]。BEV 表征本身的鲁棒性也被单独系统评估过（自然损坏 + 3D 一致 patch 攻击）[9]。

### 3.2 激光雷达（+相机）融合：精度上限与冗余能力的双重锚点

- **融合范式的两条主线。** TransFusion 用软关联的 Transformer 解码器替代硬性投影关联，专门解决图像质量差和标定误差场景 [12]；BEVFusion 把多模态特征统一到共享 BEV 空间以保留相机的语义密度，同时把视角变换延迟降低 40 倍以上，在 nuScenes 上 3D 检测 +1.3% mAP/NDS、BEV 地图分割 +13.6% mIoU，计算量还低 1.9× [13]。
- **最干净的模态头对头来自统一框架。** FUTR3D 用模态无关的特征采样器支持"几乎任意传感器组合"，并给出对城市 NOA 选型最有价值的一条结论：**4 线激光雷达 + 相机（58.0 mAP）> 32 线纯激光雷达方案（56.6 mAP）**，即相机可以直接换取激光雷达线数/成本 [14]。
- **模态缺失是被专门量化的。** MetaBEV 覆盖 6 类传感器损坏 + 2 种极端缺失：激光雷达缺失时相对原版 BEVFusion 提升 35.5 NDS 检测与 17.7 mIoU 分割；相机缺失时仍有 69.2 NDS / 53.7 mIoU [15]。UniBEV 则把"一次训练、三种输入（LC / 仅激光 / 仅相机）"作为设计目标，在全部输入组合上优于 BEVFusion 与 MetaBEV，并给出加权平均融合优于常规拼接的消融 [16]。
- **激光雷达自身的天气退化有独立的物理级证据。** Seeing Through Fog 构建了未见恶劣天气下的多模态融合基准 [32]；LiDAR Snowfall Simulation 用物理仿真量化雪天点云退化对 3D 检测的影响 [33]。这两项是"激光雷达并非全天候"的标准引用。
- **一条重要的方法论警告。** "Detecting As Labeling" 认为激光雷达-相机融合的算法研发链条存在过拟合，其源头是数据标注构建时的基本规则被违反 [34]——也就是说融合相对单模态的那几个点，未必全部来自真实的感知增益。

### 3.3 4D 毫米波雷达融合：三个子路线、一条追赶曲线

**(a) 4D 雷达 + 相机（最主流，对标"替代低线束激光雷达"）**

RCFusion 首先在统一 BEV 空间做 4D 雷达与相机融合，并在 TJ4DRadSet 与 VoD 上验证 [17]；LXL 用图像深度分布 + 雷达 3D 占据栅格辅助"采样式"视角变换，在两个数据集上大幅超过当时 SOTA，其命名 "LiDAR Excluded Lean" 直接表明"去激光雷达"的定位 [19]；MSSF 用多阶段采样融合把 VoD/TJ4DRadSet 的 3D mAP 分别再推 +7.0% / +4.0%，并明确写出"在 VoD 上甚至超过了经典的基于激光雷达的方法" [20]；CVFusion 用雷达引导的迭代 BEV 融合 + 跨视角实例级精化，在 VoD/TJ4DRadSet 上再取得 +9.10% / +3.68% mAP [21]。Doracamom 进一步把配置扩展到**多视角 4D 雷达 + 环视相机**，同时做 3D 检测与语义占据预测，在 OmniHD-Scenes、VoD、TJ4DRadSet 上均达 SOTA [27]。

**(b) 单 4D 雷达（对标"雷达能不能自己站住"）**

SMURF 用多表示融合（pillar 化 + 核密度估计）缓解 4D 雷达点云稀疏与噪声，结论很有信息量：**仅用 4D 雷达即可与当时最好的 4D 雷达+相机融合方法打平**（TJ4DRadSet BEV mAP +1.22%、VoD 整区 3D mAP +1.32%），且多数帧推理不超过 0.05 s [18]。这说明当时的融合方法尚未真正吃透相机信息。

**(c) 4D 雷达 + 激光雷达（对标"给激光雷达上天气保险"）**

L4DR 是早期融合方向的代表：在带雾仿真的 VoD 上，相对纯激光雷达方案 3D mAP 最高 +20.0%，并在 K-Radar 真实恶劣天气上验证增益一致 [22]；3D-LRF 是同期独立的 CVPR 工作，同样面向多天气条件下的激光雷达 + 4D 雷达融合 [23]。ASF 则更进一步做三模态：把相机、激光雷达、4D 雷达统一投影到 canonical 空间并做跨传感器 patch 注意力，在 K-Radar 上 AP_BEV 87.2%（+9.7%）、AP_3D 73.6%（+20.1%）@IoU=0.5，且计算开销低——这是目前少有的**三条路线同框对比**的实证 [24]。

**(d) 占据栅格上的对比**

RadarOcc 直接处理 4D 雷达张量做 3D 占据预测，并在 K-Radar 上对**不同模态**的基线做统一 benchmark，结论是雷达路线在占据预测上达到 SOTA，"与激光雷达或相机方法相比也有可观结果"，并在恶劣天气下有定性优势 [28]。作为对照，OpenOccupancy 把 nuScenes 扩成环视稠密占据基准，同时建立了相机、激光雷达与多模态三套基线，是"占据任务上三模态对比"的通用场地 [29]。

**(e) 需要放在旁边读的传统雷达证据**

CRN（相机 + nuScenes 的传统 3D 雷达）实时设定 20 FPS 时与激光雷达检测器可比，**在 100 m 设定下甚至反超**，离线设定 nuScenes test 62.4% NDS / 57.5% mAP，在所有相机与相机-雷达检测器中排第一 [25]；RCBEVDet 在 nuScenes 与 VoD 上取得雷达-相机 SOTA，并在 21~28 FPS 下优于所有实时纯相机与雷达-相机检测器 [26]。由于用的是无高度的 3D 雷达，这两条结果应被读作 4D 雷达路线的**保守下界**。

## 4. 按城市 NOA 场景拆的适用条件

| 城市 NOA 典型场景 | 纯视觉 | 激光雷达融合 | 4D 雷达融合 | 支撑证据 |
|---|---|---|---|---|
| 白天结构化城市道路、常规车辆行人 | 可用，精度已接近 | 最优 | 可用；VoD 上已有超越经典激光雷达方法的报告，但数据集规模小 | [8][13][20] |
| 夜间 / 逆光 / 隧道进出口 | 明确劣势（图像损坏敏感） | 稳健 | 稳健（不依赖可见光） | [30][31][4] |
| 雨雪雾 | 最差 | 中等，激光雷达自身物理退化 | 最优 | [30][32][33][4][22][23] |
| 远距离目标、高速汇入 | 深度误差随距离恶化 | 受线数限制 | 强（长距 + 直接测速） | [7][25][35] |
| 静止 / 异形 / 长尾障碍物 | 依赖占据预测补位 | 强（几何直接可测） | 中等（点云稀疏、噪声多，需占据表征补位） | [29][28][27] |
| 可行驶空间与占据栅格 | 相机基线成熟 | 多模态基线最强 | 4D 雷达占据已达可用水平 | [29][28][27] |
| 在线建图（去高精地图） | 仅相机即为最好性能/效率折中 | 增益有限 | 少见专门研究 | [11] |
| 传感器脏污/遮挡/单点失效 | 无冗余 | 架构可显著缓解 | 三模态可用性感知融合效果最好 | [15][16][24] |
| 算力与成本预算 | 最省 | 最贵，但可用相机换线数 | 中间档，论文普遍以低成本立论 | [14][5][19] |

## 5. 证据强度总结与阅读提醒

| 结论 | 证据强度 | 理由 |
|---|---|---|
| 常规工况下"激光雷达融合 > 纯视觉" | **强** | nuScenes 大规模基准 + 统一框架消融 + 多年独立复现 [1][13][14][30] |
| "纯视觉在图像退化下显著更脆弱" | **强** | 24 模型 × 27 类损坏的系统评测明确写入结论 [30]，33 模型的 BEV 鲁棒性评测佐证 [31] |
| "4D 雷达在恶劣天气优于激光雷达" | **中强** | K-Radar 用同构网络做的受控对比 [4]，L4DR [22]、3D-LRF [23]、ASF [24] 三项独立工作在两个数据集上一致复现 |
| "4D 雷达+相机已可替代低线束激光雷达" | **中等** | 仅在 VoD/TJ4DRadSet 上成立 [20][21]，两者规模小、以前视为主；nuScenes 量级的环视验证缺失，OmniHD-Scenes [5] 是刚补上的场地 |
| "单 4D 雷达可与雷达+相机融合打平" | **弱到中等** | 单一工作的结论且发表于 2023 年 [18]，之后融合方法进步很快，该结论已被 [20][21] 部分推翻 |
| "冗余传感器主要价值在失效工况而非常态精度" | **中强** | MetaBEV [15]、UniBEV [16]、ASF [24] 从三种架构路线得到方向一致的结论 |
| 各类"成本"论述 | **弱** | 学术论文几乎不给可验证的价格数据；唯一可量化的降本证据是 FUTR3D 的线数替换实验 [14] |

**四条阅读提醒：**

1. **不要跨数据集相减。** VoD/TJ4DRadSet 的 mAP 与 nuScenes 的 NDS 不在同一体系；"4D 雷达在 VoD 上超过激光雷达"不能推出"4D 雷达在 nuScenes 上超过激光雷达"。
2. **区分 3D 雷达与 4D 雷达。** nuScenes 上一切"radar-camera"结果用的是无高度维的传统雷达 [1][25][26]。
3. **警惕融合基准上的过拟合。** [34] 的批评意味着"融合 vs 单模态"的小幅差值需要打折。
4. **纯视觉的"可比"是有条件的可比。** StreamPETR 的原话是 comparable，前提是干净数据、在线设定、nuScenes 分布内 [8]；一旦进入 [30][31] 的退化设定，差距会重新拉开。
