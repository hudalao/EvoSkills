# 医疗多模态大模型现状（影像 / 病历 / 临床问答）与 2025 年以来的新综述

（检索截至 2026-08-06；论文标题保留英文原文）

## 一、一句话结论

到 2026 年年中，医疗多模态大模型已经从"能看懂一张图"走到"能把影像、病历文本、检验结果放在一次对话里一起推理"，在**闭卷考试型问答**上分数接近饱和、在**影像报告初稿生成**上已经出现多中心前瞻验证与随机对照试验级别的证据；但在**真实临床工作流、跨模态因果推理、鲁棒性与安全性**三件事上仍有系统性缺口——最尖锐的证据是：多个审计研究发现模型即使把图片遮掉或换成别的病人，答案也基本不变 [33][34][38]。

想快速补课的话，2025 年以来最值得先读的四篇综述是：Information Fusion 的《Medical multimodal large language models: A survey》[1]、Korean Journal of Radiology 的放射学专题综述 [3]、Nature 的 GenMI 视角综述 [4]，以及 Biomedical Engineering Letters 的 PRISMA-ScR 范围综述 [5]。

## 三、三条主线各自做到了什么程度

### 3.1 影像：从"看图问答"到"3D + 全片 + 定位 + 多时间点"

**（1）通用医疗多模态基座已经成规模开源。**
- MedGemma [12] 基于 Gemma 3 的 4B / 27B 构建医疗视觉-语言基座，在分布外任务上相对基座模型取得医疗多模态问答 +2.6%～10%、胸片征象分类 +15.5%～18.1%、agent 类评测 +10.8% 的提升，且保留了 Gemma 3 的通用能力。
- **MedGemma 1.5 [13]（2026）是目前最能说明"程度"的一份技术报告**：单一架构内同时支持高维影像（CT/MRI 体数据、病理全切片 WSI）、基于 bounding box 的解剖定位、多时间点胸片对比，以及**医学文档理解（化验单、电子病历）**——影像与病历两条线在模型层面已经开始合流。
- Lingshu [14] 走的是数据治理 + 多阶段训练 + 可验证奖励强化学习的路线，明确针对"影像之外的医学知识覆盖不足、数据质量差导致幻觉、缺少面向复杂临床场景的推理能力"三个痛点。
- Hulu-Med [15] 用 16.7M 全公开/合成样本（12 大解剖系统、14 种成像模态）在单一架构里统一了纯文本、2D/3D 视觉语言与视频理解，对 3D 与视频输入做到最多 55% 的视觉 token 裁剪；在 30 个院内外基准上有 27 个超过开源模型、16 个超过 GPT-4o，纯文本 HealthBench 上超过 GPT-4o、追平 GPT-o1。

**（2）3D 与专科基座也已经成型。** RadFM [16] 构建了 13M 张 2D 图与 615K 例 3D 扫描的 MedMD 数据集，支持文本 + 2D/3D 扫描联合输入，覆盖诊断、VQA、报告生成、推理式诊断，并自建 RadBench 评测，效果超过 GPT-4V。病理方向 MUSK [17] 用 5000 万张病理图（11,577 例患者）与 10 亿病理相关文本 token 做统一掩码预训练，在 23 个 patch/slide 级基准上领先，并能做黑色素瘤复发、泛癌预后、免疫治疗响应预测。皮肤科 PanDerm [18] 用 11 家机构、4 种成像模态的 200 万+ 真实图像预训练，在 28 个基准上全面 SOTA，且常常只用 10% 标注就超过既有模型。

**（3）报告生成已经进入"读者研究 / 前瞻验证"阶段。** Radiology 2025 的一项工作 [19] 用 42 家医院 2005–2023 年的胸片-报告对训练领域专用多模态生成模型，在 PadChest、Open-i、VinDr-CXR、MIMIC-CXR-JPG 等公开集上测试 13 类征象的敏感度/特异度，并让 4 位放射科医生把它与放射科医生报告、通用大模型（GPT-4Vision）做主观质量与排序比较——"可接受性"定义为医生愿意原样签发。

### 3.2 病历（EHR / 临床文本）：LLM 已经能当"通用 EHR 编码器"，但多模态融合仍以 agent 拼装为主

- **把病历码转成自然语言，通用 LLM 就能当 EHR 表征器。** [20] 把医疗编码替换为自然语言描述后，用通用 LLM 产出高维 embedding，在 EHRSHOT 的 15 个临床预测任务上与专用 EHR 基座模型 CLMBR-T-Base 打平；UK Biobank 外部验证中部分任务显著更优。结论是专用 EHR 模型胜在算力效率，LLM 路线胜在可移植性与不依赖私有训练数据。
- **多模态 EHR 预测目前更多靠"多智能体拼装"而不是端到端大模型。** MoMA [21] 用"专科智能体"把影像、化验等非文本模态转成结构化文本摘要，再由聚合智能体与预测智能体产出结论，在三项预测任务上超过既有方法——这恰恰说明真正端到端的多模态 EHR 大模型还没成熟。
- **模型层面的合流刚刚开始**：MedGemma 1.5 [13] 把化验单与电子病历文档理解直接纳入同一模型能力清单，是这条线最新的进展信号。
- 想系统了解这条线，读 [11]（EHR 建模综述）与 [3]（放射科视角强调影像必须结合病历）。

### 3.3 临床问答：闭卷题接近饱和，开放式与多轮场景仍有大量空间

- **考试型基准已被推到高位。** MedXpertQA [23] 用 4,460 题覆盖 17 个专科、11 个人体系统，MM 子集刻意采用带患者病历与检查结果的专家级考题（而不是从图注拼出来的简单问答），并做了数据合成来降低泄漏风险。GPT-5 的评测 [26] 在 MedQA、MedXpertQA（文本 + 多模态）、MMLU 医学子集、USMLE 自测、VQA-RAD 上统一协议下全面刷新，其中 MedXpertQA MM 的推理分与理解分相对 GPT-4o 分别提升 +29.26% 与 +26.18%。
- **开放式评测才是当前的主战场。** HealthBench [24] 用 5,000 段多轮对话、262 位医生编写的 48,562 条条目化评分标准，量出了近两年的真实进步曲线：GPT-3.5 Turbo 16% → GPT-4o 32% → o3 60%。MedHELM [25]（Nature Medicine 2026）则给出临床医生验证过的任务分类（5 大类 / 22 子类 / 121 项任务）与 37 项评测，用 LLM-jury 比较 9 个前沿模型，推理型模型（DeepSeek R1、o3-mini）胜率 66%，而 Claude 3.5 Sonnet 以低 15% 的成本取得相当结果。
- **多模态问诊对话已经做到 RCT 式的对照评估。** 多模态 AMIE [27]（Nature Medicine 2026）提出"状态感知对话框架"，按诊断不确定度动态引导病史采集，在 105 例模拟远程问诊（含皮肤照片、心电图、临床文档）中以随机、盲法方式与初级保健医生对照——这是把"影像 + 病历 + 问答"三者真正合到一次会诊里的代表工作。

## 四、代表性基准与当前分数（一眼看清"差距在哪"）

| 基准 | 规模/设计 | 当前水位（关键数字） |
|---|---|---|
| GMAI-MMBench [28] | 284 个数据集、38 种影像模态、18 类临床任务、18 个科室、4 种感知粒度，VQA 形式，评测了 50 个 LVLM | **GPT-4o 仅 53.96%**，是"通用多模态医疗能力远未解决"的标志性数字 |
| MedXpertQA [23] | 4,460 题，Text + MM 双子集，专家复核、合成去泄漏 | 专为压制 MedQA 难度不足而设计；GPT-5 在 MM 子集相对 GPT-4o 大幅提升 [26] |
| HealthBench [24] | 5,000 段多轮对话，262 位医生，48,562 条评分标准 | GPT-3.5 Turbo 16% → GPT-4o 32% → o3 60% |
| MedHELM [25] | 5 类 / 22 子类 / 121 项真实临床任务，37 项评测 | 推理型模型胜率 66% |
| AgentClinic [29] | 多模态 agent 基准，9 个专科、7 种语言，含患者交互、信息不全下的多模态采集与工具使用 | **同样的 MedQA 题目改成序贯决策形式后，诊断准确率可跌到原来的十分之一以下**；Llama-3 借助 notebook 工具可获得最高 92% 的相对提升 |
| MedBench v4 [30]（中文） | 全国性云端评测，70 万+ 专家标注任务，24 个一级 / 91 个二级专科，分设 LLM、多模态、agent 三条赛道 | 基础 LLM 均分 54.1/100（最佳 Claude Sonnet 4.5 62.5），**安全与伦理仅 18.4/100**；**多模态模型均分更低，只有 47.5/100（最佳 GPT-5 54.9）**，感知尚可但跨模态推理弱；agent 化后均分升到 79.8/100（最高 85.3，安全 88.9） |
| 急诊/重症 VLM 基准 [37] | 含医学影像 + 临床上下文的诊断问题 | 小型开源 VLM 最高 40.4%，GPT-4o 68.1% |

一个跨基准的稳定规律：**越靠近真实临床工作流（序贯决策、多轮、开放式、跨模态），分数掉得越厉害**；这也是 [9] 所说"知识—实践鸿沟"的量化体现。

## 五、临床级证据：目前最"硬"的几项

1. **随机对照试验（眼科）** [31]：EyeFM 用 5 种模态、1450 万张眼科影像配对临床文本预训练，在中国高危人群视网膜筛查中做单中心、平行、双盲 RCT，668 名受试者、16 位眼科医生等量分配。带 EyeFM 副驾的医生正确诊断率 92.2% vs 75.4%、转诊率 92.2% vs 80.5%（P 均 < 0.001）；随访时患者自我管理依从率 70.1% vs 49.1%、转诊建议依从率 33.7% vs 20.2%。
2. **多中心前瞻验证（消化内镜报告）** [22]：Report-Angel 用 20,617 对图文训练，前瞻内部队列临床可接受报告率 79.3%（95% CI 74.4–83.5），前瞻外部队列 83.3%（78.7–87.3）；病例级报告完整度 88.51%、准确度 78.93%，平均每个病灶处理 1.5 秒。
3. **读者研究（胸片报告）** [19]：42 家医院数据训练的领域专用模型，与放射科医生报告及 GPT-4Vision 做盲法主观质量与排序比较。
4. **独立第三方评测（临床问答产品）** [32]：把 OpenEvidence、UpToDate Expert AI 两款已进入临床的商用工具，与 GPT-5.2、Gemini 3.1 Pro、Claude Opus 4.6 在 500 道 MedQA、500 条 HealthBench 以及 100 条真实医生提问构成的 RCQ 基准上对比，12 位美国临床医生做随机盲法评审共 1,800 条标注。结论相当刺眼：**通用前沿模型在三项评测中全面胜出，专用临床 AI 工具在真实临床提问上的表现与开启 AI 概览的 Google 搜索相当**。

## 六、研究空白（按紧迫程度排序）

1. **模型可能根本没在"看图"。** 有工作直接做因果审计——遮挡相关区域、遮挡无关区域、换成另一位病人的同标签胸片——发现胸片视觉语言模型的高准确率可能来自征象名先验而非读片，且现有标准基准无法区分这两者 [33]。Korean Journal of Radiology 的述评 [34] 汇总多项研究得到一致结论：图像输入对通用 MLLM 表现只有很小影响，图像类问题准确率明显低于纯文本问题；脑 MRI 场景中"提供图像描述"的效应最强（OR 达 68），而只给图像几乎无法诊断；更耐人寻味的是文本变长会显著提高模型准确率，而人类读片者不受文本长度影响。
2. **鲁棒性远未达到部署门槛。** 面对常见影像伪影，VLM 在原图上准确率本就只有 0.645（MRI）/0.602（OCT）/0.604（X 光），加入轻微伪影后再降 3.34% / 9.06% / 10.46%；对强伪影的检出率仅 0.194 / 0.128 / 0.115 [35]。Nature Medicine 2026 的系统性对抗压力测试 [38] 给出同方向结论：前沿模型在关键输入被删除时仍能"猜对"，却会被极轻微的提示改动带偏，并编造看似可信实则错误的推理链；不同健康基准衡量的东西差异极大，**基准分数系统性高估真实适用性**。
3. **幻觉仍缺乏统一定义与治理手段。** [36] 把"医学幻觉"定义为任何在事实、逻辑或证据支持上出错、并可能改变临床决策的输出，并评测了 11 个基座模型；这一条也是 Lingshu [14] 明确列出的三大痛点之一。
4. **安全与伦理是多模态方向最薄弱的一环。** 中文 MedBench v4 [30] 上基础模型安全与伦理只有 18.4/100，多模态模型总分（47.5）还低于纯文本模型（54.1）——**跨模态推理，而非跨模态感知，才是真正的瓶颈**。
5. **评测范式仍以静态问答为主。** AgentClinic [29] 已经证明把同样的题改成序贯决策会让准确率崩塌一个数量级；[9] 也指出现有 39 个临床基准在评测方法学上存在明显缺口。
6. **前瞻性、多中心、外部验证的研究仍是少数。** 目前只有内镜报告 [22]、眼科副驾 RCT [31] 等少数几项达到这个级别，绝大多数医疗 MLLM 论文停留在回顾性公开数据集上；[10] 把这一点连同公平性、跨国合规一并列为落地障碍。
7. **病历侧的端到端多模态建模仍是空白。** 现阶段主流做法仍是用智能体把非文本模态"翻译"成文本再融合 [21]，而不是让模型原生消化结构化 EHR + 影像；MedGemma 1.5 [13] 刚刚迈出第一步。
