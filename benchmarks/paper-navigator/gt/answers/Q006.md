# 中文电子病历实体识别与关系抽取的奠基工作溯源

## 一、结论速览

如果只想记住三条线索：

1. **定义的源头不在中文，而在 i2b2。** 中文电子病历（CEMR）里"医学实体"和"实体/事件关系"的类别体系，几乎全部是 2010 年 i2b2/VA 评测所定义的 problem / test / treatment 三类概念 + 断言 + 八种句内关系的中文改写 [1]；而"事件—时间关系"这一层的原始定义来自 2012 年 i2b2 时序评测的 EVENT / TIMEX3 / TLINK 三元标注 [2]。
2. **中文侧最早的一批工作出现在 2010—2011 年。** 规则+本体路线的开端是李毅等 2010 年《中文电子病历信息抽取研究》[3]；基于机器学习（CRF）真正做"中文病历命名实体识别"的公认首次尝试是叶枫等 2011 年《电子病历中命名实体的智能识别》[4]，它定义的实体只有三类：疾病、临床症状、手术操作。
3. **中文自己的完整实体+修饰+关系标注体系，成型于哈工大关毅课题组 2014—2016 年的语料库工作** [9][10][11]：5 类实体、7+3 类修饰、6 大类（20 个子类）实体关系，明确"只标注句内关系"，并首创"实体组"来简化复杂关系。这是中文电子病历关系抽取真正意义上的奠基之作。

英文期刊上最早的两篇中文临床 NER 论文都在 JAMIA、都在 2013 年在线发表：徐妍等的联合分词—NER 工作（Epub 2013-08-09）[5] 略早于雷健波等的系统性比较研究（Epub 2013-12-17）[6]。

## 二、论文时间线

### 0. 前史（2011、2013）：中文体系借来的那把尺子

**[1] 2010 i2b2/VA challenge on concepts, assertions, and relations in clinical text**（Uzuner 等，JAMIA 2011）
这是几乎所有后续中英文临床信息抽取论文的定义原点，它规定了三件事：

- **概念（实体）三类**：medical problem（医疗问题）、test（检查/检验）、treatment（治疗）。
- **断言（assertion）**：对 problem 标注 present / absent / possible / conditional / hypothetical / not associated with the patient 等取值，把"有没有、是不是病人本人的、是否假设"从实体里剥离出来单独建模。
- **关系八类、三大组**：治疗↔问题 5 类（TrIP 治疗改善了问题、TrWP 治疗恶化了问题、TrCP 治疗导致了问题、TrAP 治疗施加于问题、TrNAP 因该问题而未施治疗）；检查↔问题 2 类（TeRP 检查证实了问题、TeCP 为证实问题而做检查）；问题↔问题 1 类（PIP）。关系**只在同一句内**标注。
  （上述八类关系的中文释义可在中文综述 [9] 的"表 5"中逐条对照。）

**[2] Evaluating temporal relations in clinical text: 2012 i2b2 Challenge**（Sun、Rumshisky、Uzuner，JAMIA 2013）
这是"事件关系"这一提法的原始出处：把病历叙述切成 **EVENT**（临床事件，带类型/极性/模态）、**TIMEX3**（时间表达式，带 type/value/modifier）、**TLINK**（事件—事件、事件—时间之间的 BEFORE / AFTER / OVERLAP 时序链接），从而把病历放到一条统一时间轴上。中文侧的"医疗事件抽取""时间关系抽取"任务全部沿用这套三层结构。

### 1. 2010—2011：中文电子病历信息抽取的真正起点

**[3] 李毅、鲍鹏飞、薛万国《中文电子病历信息抽取研究》（生物医学工程学杂志 2010;27(4):757-762，PMID 20842840）**
解放军总医院医学信息研究所的工作，是可检索到的最早一篇专做中文电子病历信息抽取的论文。技术路线是**自然语言理解 + 本体**：在 GATE 平台上构建命名实体规则、分类词表和领域本体，实现中文病历的自动信息抽取；实验对象是**药物使用分布**与**患者年龄/性别分布**。注意：它还没有"命名实体类别体系"的概念，是规则/词表驱动的抽取，不是标注语料 + 统计模型的范式。

**[4] 叶枫、陈莺莺、周根贵、李昊旻、李莹《电子病历中命名实体的智能识别》（中国生物医学工程学报 2011;30(2):256-262）**
这是**中文电子病历命名实体识别的开山之作**（该文被自动化学报 2014 年综述 [9] 收作参考文献第 95 条，编号可核）。它的原始设定值得完整记录，因为后来所有中文体系都是在它的基础上扩张的：

- **实体只定义三类**：疾病、临床症状、手术操作——注意此时还没有"检查/检验""药物""身体部位"这些类别，也没有任何关系或修饰的定义。
- **语料**：自建小规模标注语料，250 份病历，覆盖 25 个疾病大类。
- **模型**：条件随机场（CRF++），特征集为语言符号、词性、构词特征、词边界、上下文。
- **结果**：三类实体最佳 F 值分别约 92.67% / 93.76% / 95.06%（三次对照实验）。

### 2. 2013—2015：英文期刊上的中文临床 NER，与"怎么标"的第一轮争论

**[5] Joint segmentation and named entity recognition using dual decomposition in Chinese discharge summaries**（Xu Yan 等，JAMIA 2014;21(e1):e84-92，**Epub 2013-08-09**）
现有检索范围内**最早在国际同行评议期刊上发表的中文临床 NER 论文**。核心贡献是抓住中文特有的困难——**没有天然词边界**：先用 CRF 分别做分词和 NER，再用**对偶分解（dual decomposition）**把两个任务联合求解。语料为 336 份出院小结、71,355 词，同时标注分词与命名实体；联合模型使分词提升约 0.2%、NER 提升约 1%。据 [10] 的转述，该语料在 i2b2 式类别之外**增加了"人体部位"类型**，这正是后来 CCKS 五类/六类体系里"解剖部位"的由来。

**[6] A comprehensive study of named entity recognition in Chinese clinical text**（Lei Jianbo、Tang Buzhou、Lu Xueqin、Gao Kaihua、Jiang Min、Xu Hua，JAMIA 2014;21(5):808-814，**Epub 2013-12-17**）
中文临床 NER 领域引用最广的奠基论文，其实验设置常被后人直接沿用：

- **语料**：北京协和医院 800 份临床文书 = 400 份**入院记录** + 400 份**出院小结**，训练:测试 = 2:1。
- **实体四类**：clinical problem（临床问题）、procedure（操作）、laboratory test（实验室检验）、medication（药物）——这是把 i2b2 的 treatment 拆成 procedure/medication、把 test 收窄为 laboratory test 的中文改造。
- **方法**：CRF、SVM、最大熵（ME）、结构化 SVM（SSVM）四种主流序列/结构模型的横向比较，并研究词典、分词等中文特有特征的作用。
- **结果**：SSVM 最优，入院记录 F 值 93.51%、出院小结 90.01%。

**[7] Named Entity Recognition in Chinese Clinical Text Using Deep Neural Network**（Wu Yonghui、Jiang Min、Lei Jianbo、Xu Hua，MedInfo 2015）
同一支队伍把中文临床 NER 带入神经网络时代的转折点：用大规模无标注语料以无监督方式训练词向量，再用深度神经网络做 NER，**最小化特征工程**，效果超过基于人工特征的 CRF。这是"中文临床 NER 从特征工程转向表示学习"的起点。

**[8] Data-Driven Information Extraction from Chinese Electronic Medical Records**（Xu Dong 等，PLoS ONE 2015）
同期另一条路线：不追求实体分类体系，而是把中文病历自由文本转成**"时间—事件—描述"三元组**（描述是事件的细化或结局）。方法上是跨领域医学词表 + 无监督迭代扩词 + 中文书写习惯与时间词规则 + 用 Normalized Google Distance 度量事件与描述相关性的 SVM；在 24,817 份去标识中文病历上验证。它是中文侧最早把"事件 + 时间"作为抽取目标的成规模工作之一。

### 3. 2014—2017：中文自己的实体/修饰/关系定义成型（哈工大关毅组）

**[9] 杨锦锋、于秋滨、关毅、蒋志鹏《电子病历命名实体识别和实体关系抽取研究综述》（自动化学报 2014;40(8):1537-1562）**
中文领域第一篇系统梳理"实体识别—实体修饰识别—关系抽取"三段式任务的综述，逐条给出了 i2b2 2010 的实体与八类关系的中文定义（表 5），并整理了当时可用的评测、语料与词典资源。要理解"最早是怎么定义的"，这篇是最方便的中文入口。

**[10] 杨锦锋、关毅、何彬、曲春燕、于秋滨、刘雅欣、赵永杰《中文电子病历命名实体和实体关系语料库构建》（软件学报 2016;27(11):2725-2746）**
**中文电子病历实体关系定义的奠基文献**（2014-12 投稿、2015-08 录用、2016-11 刊出）。它在参考 i2b2 2010 的基础上做了明确的中文改造：

- **实体 5 类**：疾病、疾病诊断分类、症状（再细分为**自诉症状**与**异常检查结果**）、检查、治疗。把 i2b2 的 medical problem 拆成"疾病 + 症状"，并把症状按主观/客观再分，是最关键的中文化决定。
- **修饰**：疾病/症状 7 类（否认、非患者本人、当前、有条件、可能、待证实、偶有）；治疗 3 类（既往、否认、当前）。
- **关系 6 大类 20 个子类**：治疗—疾病（TrID/TrWD/TrCD/TrAD/TrNAD）、治疗—症状（TrIS/TrWS/TrCS/TrAS/TrNAS）、检查—疾病（TeRD/TeCD）、检查—症状（TeRS/TeAS）、疾病—症状（DIS）、疾病—诊断分类（DADt）。与 i2b2 的 Tr*/Te*/PIP 命名一一对应可见其血缘，但把"问题"细分为疾病与症状后关系数量翻倍。
- **只标注句内关系**；引入**"实体组"**概念（把同时出现的同类实体打包）以简化复杂关系表达。
- **规模与质量**：哈医大二院 35 个科室、87 个子科室的 992 份住院病历（出院小结 + 首次病程记录），39,733 个实体、2,735 个关系；标注一致性实体 F=0.922、关系 F=0.895。

（该组还有两篇中文期刊的前置工作常被引作更早的"标注规范"来源：蒋志鹏等《面向中文电子病历的词法与语料标注研究》高技术通讯 2014;24(6):609-615，以及曲春燕等 2015 年参照 i2b2 2010 制定中文标注规范的语料工作 [26]。本次检索未能取得这两篇的稳定可访问链接，故不列入参考文献，但溯源时应知其存在。）

**[11] Building a comprehensive syntactic and semantic corpus of Chinese clinical texts**（He Bin、Dong Bin、Guan Yi 等，JBI 2017，预印本 arXiv:1611.02091）
上一条工作的英文版兼扩展版，也是国际上可引的中文临床标注语料标准文献：句法语料 138 份文档、47,426 词、2,612 棵完整句法树；语义语料 992 份文档、**39,511 个实体 + 断言 + 7,693 个关系**；同时公布迭代式标注方法、标注指南与基于该语料训练的中文临床文本处理与信息抽取系统 CCTPIES。

**[12] Developing a cardiovascular disease risk factor annotated corpus of Chinese electronic medical records**（Su Jia、He Bin、Guan Yi 等，BMC MIDM 2017，预印本 arXiv:1611.09020）
把 i2b2 2014 心血管风险因素评测的思路搬到中文：标注风险因素及其**指标（indicator）、时间属性（temporal attribute）与断言**，并提出若干中文特有的标注规则（例如未达阈值的检查数值同样标注）。这是中文侧"面向具体疾病的事件式标注"的早期范例。

### 4. 2017—2020：评测把定义标准化（CCKS 系列）

**[13] HITSZ_CNER: A hybrid system for entity recognition from Chinese clinical text**（Hu Jianglu、Shi Xue、Liu Zengjian、Wang Xiaolong、Chen Qingcai、Tang Buzhou，CCKS 2017 Task 2）
CCKS-2017 任务二（中文电子病历命名实体识别）的代表性参赛系统。**CCKS 2017 把实体统一定义为五类：症状和体征、检查和检验、疾病和诊断、治疗、身体部位**，官方发布 300 份人工标注 + 400 份未标注病历，覆盖病史特点、出院情况、一般项目、诊疗过程四个部分。这套五类定义此后成为中文工业界与学术界事实上的默认体系。

**[14] Overview of CCKS 2018 Task 1: Named Entity Recognition in Chinese Electronic Medical Records**（Zhang Jiangtao、Li Juanzi、Jiao Zengtao、Yan Jun）
CCKS 2018 延续并调整了实体类别定义与数据规模，是 CCKS 系列官方任务综述里最早可正式引用的一篇。

**[15] Overview of the CCKS 2019 Knowledge Graph Evaluation Track: Entity, Relation, Event and QA**（Han Xianpei 等，arXiv:2003.03875）
CCKS 2019 把评测扩到 6 个任务，医疗侧首次把**实体—属性—关系—事件**并列为一个连续任务族，标志中文医疗信息抽取从"只做 NER"走向"实体+关系+事件"的完整结构化。

**[16] Overview of CCKS 2020 Task 3: Named Entity Recognition and Event Extraction in Chinese Electronic Medical Records**（Li Xia、Wen Qinghua、Lin Hu、Jiao Zengtao、Zhang Jiangtao，Data Intelligence 2021）
中文电子病历"**事件**"定义最正式的官方出处之一：任务分为子任务 1 医疗命名实体识别（疾病和诊断、影像检查、实验室检验、手术、药物、解剖部位六类）与子任务 2 医疗实体及**事件抽取**（以肿瘤事件为例，抽取原发部位、病灶大小、转移部位等事件属性/论元）。该届吸引 354 支队伍报名、46 支提交有效结果，预训练语言模型成为主流方案。

### 5. 2018—2022：方法主线的演进

**[17] Adversarial training based lattice LSTM for Chinese clinical named entity recognition**（Zhao Shan 等，JBI 2019）——用 lattice LSTM 把词典中的词信息注入字级别序列标注，正面回应中文"无词边界"这一从 [5] 起就存在的老问题，并用对抗训练提升跨语料鲁棒性。

**[18] Chinese clinical named entity recognition with variant neural structures based on BERT methods**（Li Xiangyang 等，JBI 2020）——系统比较 BERT 及其变体在中文临床 NER 上的多种接法，代表 2019 年之后中文临床 NER 的默认基线由 BiLSTM-CRF 转为 BERT 系。

### 6. 2020—2025：数据集、基准与事件/时间关系的再定义

**[19] CMeIE: Construction and Evaluation of Chinese Medical Information Extraction Dataset**（Guan Tongfeng、Zan Hongying、Zhou Xiabing、Xu Hongfei、Zhang Kunli，NLPCC 2020）——中文医学信息抽取（实体+关系三元组）的公开数据集，把关系抽取从"某一家医院的私有语料"变成可复现的公开任务。

**[20] CBLUE: A Chinese Biomedical Language Understanding Evaluation Benchmark**（Zhang Ningyu 等，ACL 2022，arXiv:2106.08087）——首个中文生物医学语言理解基准，把命名实体识别、信息抽取（含 CMeIE）、临床诊断归一化、句子/句对分类等任务与在线评测平台整合；报告了 11 个中文预训练模型的基线，并指出与人类上限仍有明显差距。中文医疗 IE 的"评测碎片化"时代到此收束。

**[21] A unified framework of medical information annotation and extraction for Chinese clinical text**（Zhu Enwei 等，Artificial Intelligence in Medicine 2023）——把实体、属性/修饰、关系重新统一到一套标注与抽取框架里，可视作 [10][11] 体系在深度学习时代的重述。

**[22] Extraction of risk factors for cardiovascular diseases from Chinese electronic medical records**（Su Jia 等，CMPB 2019）——[12] 语料的下游落地，验证"专病事件式标注 → 抽取系统"这条链路。

**[23] Temporal indexing of medical entity in Chinese clinical notes**（Liu Zengjian 等，BMC MIDM 2019）——中文侧对 i2b2 2012 那套 EVENT/TIMEX/TLINK 思路的正面回应：为每个医疗实体选定发生时间或时间区间，把所有实体索引到统一时间轴。

**[24] End-to-end Chinese clinical event extraction based on large language model**（An Bo 等，Scientific Reports 2025）——大模型时代的中文临床事件抽取，端到端替代"实体识别 + 论元分类"的流水线，是当前引用脉络的前沿一端。

```
      ├─→ Lei Jianbo 2014 [6]（4类实体，CRF/SVM/ME/SSVM 横评）
      │        └─→ Wu Yonghui 2015 [7]（词向量+DNN，去特征工程）
      │                    └─→ lattice LSTM [17] → BERT 系 [18] → LLM [24]
      ├─→ Xu Dong 2015 [8]（时间—事件—描述三元组）→ 时间轴索引 [23]
      │
      └─→ 评测标准化：CCKS 2017 五类 [13] → CCKS 2018 [14] → CCKS 2019 实体/关系/事件并列 [15]
                    → CCKS 2020 NER + 事件抽取 [16] → CMeIE 公开数据集 [19] → CBLUE 基准 [20]
```

一句话概括演进逻辑：**类别定义**从"3 类实体、无关系"（2011）→"4~5 类实体"（2014）→"5 类实体 + 修饰 + 20 类关系"（2016）→"5/6 类实体 + 事件论元"（CCKS 2017/2020）；**方法**从 CRF/SSVM（2011—2014）→ 词向量 + DNN（2015）→ lattice LSTM / BiLSTM-CRF（2018—2019）→ BERT 系（2020）→ 大模型端到端（2023 之后）；**资源**从各家私有语料 → 评测公开集 → CMeIE/CBLUE 统一基准。

## 五、溯源时的几点提醒

1. **"谁最早"要区分语种和范式。** 中文期刊上李毅等 2010 [3] 早于叶枫等 2011 [4]，但前者是规则/本体式抽取、没有实体类别体系；若问的是"标注语料 + 统计模型意义上的中文病历 NER"，叶枫等 2011 [4] 才是首次尝试。英文期刊上则以 Xu Yan 等（Epub 2013-08-09）[5] 最早，比常被当成"第一篇"的 Lei Jianbo 等（Epub 2013-12-17）[6] 早约四个月——只看 2014 年的卷期号会得出错误结论。
2. **关系抽取在中文侧晚于实体识别约 5 年。** 2011—2015 年的中文工作几乎只做实体；成体系的中文实体关系定义要到 2016 年 [10][11] 才出现，此前的"关系"要么直接沿用 i2b2 英文定义 [1]，要么以"时间—事件—描述"这类非标准形式出现 [8]。
3. **存疑条目**：Semantic Scholar 收录有一条 2010 年的《The Automatic Extraction of Temporal Relation from Chinese Narrative Medical Records Using Conditional Random Fields》[25]，若成立则会是中文病历"关系（时序关系）抽取"的更早起点；但本次检索未能在 PubMed、出版社或任何期刊页面上核到其出处、作者与卷期，**不建议在未核实前作为奠基文献引用**。
4. **两篇中文前置文献值得线下补核**：蒋志鹏等《面向中文电子病历的词法与语料标注研究》（高技术通讯 2014;24(6):609-615，见 [9] 参考文献第 125 条）与曲春燕等 2015 年参照 i2b2 2010 制定中文电子病历标注规范的工作（见中文综述 [26] 的转述）。二者是 [10] 的直接前身，但缺乏稳定的公开链接。
5. **中文综述可作二次核验入口**：[9]（2014，任务与定义）与 [26]（2021，方法演进）分别覆盖了本问题的前半段与后半段。
