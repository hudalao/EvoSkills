# 智慧城市公共摄像头与算法识别系统：隐私、偏见、问责的治理框架文献综述（2021年以来）

## 〇、总体判断

2021年以来，围绕"城市公共空间摄像头 + 算法识别（人脸、车牌、行为、情绪）"的治理研究，已经从"要不要用"的伦理表态，转向三条互相咬合的治理线：

1. **法域层的硬约束**：以欧盟《人工智能法》对远程生物识别的禁止与分级、GDPR/执法指令的数据保护要求、美国州法（如伊利诺伊 BIPA）与地方禁令、中国《个人信息保护法》及人脸识别专门规则为代表，核心争点是"禁止清单"划到哪里 [1][19][20][22][23][24][25]。
2. **机构层的问责工具**：算法影响评估、算法登记册、第三方与社会技术审计、人类监督条款、公共采购条款、公共部门问责制度设计 [26][27][28][14][29][21][32][33]。
3. **设计与参与层的可争议性**：把"可申诉、可解释、可退出、可被质疑"写进摄像头系统本身，以及让受影响社区进入采购与评估流程 [30][7][31][38][34]。

学界的主要分歧不在"有风险"，而在于：**风险是可以通过场景分级与程序性问责被驯服的（改良派 [2][22][5][34][35]），还是结构性的、需要以禁令与政治抵抗回应（批判派 [15][19][17][18]）**。

下文按"应用路径 → 风险点 → 法规/政策框架 → 问责工具箱 → 公众态度 → 学术争议 → 证据缺口"展开，正文中的编号对应文末参考文献。

## 一、应用场景与部署路径

城市摄像头 + 算法识别并非单一系统，治理讨论必须区分场景，因为法律定性（是否生物识别、是否远程实时识别、是否执法目的）和风险量级都随场景变化 [2]。2021年以来被实证研究覆盖较好的部署路径有六类：

| 场景 | 典型技术形态 | 代表研究 | 治理焦点 |
|---|---|---|---|
| 城市公共安全智能视频监控平台 | 目标检测、行为识别、异常检测、端到端 SVS 架构 | [3] | 个人可识别信息的采集/存储/最小化，隐私需求在系统设计阶段的落地 |
| 警务实时/事后人脸识别 | 布控名单比对、人工复核 | [14][22][16][38] | 合法性基础、必要性与比例、人工复核质量、社区协商 |
| 交通与行人管理 | 路口摄像头 + 算法信号控制 | [6] | "平淡无奇"的基础设施如何在无争议中改变公共空间与行为规范 |
| 市政执法扫描车（停车、市容） | 车载摄像头 + 车牌/物体识别 | [7] | 自动执法的可争议性、异议渠道与救济 |
| 车牌识别（ALPR） | 固定/移动车牌读取 | [9] | 从交通行政向刑事侦查的功能蔓延 |
| 街区级传感与行为干预 | 摄像头 + 声音 + 灯光"氛围助推" | [8] | 不指向个人身份的"氛围画像"与助推是否受数据保护法约束 |

从城市治理研究的视角看，这些部署共同构成了"城市人工智能（Urban AI）"的一部分：算法系统从辅助自动化走向对城市空间与行为的自主调节，因而必须被当作治理主体而非工具来讨论 [4]。地方政府层面的落地路径研究提出了较完整的"负责任城市创新"框架，把技术、组织能力、伦理评估、公众参与并列为前置条件 [5]；城市规划学界的综述则指出规划实务在偏见、透明、问责、隐私四个方面尚未建立职业标准 [18]。

**部署路径的经验教训**：把治理放在采购之前（采购条款是最早也最有效的闸门）[32]；把公众参与放在部署之前而非投诉之后 [38][31]；把可争议性放在界面与流程之中 [30][7]；把问责证据（日志、评估、登记）放在系统之内 [26][28]。

## 二、风险点

### 2.1 隐私：从"是否可识别"到"是否可影响"

- 智能视频监控系统天然大量采集个人可识别信息，隐私要求必须在架构设计期确定，而不是事后叠加；[3] 给出了公共安全场景下的隐私关切清单与端到端设计方案。
- 公众对"摄像头还会推断情绪/属性"普遍缺乏预期；实证研究显示，人们对视频分析的接受度高度依赖场景、通知方式与推断类型，而现实部署往往不告知 [11]。
- 更棘手的是不以身份识别为目的的"氛围画像 + 助推"：埃因霍温 Stratumseind 案例说明，以"可识别性"为触发条件的数据保护法可能整体落空，因为系统影响的是人群行为而非个人档案 [8]。

### 2.2 功能蔓延：治理失效最常见的形式

- 丹麦 ALPR 的研究显示，一项以交通治理名义引入的"平淡监控"，如何逐步扩展为常态化的警务数据基础设施 [9]。
- 荷兰公共摄像头的法律分析进一步指出，功能蔓延往往通过目的描述的模糊化与技术升级完成，现行法律对"同一摄像头新增算法能力"缺乏有效抓手 [10]。

### 2.3 偏见与准确性：技术指标之外的部署风险

- 人脸识别的人口统计学公平已有系统综述，梳理了误差在不同人群间的分布、成因（数据、图像质量、算法）与缓解手段的边界 [12]。
- 对城市级布控尤其关键的是"布控名单不平衡效应"：误识率不仅取决于算法本身，还随名单规模与名单人口构成变化——这意味着同一算法在小规模试点中的表现无法外推到城市级部署 [13]。
- 但把偏见完全当作技术问题会遗漏制度性风险：面向英国三次警方部署的社会技术审计发现，问题更多出在必要性论证、受影响社区咨询、人权合规与人工复核环节 [14]。
- 在数据保护与司法救济制度薄弱的地区，误识的后果被放大，因而有研究直接主张在全球南方城市实行禁令而非规制 [15]。

### 2.4 寒蝉效应与集会自由

公共空间的持续识别会改变人们出现在街头的方式。针对抗议场景的研究指出，实时人脸识别对集会自由的干预具有事前威慑性质，现行以"个案必要性"为中心的合法性审查难以捕捉这种整体性寒蝉效应 [16]。

### 2.5 问责断裂

- 公共部门 AI 的问责研究综述显示，学界对"问责"本身的概念界定分歧很大，导致政策工具彼此不可比 [33]。
- 最常被写进法律的补救措施——"人类监督"——在实证上并不可靠：监督者缺乏能力、时间与激励，甚至产生自动化偏见 [29]；有研究因此主张把人类监督重构为"制度化的不信任"，即通过分权、外部审查与民主控制来实现，而非依赖个体操作员 [21]。

### 2.6 权力结构与政治经济批判

监控研究把"智慧城市"视为一种可被威权化的治理形态，提出了系统的研究议程（技术输出、数据集中、抵抗形式）[17]；城市规划领域也提醒，算法系统可能固化既有的空间不平等并排除边缘社区 [18]。

## 三、法规与政策框架

### 3.1 欧盟：禁止清单、风险分级与执法例外

- 对《人工智能法》立法草案的批评意见集中在：远程生物识别的"实时/事后"区分与执法例外过宽，应当扩大禁止范围并对生物识别监控采取更严格立场 [19]。
- 执法场景下的人脸识别处于《人工智能法》、执法指令与 GDPR 的交叉地带，数据治理风险（数据来源合法性、比对库构建、跨部门共享）尚未被单一制度覆盖 [20]。
- 关于第14条式的人类监督义务，研究主张以民主设计（institutionalised distrust）取代对"人在回路"的形式化要求 [21]。

### 3.2 英国：判例驱动的增量规制

英国路径以 Bridges 案后的合法性框架为基础，主张通过"增量式"规则（授权基础、必要性测试、名单管理、独立监督）而非专门立法来约束执法机关的实时人脸识别 [22]；配套的社会技术审计工具则把这些法律标准转化为可核查的清单 [14]。

### 3.3 美国：州法与地方条例的双轨

- 伊利诺伊 BIPA 的适用研究揭示了法律概念（"生物识别标识符""同意"）与技术现实（特征模板、迁移学习、公开数据集）之间的张力，这是判断城市摄像头系统合规与否的核心难点 [23]。
- 地方层面的禁令与监控条例，则依赖社区倡导者的技术审查能力；面向社区的政策工具包把"这是不是AI/监控系统""它的可问责点在哪里"变成可操作流程 [31]。

### 3.4 中国：适应性治理与个人信息保护法

- 有研究把中国对人脸识别的治理刻画为"适应性治理的政策设计"：在鼓励应用的同时，通过司法解释、行业标准与专门规章逐步收紧公共场所应用边界，形成工具组合而非单一禁令 [24]。
- 制度底座是《个人信息保护法》对敏感个人信息、单独同意与最小必要的规定，其对城市数据实践的影响已有系统梳理 [25]。（说明：2025年6月起施行的《人脸识别技术应用安全管理办法》属于法规文本而非学术论文，故不列入文末文献表；截至检索时点，针对该办法实施效果的实证研究尚未出现。）

### 3.5 全球南方与跨国比较

- 面向全球南方的研究强调，在缺乏数据保护执法与司法救济的语境中，"先部署后规制"的路径不可逆，因而主张暂停或禁令 [15]。
- 跨法域比较研究提出了分层治理模型（自律—软法—硬法—技术标准）并比较美、欧、英三地的落差 [1]；另有欧洲项目成果面向市政决策者，给出"城市安全技术民主使用"的范围界定与操作指引（需求论证、透明公开、参与、评估与退出机制）[35]。

## 四、问责工具箱（可落地的治理机制）

| 工具 | 作用点 | 代表文献 | 已知局限 |
|---|---|---|---|
| 算法影响评估（AIA） | 部署前识别影响、确定救济对象 | [26][27] | "影响"由评估制度本身共同建构，可能遗漏未被表达的伤害；需明确合法性来源、评估者、公众参与与救济 |
| 算法登记册 | 常态化透明、供外部监督者复用 | [28] | 易沦为打钩：只登记政治上不敏感的系统、信息颗粒度不足以支撑问责 |
| 社会技术审计 / 第三方审计 | 把法律与伦理标准转成可核查项 | [14] | 依赖数据可得性与机构配合，难以覆盖人工复核的真实行为 |
| 社区审计与倡导工具包 | 把地方政治过程纳入治理 | [31] | 需要持续的能力建设与信息公开 |
| 人类监督条款 | 法定救济 | [29][21] | 个体监督不可靠，应转向制度化不信任与外部审查 |
| 可争议性设计 | 事中/事后异议与救济 | [30][7] | 目前多为框架与思辨设计，缺少大规模落地评估 |
| 公共采购条款 | 最早的闸门 | [32] | 采购方能力不足、供应商信息不对称 |
| 市民中心的数据治理 | 城市级数据权责安排 | [34][5] | 从伦理原则到问责机制的转化仍是难点 |
| 公共部门问责制度设计 | 概念与责任链 | [33] | 学界对"问责"定义分歧，导致工具不可比 |

一个务实的组合是：**采购条款 [32] → 部署前 AIA 与必要性论证 [26][27] → 公开登记 [28] → 运行期社会技术审计 [14] → 面向个人的可争议性与救济 [30][7] → 面向社区的参与与复审 [31][38]**，并把人类监督定位为制度安排而非个人职责 [29][21]。

## 五、公众态度与正当性

- 四国（中国、德国、英国、美国）比较调查显示，人脸识别的接受度存在显著跨国差异（中国最高、德国最低），且受感知有用性、可靠性与后果判断影响，说明"公众接受"高度依赖制度语境 [36]。
- 美国警务场景的证据表明，对警察机构的制度性信任是公众态度的关键变量，即技术评价在很大程度上是机构评价的投射 [37]。
- 因此，若把"公众支持率"直接当作正当性依据，会掩盖信任的来源问题；共构式政策制定（公众参与警方对 FRT 的采购、使用与效果评估）被提出为更稳健的正当性来源 [38]。
- 城市数据治理研究也把"市民中心"从口号推进到问责结构：谁代表市民、以什么程序审议、争议如何裁决 [34]；维也纳智能行人信号灯的案例则显示，越是"平淡无奇"的城市 AI，越容易在缺乏公共讨论的情况下改变公共空间规范 [6]。

## 六、学术争议（对立观点整理）

1. **禁令 vs 场景化风险规制**：主张禁止公共空间远程生物识别或在制度薄弱地区全面禁用 [19][15]；主张按使用场景分级、以风险—收益权衡替代一刀切 [2]，以及以判例驱动的增量规制 [22]。
2. **程序性问责是否有效**：AIA 与登记册被视为把伤害制度化处理的关键 [26][27]；实证研究则显示它们容易退化为形式合规 [28]，且"影响"的定义权掌握在被评估者手中 [26]。
3. **人类监督能否成立**：法律普遍写入人类监督 [20]；批评者认为这是"责任洗白"，应转向机构化监督与民主控制 [29][21]。
4. **技术改进能否解决偏见**：公平性研究给出可度量的改进路径 [12]，但布控名单效应说明部署规模会重新引入风险 [13]，社会技术审计与全球南方研究则强调制度与权力条件才是决定性的 [14][15]。
5. **智慧城市：改良还是结构批判**：负责任创新、市民中心数据治理与民主化城市安全技术指南属改良路线 [5][34][35]；威权智慧城市议程与规划伦理研究则质疑改良能否触及权力结构 [17][18][4]。
6. **公众接受度的意义**：接受度调查提示可行性 [36][37]，参与式路径研究则主张正当性必须来自过程而非满意度 [38][31]。

## 七、证据缺口（供后续检索参考）

- **实施后评估稀缺**：城市级部署的因果效果（犯罪率、误识数量、申诉与纠错率）几乎没有多点、可复制的评估；[14] 的审计是少数把真实部署与法律标准对齐的尝试。
- **中国最新规则的实证研究空白**：2025年施行的人脸识别专门规章尚无学术评估，现有文献止步于政策设计与 PIPL 层面 [24][25]。
- **中文期刊文献可引用性受限**：本次检索的学术数据库对中文核心期刊覆盖不足，网络检索命中的多为法规解读与律所评论，无法满足论文级引用要求，故文献表以英文文献为主。
- **建筑工地与灾害场景的治理研究薄弱**：施工现场计算机视觉与灾害应急视频分析的文献以技术方案为主，涉及工人隐私、算法问责的治理研究极少，是明显的空白区。
- **可争议性与参与机制缺少长期落地证据**：[30][7][31] 多为框架、思辨设计或工具包，缺乏多年期的制度运行数据。
