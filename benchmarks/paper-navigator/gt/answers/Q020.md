# 大模型与强化学习在智能电网调度、储能优化、新能源消纳中的最新综述与代表论文（2024–2026）

## 0. 结论速览

这个方向在 2024 年之后已经形成了两条独立成熟、并且开始交汇的文献线：

- **强化学习（RL/DRL）线**已经进入"综述收敛期"。安全强化学习（safe RL）成为公认的主线问题，2024–2026 年出现了 3 篇高水平综述（Proceedings of the IEEE [14]、Renewable & Sustainable Energy Reviews [15]、Engineering Applications of AI [16]）和一部体系化的长篇综述专著 [17]；此外还有电压控制 [21]、系统韧性 [22]、图强化学习 [19]、电网拓扑控制 [20] 四个细分方向的专门综述。
- **大模型（LLM/基础模型）线**从 2024 年 Joule 那篇"能力与局限"评估文章 [1] 起步，2025–2026 年密集出现综述与路线图（Applied Energy [2]、MPCE [3]、IEEE Access [5]、Energy Reports [6]、SEGAN 多模态 [8]、Nature 系 Communications Engineering [12]），并已从"问答/文档"阶段推进到"调度智能体（agent）"阶段 [10][11][45][49]。
- **两条线的交汇（LLM×RL）是当前最新、最值得关注的增量**：LLM 承担奖励设计、语义约束翻译、经验检索与日前粗调度，RL 负责日内精细连续控制，代表工作集中在 IEEE TPWRS/TSG/TII，2024 年起步、2026 年出现完整的两阶段协同框架 [40][41][42][43][44]。
- **评测（benchmark）是这个领域目前最明显的短板**：RL 侧有 Grid2Op/L2RPN 谱系 [53] 与 2025 年的 RL2Grid [52]、OPF 环境设计研究 [54]；LLM 侧有 ElecBench [50][51]、ProOPF [55]、Power Systems Agent Benchmark [56]、PowerAgentBench-SS [57]。但两侧互不相通，且"新能源消纳率/弃风弃光率"这一中国语境下的核心指标尚未进入任何公开 benchmark。

检索时间窗以 2024 年 1 月至 2026 年 8 月为主，个别奠基性 benchmark（Grid2Op/L2RPN）为提供谱系背景而保留 2021 年文献并单独标注。

## 2. 代表性论文（按主题分类）

### 2.1 智能电网调度：RL 求解 ED / SCOPF / UC

- **大电网实时安全约束经济调度**：Knowledge-Augmented Population-Based DRL [26]（2025, IEEE TPWRS）。用参数空间扰动构造种群做探索、聚合个体结果构造代理梯度，配合"顺序安全投影（S2P）"技术；在 **39 节点、500 节点、2383 节点**三个规模上验证，报告在最优性、决策安全性、计算性能与规模适应性上均优于 SOTA DRL 方法。这是目前把 DRL 推到最大电网规模的代表性工作。
- **实时序贯安全约束最优潮流**：Hybrid Knowledge-Data-Driven RL [27]（2024, IEEE TPWRS，约 48 次引用）。改进 SAC + 知识-数据混合安全层，把不安全动作投影回安全域，并用"非起作用约束识别"加速安全层计算。
- **物理信息强化学习求解实时 OPF**：[28]（2025, IEEE TSTE，约 43 次引用）。基于潮流方程设计"物理信息 actor"直接满足等式约束，不等式约束通过策略梯度增广修正——是 RL-OPF 里可行性保障做得较扎实的一篇。
- **前瞻式经济调度**：Adaptive look-ahead economic dispatch based on DRL [29]（2024, Applied Energy）。
- **虚拟电厂无模型经济调度**：Adversarial Safe RL [30]（2024, IEEE TPWRS）。两阶段框架——先在仿真器预训练、再在真实环境微调；对抗训练提升训练/测试环境偏差下的鲁棒性。
- **储能参与的实时 SCED 的安全策略学习**：[31]（2025, IEEE TPWRS）。专门处理"单步约束 + 时间耦合约束（储能 SOC）"同时满足的难题，提出安全探索 + 安全优化双模块，并用残差网络策略直接输出各类可控资源的实值出力。
- **真实电网工程落地**：Demonstrating Safe DRL Based Coordinated Frequency Control in East China Power Grid [32]（2026, IEEE PES IM）。显式加入联络线潮流与运行极限的安全约束，**用华东电网真实数据验证**。这类"真实大电网现场验证"的论文极少，是判断技术成熟度的关键锚点。

### 2.2 储能优化

- **算法横向对比与实验设计的影响**：Deep reinforcement learning for economic battery dispatch: A comprehensive comparison of algorithms and experiment design choices [33]（2025, Journal of Energy Storage）。这是储能 RL 方向少有的系统性 head-to-head 对比研究，同时指出实验设计选择本身对结论影响很大——做基线对比时应优先参考。
- **多时间尺度水风光储协同**：Long-Term and Short-Term Coordinated Scheduling for Wind-PV-Hydro-Storage Hybrid Energy System [34]（2025, IEEE TSTE，约 30 次引用）。把长期调度建模为 MDP，每个 MDP 步内嵌短期混合整数线性规划模型，形成"数据-模型混合驱动"；在真实水风光储系统上验证，报告在弃电量削减上显著优于传统场景削减法与鲁棒优化。
- **考虑预测误差的风储联合调度**：Forecasting error-aware optimal dispatch of wind-storage integrated power systems (SAC-DRL) [35]（2025, Energy）。
- 综述层面对应 [23][24]。

### 2.3 新能源消纳与电压/无功

- **消纳与电压波动的权衡**：Deep Reinforcement Learning for Voltage Control and Renewable Accommodation Using Spatial-Temporal Graph Information [36]（2024, IEEE TSTE）。这是直接把"renewable accommodation（消纳）"写进标题与目标函数的代表作：用多粒度注意力时空图卷积网络（MG-ASTGCN）提取配网时空关联，DDPG 动态平衡"电压波动抑制 vs. 新能源消纳"；在修改的 **IEEE 33/69/118 节点**辐射状配网上显著优于基于优化的基准。
- **逆变器主动电压控制的图多智能体 RL**：[37]（2024, IEEE TSG，约 53 次引用）。把 AVC 建模为 Dec-POMDP，每个可控设备一个智能体，用 GCN 聚合相邻智能体信息，目标是电压合格 + 网损下降。
- **不确定性下的微网多目标区间优化调度**：[38]（2024, IEEE TSG，约 62 次引用）。风光出力用区间变量刻画，提出 TCSAC（三评论家综合经验回放 SAC），在改进 IEEE 118 节点微网验证。
- **领域知识嵌入的约束强化学习**：Domain knowledge embedded constrained reinforcement learning for scheduling of renewable energy power system [39]（2026, Applied Energy）。最新的"知识 + 约束 RL"用于新能源电力系统调度。

### 2.4 大模型 × 强化学习融合（最新增量所在）

- **语言化并网规程直接进 OPF**：Real-Time Optimal Power Flow With Linguistic Stipulations: Integrating GPT-Agent and Deep Reinforcement Learning [40]（2024, IEEE TPWRS，约 61 次引用）。首次把传统上无法量化的自然语言规程（Grid Code）建成 OPF 的目标与约束：GPT 智能体把"规程满足程度"解释为奖励与约束，非可微奖励通过原始-对偶 DRL 训练环路优化。这是 LLM×RL 在电力领域最早、也是被引最高的代表作。
- **LLM 代人设计安全惩罚函数**：RL2: Reinforce Large Language Model to Assist Safe Reinforcement Learning for Energy Management of Active Distribution Networks [41]（2024, IEEE TSG）。抓住的痛点很实际——safe RL 的惩罚函数设计需要同时懂 RL 和电力运行，新入场的配网运营商不具备，因此让 LLM 来生成/调整惩罚函数。
- **两阶段 LLM-RL 协同电压控制**：Two-Stage Active Distribution Network Voltage Control via LLM-RL Collaboration [42]（2026, IEEE TSG）。日前阶段 LLM 智能体接收区域级粗预测，生成有载调压变压器（OLTC）与并联电容器（SC）的调度策略；日内阶段 RL 智能体基于节点级精确量测，输出光伏逆变器无功策略。框架之上还配了 LLM 的自演化机制与 RL 的预训练-微调流水线。这是目前"LLM 管慢变量、RL 管快变量"这一范式最完整的实例。
- **LLM 辅助 DRL 做综合能源系统能碳协同优化**：[43]（2025, IEEE TII）。用 LLM 的推理与分析能力，通过交互式迭代与反馈环路去优化 DRL 算法本身。
- **LLM 直接充当调度员**：Large Language Model as An Operator: An Experience-Driven Solution for Distribution Network Voltage Control [44]（2025, arXiv）。经验存储/检索/生成/修改四模块协同，实现调度策略的自演化，面向信息不完备场景。

### 2.5 大模型调度智能体与系统

- **GAIA**：A large language model for advanced power dispatch [45]（2025, Scientific Reports，约 82 次引用）。面向调度业务微调的电力大模型，覆盖运行调整、运行监视、黑启动等任务，配套提出了多源数据构造微调数据集的方法与专用提示策略。是"电力垂域大模型"最常被引的落地样本。
- **自动建模与优化**：Large Language Model Powered Automated Modeling and Optimization of Active Distribution Network Dispatch Problems [46]（2025, IEEE TSG）。多 LLM 协同架构：Information Extractor / Problem Formulator / Code Programmer 分别负责信息抽取、优化问题建模、代码实现，让不具备电力优化专业能力的配网运营主体用自然语言直接得到调度策略。
- **多智能体 + 反馈驱动做电力仿真**：Enhancing LLMs for Power System Simulations: A Feedback-Driven Multi-Agent Framework [47]（2024, IEEE TSG）。增强 RAG + 改进推理 + 带错误反馈的动态环境行动三模块；在 Daline 与 MATPOWER 的 **69 个任务**上分别取得 **93.13% 与 96.85% 的成功率**——这是该方向少数给出硬性成功率指标的工作。
- **PowerGraph-LLM** [48]（2025, IEEE TPWRS）：首个显式用 LLM 求解 OPF 的框架，把电网的图表示与表格表示结合起来查询 LLM，并给出面向 OPF 的上下文学习与微调协议。
- **调度智能体框架综述式论文**：Large Language Model-based power dispatch agent: Framework, application and challenges [49]（2026, IJEPES）。

## 3. Benchmark 与评测（这一节是判断 SOTA 的关键）

### LLM 侧

| Benchmark | 出处 | 评测内容与规模 |
|---|---|---|
| **ElecBench** [50][51] | 2024 arXiv / 2025 Engineering Applications of AI | 电力调度领域最早也是被引最多的 LLM 评测基准。把场景分为通用知识与专业业务两层，定义 **6 项核心指标（真实性 factuality、逻辑性 logicality、稳定性 stability、安全性 security、公平性 fairness、表达力 expressiveness）并细分为 24 个子指标**，测试集公开 |
| **ProOPF（ProOPF-D + ProOPF-B）** [55] | 2026, arXiv | 面向"专业级 OPF 优化建模"的数据集与基准：ProOPF-D 含 **12K** 条自然语言请求-参数调整/结构扩展配对实例及可执行实现；ProOPF-B 含 **121 个专家标注测试样例**及标准答案代码，支持具体与抽象两种建模模式的端到端评测 |
| **Power Systems Agent Benchmark** [56] | 2026, arXiv | 可执行式评测：智能体接收结构化任务、返回结构化解，由确定性评测器重算工程量、校验运行约束，返回可行性标志、归一化得分与显式违约列表。含 **41 个任务族、覆盖 8 个电力工程领域**（潮流、保护、稳定、微网、可靠性、电能质量、预测等）；用私有种子按需生成留出样例以抗数据污染 |
| **PowerAgentBench-SS** [57] | 2026, arXiv | 面向稳态研究的工具使用型智能体基准。定义智能体接口、工具契约、证据日志与风险敏感指标（submitted recall、evidence-backed recall、found recall、false-safe penalty、severity regret、residual violation score、action cost、tool-use efficiency）；以 IEEE 39 节点确定性运行点变体上的 **DC 热稳 N-2 故障筛查**为试点实例化 |

| Benchmark | 出处 | 说明 |

## 4. 关键指标速查（可直接引用的量化结果）

- 多智能体 LLM 仿真框架在 Daline / MATPOWER 69 个任务上成功率 **93.13% / 96.85%** [47]。
- 分布式强化学习框架使电网扰动降低 **40%**、运行成本降低 **12.2%**（综述汇总口径）[23]。
- 大规模实时 NCED 的 DRL 已验证到 **2383 节点**量级，且在最优性/安全性/计算性能上优于 SOTA DRL [26]。
- 新能源消纳类工作的标准算例仍是 **IEEE 33 / 69 / 118 节点**配网 [36] 与 IEEE 118 节点微网 [38]。
- LLM 评测的通用指标体系目前是 ElecBench 的 **6 大类 24 子项** [50][51]；智能体评测已转向"可执行式 + 风险敏感"指标 [56][57]。
- 安全强化学习综述被引量级：Proceedings of the IEEE 约 73 次 [14]、RSER 约 57 次 [15]；LLM 侧被引量级：Joule 约 151 次 [1]、GAIA 约 82 次 [45]。

## 5. 研究空白（gap analysis）

1. **评测碎片化，缺少统一 SOTA 排行榜。** LLM 侧（ElecBench / ProOPF / PSAB / PowerAgentBench-SS [50][51][55][56][57]）与 RL 侧（Grid2Op-L2RPN / RL2Grid / OPF-Gym [52][53][54]）各成体系、互不相通；LLM×RL 融合方法目前**没有任何统一基准**可比。多数方法论文仍在自建算例上自证，横向可比性差 [20][33]。
2. **"新能源消纳"指标未国际标准化。** 弃风弃光率、消纳率是中国新型电力系统的核心 KPI，但没有任何一个公开 benchmark 把它作为一等评价指标；[36] 这类工作只能在自定义算例上报告改善幅度。
3. **安全性只有工程手段、缺理论保证。** 三篇 safe RL 综述 [14][15][16] 一致指出：硬约束满足、时间耦合约束（储能 SOC）[31]、N-1/N-2 安全域仍缺可证明的保证，现有方案要么用安全层逐步修正（易得次优的边界动作、可能违反时间耦合约束），要么用安全评估模型（可能违反单步约束）。
4. **泛化与拓扑迁移未解决。** 图强化学习综述给出明确判断：当前仍主要是概念验证，尚不可部署到真实系统 [19]；拓扑变化、规模迁移、N-1 后网架变化下的策略泛化是公开难题 [20]。
5. **真实电网现场验证案例极少。** 全库中用真实大电网数据做闭环验证的公开工作寥寥（华东电网协调频率控制 [32] 是少数样本），这与综述中"迈向部署"的乐观叙述存在明显落差 [10][12]。
6. **LLM 的物理一致性与幻觉问题未解决，闭环控制罕见。** LLM 目前主要占据"建模 / 接口 / 解释 / 代码生成"层 [46][48][49]，直接做闭环实时控制的公开工作极少；数值精度、潮流可行性、代码正确性仍依赖 validation-in-the-loop 与确定性评测器兜底 [55][56]。领域数据稀缺、关键基础设施上的可靠性与可解释性被多篇综述同时列为首要障碍 [4][5]。
7. **LLM×RL 融合仍处早期。** 已出现的范式集中在 LLM 做奖励/惩罚函数设计 [41]、语义约束翻译 [40]、经验检索与自演化 [44]、日前粗调度 [42]，但缺乏大规模消融实验与跨方法对比；[25] 的四角色分类法尚未在电力场景被完整实证覆盖。
8. **储能方向的结论稳健性存疑。** [33] 的系统对比表明，算法选择之外，**实验设计选择本身**就足以左右结论；退化建模与经济调度的耦合、多重收益叠加（multi-use）场景下的策略学习仍缺公认做法 [23][24]。
9. **跨时间尺度耦合仍是瓶颈。** 长期（年/月）运行规则与短期（日内/实时）调节能力的相互制约，目前只有少数"数据-模型混合驱动"方案 [34]；多时间尺度统一学习框架尚未成型。
