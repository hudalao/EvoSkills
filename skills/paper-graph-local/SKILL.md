# 论文脉络图（Paper Graph）
把一个研究方向的代表性论文整理成「挑战→解决方案」图谱，再逐方案画出按时间排列的演化时间线。所有论文检索与精读都委托 `paper-navigator-expert`，本技能自身不搜论文。

```
对准意图与目标 → 文献接地(paper-navigator-expert) → 相关性分档 → 挑战-方案图谱
        → 逐方案演化链 → 逐边证据自审 → 装配报告（时间线+附录） → 追问迭代
```

## 何时使用
- 了解某方向/主题的发展历史、演化脉络、「家族树」、引用树、文献分类法
- 某篇论文「从哪来」（建立在什么之上）或「到哪去」（重要后续改进）
- 看一条研究线索跨多年的成熟过程与思想传承

不适用于：资源清单盘点（数据集/基准/工具罗列）、只找一篇「最新/最好」的论文、简单关键词检索、两个具体模型的一对一对比、单篇论文的摘要式解读、非学术引用工作、只要参考文献列表而非图谱。

## 呈现纪律（务必遵守 · 面向手机用户 · 生产环境无文件系统）
第 1–6 步是**给你（agent）的内部规程**，非念给用户的脚本。中间产物（登记表全表、逐篇分档理由、拓扑论证、逐边自审明细）在**思考模式**里推演即可，**不写文件、不整段输出给用户**。用户在手机端，每次对外输出尽量一屏内。

**能力边界**：本技能只产出脉络综述文本——**不执行代码、不跑实验、不读外部代码/文件**（论文检索只经 paper-navigator-expert）。不假称检索了未检索的内容，不用记忆里的「名作」冒充检索结果。

**只在这 3 个点向用户输出**，其余全部静默执行：
1. **对准方向**（第 1 步）：推断目标并判定意图形态——**推得出直接做**：开头嵌半句点明方向+纠偏尾（如「围绕X的发展脉络（理解偏了随时纠）——」），不成段复述、不玩「方向对再展开」这类假等待；**推不出才问一句**（给闭合选项），不猜默认。
2. **文献信号 + 图谱总览**（第 4 步末）：2–3 句检索结果（几篇可用+覆盖情况）、核心论文单（每篇一行）、挑战→方案总览。
3. **脉络报告**（第 6 步）：逐方案时间线 → 未解问题汇总 → 图例 → 论文附录。

**用词纪律**：对用户**不出现内部术语**（「CORE/ADJACENT/REJECT」「登记表」「审计」「第 X 步」零价值），一律翻成人话（核心文献/相关背景/已排除、证据核查等）；不旁白进度、直接给结果。中间过程用户随时可索取，按需展开，不预先倾倒。

**手机排版**：表格 ≤3 列；时间线用第 6 步的固定等宽样式；论文标题保留英文原文，其余跟随用户语言（默认中文）。

## 意图分型（对准方向时判定，决定树根与时间线方向）
判不准按整域脉络走：
- **整域脉络**（默认；"X 的发展历史/脉络/家族树"）：标准全流程。
- **种子溯源**（给出具体论文，问"从哪来/基于什么"）：以种子论文为**终点**向前追溯思想来源；检索短语围绕种子的标题与机制构造。
- **后续追踪**（"X 之后有什么改进/后续"）：以种子论文为**起点**向后；优先收集晚于种子的工作。
- **来龙去脉**（两者都要）：前后各一条时间线，种子居中。
- 覆盖不足时按「降级阶梯」处理，不硬撑全流程。

## 第 1 步：解析问题与对准
- 提炼**研究目标一句话**；判定意图分型。
- 构造 **2–4 组检索短语**，每组 2–5 个关键词，各覆盖目标的不同侧面，但每组都含同一个**领域锚词**（防跑题）；用规范学术表述，不照搬用户口语。
- 为 **2–5 个关键术语**各拟一句话定义（思考中完成）：缩写、跨领域同名等歧义术语先定义再检索，后续图谱与演化叙述沿用该定义。
- 问题含种子论文（标题/arXiv 号/链接）：定位确认交给第 2 步的 paper-navigator-expert，研究目标与检索短语以**该论文的标题和摘要**为准，不得偷换成别的论文；定位失败则明说，转整域模式继续。
- 对外输出第 1 点（半句+纠偏尾），随即继续，不等待。

## 第 2 步：文献接地（经由 paper-navigator-expert）
**必须**调用 `SkillLoad(path=references/paper-navigator-expert, skillName=paper-navigator-expert)` 收集论文，默认 10 篇（6–15，用户点名照办）。不要跳过此步，也不要用通用知识替代——脉络必须扎根于真实检索结果。

每篇要拿到：标题、年份、一作、出处、摘要（或等效要点）。**种子论文与各线年份最新的论文**尽量额外拿到其**结论/讨论/局限/未来工作**段落的原文要点（≤150 字）——这是「未解问题」与高等级证据的唯一来源；拿不到就留空，后续自审会自动更保守，**不要用记忆补**。

**池子要求**（向 paper-navigator-expert 明确提出）：①各检索短语的结果**均衡纳入**，不让单一侧面霸榜；②**剔除论文集/纪要整卷条目**（如标题含 Proceedings 的整卷记录，非单篇论文）。

**登记纪律**（内部）：按获取顺序编号 (N)，一经分配**不变、不复用**，后续新增接续编号；同一论文多来源只记一次（按标题归一去重）。**编号是全程唯一合法引用**：登记之外的论文、作者、结论一律视为不存在——包括你记忆中的著名工作。

## 第 3 步：相关性分档（静默）
逐篇标注三档之一（内部术语，对用户翻译成人话）：
- **CORE**：直接推进、扩展、反驳该研究线，或是其奠基工作。进入图谱。
- **ADJACENT**：把主题当现成工具用于下游任务，或处于相邻方向。仅作背景，不进图。
- **REJECT**：离题、检索误中。排除。

判定规则：解决同一问题的并行/后继方法同样是 CORE，**不要求引用种子论文**；只「用到」主题而未推进主题本身 → ADJACENT；仅表面关键词相同 → REJECT。**拿不准宁可 REJECT**——错留一篇会在演化链阶段诱发编造的边，删多了只是图小一点。每档都要能在心中落到摘要的具体证据。

处置：只有 CORE 进入图谱与演化链；附录全列并按人话标注。CORE 为空 → 全部按 CORE 处理并在报告开头一句说明。CORE 少于 4 篇 → 先回第 2 步换角度补检索一轮并重新分档；仍不足走降级阶梯。

## 第 4 步：挑战→方案图谱
- 围绕第 1 步的研究目标，从 CORE 论文识别 **2–5 个核心研究挑战**（CORE 不足 5 篇时允许 1–2 个）；每挑战归纳 **1–3 个彼此不同的解决方案策略**；把论文编号映射到方案。
- 规模：每方案 **2–5 篇**为宜——1 篇允许但时间线退化为单节点；6 篇以上说明划分太宽，拆分。
- 每篇 CORE 尽量归入至少一个方案；可多归属，但演化链阶段以**主归属**为准（避免同一篇在多条链里重复叙事）；实在离题的不硬塞（附录仍列）。
- 命名必须**具体且可从摘要溯源**：单看名字能判断是哪个领域的什么问题/什么路线；禁「方法改进」「多种途径」这类空泛名；中文命名、术语保留英文；不用引号。
- 自检（不合格就地重做一次）：≥1 挑战、每挑战 ≥1 方案？编号全在 CORE 集内？命名足够具体？重做仍不合格 → 回第 2 步换检索短语补一轮或降低论文数。

**对外输出第 2 点**：①检索信号 2–3 句（几篇可用+主要覆盖面/空白）；②核心论文单，每篇一行 `(3) Sparse Transformer · 2019 · Child et al.`，末行一句交代其余（「另有相关背景 2 篇、已排除 1 篇，见文末附录」）；③图谱总览两层列表：

> **挑战 1：长序列下的二次计算开销**
> - 方案 1.1：稀疏/线性注意力 —— (3)(5)(8)

## 第 5 步：演化链与证据自审（静默）
紧扣第 1 步的研究目标，对每个方案独立执行；**只能引用本方案的编号，跨方案借用=幻觉**。

**先在思考中做拓扑论证，再定稿**：
1. 判断拓扑：这些论文是**谱系**（后作建立在前作的具体机制上）还是**平铺**（相互独立的路径）？
2. 每条候选边 (M)→(N) 过**双端测试**，两端都指认得出才保留：M 的摘要明确缺少/受困于 X；N 的摘要明确引入解决 X 的机制。N 只是与 M 大体相关、未针对其具体机制改进 → 不连边，N 作为独立起点。
3. 每方案 **≥1 个起点**（无前驱）；**全平铺是完全合格的结果，且永远优于强行编链**；边只能从早指向晚，同年且无法分辨先后 → 不连边、并列起点。
4. 有前驱的论文用一句话写清转变：「(M) 受限于 X，(N) 引入 Y 解决」。
5. **未解问题**（每方案 0–2 条）：优先落在相关论文**结论要点的原文**；无结论要点时，仅当其**摘要明确把该问题表述为未解决**才可用。摘要用贡献动词（我们提出/引入/实现/达到）描述的是**该文贡献而非未解问题**——放弃该条。弃永远优于编。
6. **共同主题**（每方案 0–2 条，可选）：多篇共享的方法学主题，必须挂 ≥2 个本方案编号；挂不上具体论文的「领域大趋势」不许写（无孤儿）。

**逐边对抗自审**（全部方案定稿后执行）：你在审自己刚画的边，自审天然偏宽——按字面规则逐边独立执行，**先试图推翻**，推翻失败才维持，不因「整条链看着通顺」放行单边。每边定一级：
- **摘要支持**：两端证据都在摘要中明确（或清楚隐含）。
- **章节支持**：至少一端证据来自结论要点而非摘要，但具体明确。
- **推断**：说得通，但至少一端没有明文依据。保留为弱支持边。
- **拒绝**：材料与所称差距矛盾（如 M 其实已解决 X，或 N 并未处理 X）。

拿不准 → 推断；发现矛盾 → 拒绝。处置：拒绝 → 删边、目标论文转独立起点（论文保留）；推断 → 保留、呈现时句末标 **[推断]**；两级支持 → 保留不标。未解问题按同规则复查：仅推测 → 标 [推断]；实为贡献或矛盾 → 删。

## 第 6 步：装配报告
**对外输出第 3 点**，固定顺序：逐方案时间线 → 未解问题汇总 → 图例 → 论文附录。

时间线每方案一个等宽代码块，固定样式：

```
方案 1.1：稀疏/线性注意力
  (3) Sparse Transformer · 2019
   ↓ 突破：固定稀疏模式降低计算量
  (5) Reformer · 2020
   ↓ 突破：LSH 分桶自适应稀疏 [推断]
  (8) Performer · 2020
   ⌛ 未解：随机特征近似的方差控制
```

- 节点行 `(N) 短题名 · 年份`：短题名 ≤24 字符、可用通行缩写、须与附录对得上。
- 边行 `↓ 突破：一句话`（≤30 字，写「补足了什么」）；[推断] 紧跟句末。未解行 `⌛ 未解：一句话`，跟在相关论文节点后。
- 任何行 ≤30 个全角字符，宁可换行不横向溢出。起点即链首不加标注；孤立节点单行列出。
- 全平铺方案：首行写 `方案 x.y：……（并行探索，无先后依赖）`，逐行列节点。
- 分支（一篇派生多条线）：父节点后各子链以 `├` `└` 引出并缩进。
- 共同主题不进时间线，写在该方案代码块后单独一行：`共同主题：……（(3)(5)）`。
- **未解问题汇总**：跨方案合并同类项，每条 `- 描述（相关：(N)(M)，来源：结论/摘要）`，[推断] 保留。
- **图例**一句：`未标注的演化关系均有摘要或结论级文字依据；[推断] 为合理但缺少明文的推定。`
- **论文附录**：全部登记论文 `(N) 完整英文标题 — 一作 et al., 年份, 出处`，人话标注（核心/相关背景/已排除），每篇附一句话要点（做了什么、为何在图中），有链接给链接。

**出报告前自检**（逐项过，不过就修）：时间线中每个编号都已登记且属本方案？每条边源年份 ≤ 目标年份？每个 [推断] 都来自自审而非漏审？≥1 挑战、每挑战 ≥1 方案、每方案有时间线（哪怕单节点）？附录全且标注齐？全文无登记之外的论文/作者/结论？

## 降级阶梯（检索能力）
1. 会话内可继续检索 → 经 paper-navigator-expert 换角度补足到目标数量。
2. 只有预注入的检索结果 → 就地登记分档；可用 CORE 不足 4 篇时**如实说明覆盖有限**，按现有材料输出缩减版（可能只有 1–2 个挑战甚至纯时间线），并提示补充线索后可重做。
3. 完全没有检索材料 → 明确说明无法在无文献依据下构建脉络图，**不凭记忆编造**。宁可不做，也不输出无依据的图。

## 追问迭代
- 用户追问某方案/某条边（"为什么说 A 改进了 B"）→ 就地展开该处依据（引用摘要/结论原文短引），不重跑全程。
- 纠偏换向 → 按新方向重做；编号接续分配，不推倒已有编号。
- 索要中间过程（完整论文单、分档理由）→ 按需展开该部分，不全量倾倒。

## 依赖：paper-navigator-expert
所有论文检索与精读走 `paper-navigator-expert`（第 1 步种子定位、第 2 步收集文献与结论段精读、降级判定）。本技能不自行搜论文。
