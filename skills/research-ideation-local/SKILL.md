# 研究想法生成（Research Ideation）

从研究目标到排序后的想法，再到一份详细提案。所有论文检索与精读都委托 `paper-navigator`，本技能自身不搜论文。

```
定义目标 → 文献接地(paper-navigator) → 想法树生成(3轴) → 三人格精炼
        → ELO 锦标赛 → 呈现 Top-3 给用户 → 用户选择 → 扩展为提案 → 交接迭代
```

## 何时使用
- 寻找研究方向 / 头脑风暴研究想法
- 评估一个想法是否新颖、是否值得做
- 排序或比较多个研究想法
- 从一个想法生成研究提案

不适用于：检索、搜索、阅读论文 → 一律用 `paper-navigator`。

---

## 呈现纪律（务必遵守 · 面向手机用户 · 生产环境无文件系统）

下面第 1–7 步是**给你（agent）执行的内部规程**，不是念给用户听的脚本。中间产物（挑战-洞见树、想法树、各轮精炼、ELO 明细）在你**自带的思考模式**里推演即可，**既不写文件、不调工具，也不整段输出给用户**。用户在手机上，每次面向用户的输出尽量压在一屏内。

**能力边界**：本技能只生成想法与提案文本——**不执行代码、不跑实验、不读外部代码/文件**（论文检索只经 paper-navigator）。凡涉及实验/代码之处只写成计划、或交后续环节，**绝不亲自执行，也不假称已运行或已得数据**。

**只在这 4 个点向用户输出**，其余全部静默执行：
1. **对准方向**（第 1 步）：先从请求推断目标——**推得出就直接按它做**（半句点明+留改向钩子，不发问）；**推不出才问一句**（给闭合选项，也允许直接说痛点），不猜默认。
2. **文献接地信号**（第 2 步）：**2–3 句**（多少篇+主要空白），不展示树与论文清单。
3. **Top-3 卡片**（第 5 步）：手机版竖排卡片，不用宽表格；开场半句点出广度（如「从十几个方向里挑了这 3 个」），不报精确数字。
4. **提案**（第 6 步）：**默认一屏摘要**，完整版仅用户明确要求时于对话展开。

**用词纪律**：与用户交流**不出现内部术语**（"第 X 步""三人格/批判者""ELO 1276""挑战-洞见树"对用户零价值），一律翻成人话，也不旁白加载技能或执行进度、直接给结果。ELO 只供内部排序，对用户仅给排名与一句推荐理由，**不报分数**。

用户想看中间过程或完整版时随时索取——没有文件，就在对话里按需展开，**不预先全量倾倒**。

## 第 1 步：定义长期研究目标

从一个兼具科学价值与实用价值的目标出发——足够宏大可支撑多篇论文，又足够具体可指导日常决策。

**用终极形态倒推**：问"这个方向的终极形态是什么？如果问题被彻底解决，世界会变成什么样？"再从那个愿景倒推出沿途必须解决的里程碑任务——这些中间任务就是真正重要的问题。

**目标驱动优先**：挑一个重要任务死磕，方法不行就换、太难就略放宽约束——总能产出有用结果；避免"在基准 Y 上刷 0.5%"的想法驱动陷阱。

**承诺前自检（问题选择清单）**：□ 连着重要长期目标 □ 能具体说出现有方法在哪/为何失败 □ 成熟方案检查过关（Level 3/4，见反直觉规则 3）□ 有数据或能造数据 □ 资源与专长内可行 □ 至少有一个可行解法路径。

## 第 2 步：文献接地（经由 paper-navigator）

**调用 `paper-navigator`** 收集 30-50 篇相关论文。不要跳过此步，也不要用通用知识替代——想法必须扎根于真实论文。（**对用户只回 1 句**：几篇+主要空白；挑战-洞见树、四类摘要、论文清单留在内部，不输出。）

### 四种新颖度类型
贡献落在四类之一，看清自己的工作该处在哪：
- **Type 1**：定义里程碑任务的开创性工作（新颖度最高，影响最持久）
- **Type 2**：提出全新流水线或表示范式
- **Type 3**：引入新模块（注意力机制、损失函数、训练策略）
- **Type 4**：用已有模块/技巧做增量改进（最易产出，最难令人记住）

**用新颖度层级找空白**：缺失的里程碑任务（领域还没形式化的重要问题，Type 1 机会）；Type-2 稀少的任务（范式单一、待开拓）；可把某任务成熟的 Type-2 范式迁移到另一任务。最高产的想法常出现在"新颖度空白 × challenge-insight 空白"的交点。

### 构建 challenge-insight 树
对收集的论文，建立**技术挑战 ↔ 应对它的洞见/技术**的多对多映射：
- **抽取挑战**：每篇论文解决什么技术问题？（常在引言第 2-3 段、相关工作、方法动机里）
- **抽取洞见**：它用了什么关键技术或思路？
- **建立连接**：哪些洞见应对哪些挑战？

**它如何驱动想法生成**：
- 挑战对应的洞见很少 → **未解问题**（第 3 步的候选）
- 某洞见尚未被用到某挑战上 → **跨域迁移机会**（第 4 步的候选）
- 挑战对应的洞见很多 → 已被充分研究，除非有根本性新角度否则避开

*示例*：挑战「长上下文显存爆炸」← KV 量化／滑窗稀疏／状态空间模型；挑战「长程依赖丢失」← 稀疏注意力／状态空间模型——"稀疏注意力"一技多用；某洞见尚未试于某挑战即迁移机会。

**执行铁律**：不要在没有真实论文接地时生成想法。树中必须引用真实论文（标题、作者、发现）。

### 论文阅读深度
精读交给 paper-navigator，按目的选深度：①**技术级**（要复现/构建）——读全方法与公式；②**分析级**（多数）——读引言第 2-3 段与方法概览，2-3 句讲清解决什么/为何更好；③**语境级**——读摘要/引言/结论，定位新颖度类型与文献树位置、找一处局限。多数只需 ②③，① 留给要直接构建的。

**每篇记 5 项摘要**（喂给两棵树）：①一句话新颖点；②流水线（步骤1做X/2做Y/3做Z）；③问题与动机（解决什么/现有为何失败/为何更好）；④文献树位置（新颖度类型/建立在什么上/使能什么）；⑤局限与失败场景（什么数据或假设会让它崩）。

## 第 3 步：用想法树生成候选（3 轴展开）

> **此步与第 4 步静默执行**：想法树、逐节点评审、各轮精炼、人格全留在内部，不单独报进度。

以目标为种子根节点，**每层只变化一个轴**，避免"相似但不同"的伪多样性。目标产出 **15-21 个叶子候选**（<10 个多样性不足，锦标赛不可靠）。

- **第 1 层·技术轴**：解决问题的核心技术路径。每个分支必须是**根本不同的范式**（依赖不同原理，而非不同参数）。问"有哪 3 种根本不同的方式解决这个问题？"取 3 个。
- **第 2 层·领域轴**：技术应用的语境/数据域。每个领域引入**实质不同的约束**。问"在哪些语境下这个技术会面临根本不同的挑战？"每节点取 2-3 个。
- **第 3 层·形式轴**：精确的问题设定——输入、输出、约束、评测标准。每节点取 1-2 个。

**示例（种子：跨血脑屏障给药）**：技术轴=纳米颗粒载体／受体介导转胞吞／聚焦超声；领域轴（以纳米颗粒为例）=阿尔茨海默(慢性低剂量)／胶质母细胞瘤(急性高剂量)／儿童癫痫(发育期脑)；形式轴（以胶质瘤为例）=最大化肿瘤富集／最小化全身毒性／影像-治疗一体。每条根→叶路径即一个明确、独立的研究问题。

**逐节点循环：提出 → 评审 → 精炼**——写 2-3 句描述（做什么/为何可能成立/与父节点的区别）；评审三问（是否真不同于兄弟节点 / 是否至少可行 / 描述是否够具体可执行）；据评审去掉模糊措辞、把新颖性说具体。

**剪枝准则**：仅当①明显不可行（需根本拿不到的资源、违反已确立的理论/物理约束）或②与其它分支重复时才剪。**不要剪**"看似不太可能但未被证伪"、超出你当前专长、或挑战常识的想法。

**进锦标赛前核对多样性**：①层间——第 1 层各分支是否真是不同技术（能否一句话向同行说清、且被认作不同路径）；②层内——每个技术下的领域是否带来不同技术挑战；③叶子——不同叶子的评测指标是否会不同。任一不达标则补充或替换分支。

**两种贡献形态**（每个想法选其一）：**聚焦型**——单个新组件 + 干净可检验假设，易验证、归因清晰；**系统型**——组件间紧密因果交互、产生涌现能力，潜力大但须警惕变量混淆。

### 想法候选格式
```
# 研究想法：[精炼标题]
## 核心想法
[一段话：提案内容 + 对应的技术-领域-形式]
## 新颖性论证
[2-3 句：与哪篇/哪类已有工作不同，差异具体在哪——点名所区别的先前工作]
## 可行性
[所需资源/数据、粗略周期、已知风险]
## 验证计划
[具体实验提纲：数据集、基线、指标]
```
（进锦标赛后追加记录：初始 ELO 1500、当前 ELO、胜/平/负。）

## 第 4 步：精炼想法（三人格 × N 轮）

对每条初始想法各开一条精炼轨道**并行**推进；每条轨道跑 N≈3 轮：①评估当前最佳（新颖/可行/影响/对齐）→ ②**三个人格**各据评估出一版精炼 → ③取最佳作下一轮种子。轨道冠军 = 该轨道历轮最佳；所有轨道冠军进第 5 步锦标赛。

| 人格 | 关注 |
|------|------|
| **创新者** | 新颖与创造力——突破性、高风险高回报 |
| **实用者** | 可行性——现实、可清晰执行 |
| **批判者** | 科学价值——推进理解、严谨 |

### 5 种进化策略（括号内为触发条件）
1. **接地强化**（机制缺文献支撑时）：用文献引用夯实
2. **改善内聚**（机制有逻辑漏洞时）：修复
3. **启发与组合**（想法单薄时）：与文献中另一概念组合
4. **简化**（变量过多/假设不清时）：剥离为干净、可检验的假设
5. **文献驱动转向**（评估判定死胡同时）：放弃当前机制，从文献提出新路径

**pivot 硬规则**：若评估判定该路径是死胡同，人格**必须转向**——精炼不局限于打补丁。

### 逻辑内聚原则
- **变量过多** → 用**减法聚焦**：隔离最有希望的那个变量
- **组件脱节** → 用**强相关**：建立显式因果链

### 设计方案的两种模式
设计前从四来源蒸馏知识（按可得性）：①**论文**——搜相似问题的工作，读引言第 2-3 段的成因分析与关键洞见（同一难题跨领域常用不同术语）；要直接构建的读其代码，常揭示论文省略的细节；②**综合**——用自己的话重述、形成"为何难"的判断，区分哪些已有洞见适用于你的设定（原创思考在此）；③**他人**——与资深研究者讨论你的**分析**（不只抛问题）；④**实验**——小实验逐个验证失败成因假设（固定其他变量、只测该因子），确认后再设计完整方案。关键不在收集，而在综合出"为何难、何法可行"的判断。

价值在于理解技术"为何"奏效再创造性组合，而非简单拼接。
- **模式A·跨域迁移**（对应成熟方案检查 Level 3）：剥离领域细节、抽出技术内核 → 广搜其它领域中技术上相似的问题 → 理解其解法**为何**成立 → 适配本领域（数据/模态需改什么、哪些组件可直接迁移、哪些需重设计）→ 在代表性样例上先验证。源领域越远，迁移越显新颖，但适配工作也越多。
- **模式B·问题分解**（对应 Level 4）：拆成独立子问题并理清依赖 → 每个子问题套用模式A → 仍无解则继续分解或放宽约束 → 逐组件增量组合并测试接口兼容。
- **创造性组合**：组合前**枚举所有可能的方法与流水线顺序**，逐一分析权衡（精度/效率/假设/失败模式），据分析而非直觉择优，并对至少一个备选做消融。投入实现前先查这个组合是否被试过——若试过，你的洞见必须针对它失败的原因。*枚举示例*（稀疏视图三维重建）：A 深度+NeRF／B 扩散先验+NeRF／C 深度+扩散+NeRF／D 前馈+精修 → 权衡后选 C，以 A 作消融基线。
- **设计自检**：□ 能解释方案"为何"成立（不只是"做什么"）□ 针对一个具体技术瓶颈（非笼统改进）□ 查过这个组合没被做过 □ 关键假设已用小实验验证 □ 能说出相对最明显备选的优势 □ 资源内可实现。若拆不出子问题或找不到子解，多半是认知差距（多读远域论文）或检索差距（换术语再搜），真正世界级难题罕见。

每条轨道冠军记一份内部**精炼小结**（简化/新增了什么、哪个人格驱动了关键改动、补了哪些风险缓解），供第 5 步卡片提炼"为何靠前"。

## 第 5 步：ELO 锦标赛 → 呈现 Top-3

对所有候选两两比较排序，再把 **Top-3 呈现给用户选择**。

**四个维度**（各 1-10 分）：
- **新颖性**：与已发表工作有多不同？（9-10 全新路径 / 7-8 非显然组合 / 5-6 已知技术用于新设定 / 3-4 增量 / 1-2 复制）
- **可行性**：现有资源内能否实现验证？（9-10 2-3 月内可完成 / 5-6 需大量投入 / 1-2 资源不现实）
- **相关性**：是否解决与目标对齐的重要问题？（9-10 领域 top-3 开放问题 / 5-6 相关但非最紧迫 / 1-2 基本无关）
- **清晰度**：是否定义到可立即上手？（9-10 问题与指标都明确 / 5-6 方向清楚细节待查 / 1-2 不清楚问题是什么）

**ELO 机制**：起始分 1500，K=32。每场两两比较 → 期望分 `E_A = 1/(1+10^((R_B−R_A)/400))` → 更新 `R_A' = R_A + K×(S_A−E_A)`（胜 S=1，平 0.5，负 0）→ 按终分排序。两两比较靠推理给四维打分，无需脚本。候选 15-21 个时约跑 4-5 轮配对（每轮按当前分就近配对、避开已交手过的）。**收敛检查**：每轮后看 Top-3 是否与上轮相同——相同即可提前停；Top-5 仍大幅变动则再加一轮；满 5 轮无论如何停。**平局/接近**：复合分相同记平局（双方按 S=0.5 更新）；4 轮后仍相差 <50 分的两想法视为并列，在 Top-3 中标注为等价选项。

**每场打分卡**：A/B 各维度 1-10 + 一句理由 → 各自复合分 → 定胜者 → 按上式更新双方 ELO。*算例*：均 1500 时胜者→**1516**、负者→**1484**（K=32）。

**呈现 Top-3（手机版·竖排卡片，不用宽表格——8 列表格在手机上会横滚或碎版）**：每个想法一张**竖排卡片**，一屏一张，各含四行：

```
① 分层 KV 量化   ·  推荐度：最高
怎么做：按每层对量化的敏感度分配位宽——敏感层多留位、鲁棒层压缩。
为何靠前：比另两案改动更小、精度损失更低，2–3 月内可验证。
主要风险：探针在分布外文本上可能失准。
```

三张卡片之后附**一句跨方向提示**（三者共同主线，可能提示组合方案；如"共同点是'长上下文里信息不等重要'，①③可组合"），再问一句：**"想把哪个扩展成提案？（1/2/3，或组合）"**

- 卡片给足**选择信息**（怎么做+为何靠前+主要风险）；**「为何靠前」写成比较句**（为何是它、非另两个）而非绝对优点——顺带自查排序；**不倾倒完整精炼版**，选定或索取后展开。
- **四维打分与 ELO 分数保留在你内部**，不进卡片；"推荐度"用"最高/较高/高"这类词，不报数字。
- **收敛/等价**：若两想法 4 轮后仍相差 <50 分，在卡片"推荐度"处标注为并列等价选项。
- **两条硬自查**（贴推荐度前）：①名次与复合分单调一致——「最高」须是复合分最高者，冲突以分数为准；②Top-3 由跨轨道比出，非每条技术轴各取一个（否则退化成技术轴本身、零惊喜）。

## 第 6 步：扩展为研究提案

用户选定后，**默认先给一屏摘要**：问题一句、核心洞见一句、主实验一句、预期结果一句、主要风险一句，末尾问"需要我展开成完整提案吗？"。**只有用户明确要求**，才产出下面的手稿级完整版——它篇幅很长，无文件系统时直接在对话中给出，**切勿默认倾倒**（想看某一段也可只展开那一段）。

完整版按**两阶段**：

**阶段一·先生成领域专属模板**：从研究目标与文献识别领域；以通用章节（摘要/问题/相关工作/方法/评测/结论）为基础，叠加领域专属章节并适配术语（如医学用"研究设计"、社科用"方法论"）。

| 领域 | 通用章节外追加 |
|------|----------------|
| 医学/临床 | 伦理与 IRB、试验设计(分期/分组/终点)、入排标准、统计功效与样本量、安全监测 |
| 社科 | 理论框架、招募策略、量表/访谈设计、编码方案、研究者立场 |
| 化学/材料 | 合成路线与反应条件、表征计划(XRD/SEM/NMR)、安全危害分析、放大考量 |
| 物理 | 数学推导/理论框架、计算设置(DFT 参数/网格)、误差与不确定度分析 |
| 工程 | 设计规格与约束、仿真/FEA、原型制造、测试标准合规、成本效益 |
| 生物 | 模型系统论证、IACUC 伦理、对照设计、生物学重复与统计功效 |
| CS/ML | 算力需求、基线复现计划、消融设计、代码/数据可得性声明 |

**阶段二·填写提案**。六段：①**背景**——精确问题定义(输入/输出/约束/评测)+现有方法何处为何不足+范围边界；②**相关工作**——定位+3-5 篇最相关+差异化(叙事非罗列)；③**方法**——核心洞见+步骤+关键区分点+假设；④**实验计划**——数据集(为何选)/基线(≥3 含 SOTA)/主次指标/消融(对应贡献 2)；⑤**预期结果**——定量目标(给区间、可证伪)+定性预测；⑥**风险与缓解**——技术/资源/评测三类，各配后备方案。

**实验计划要点**：基线 ≥3 含 SOTA，注明官方实现还是复现；主指标只设一个（定成败的数），次指标多角度补充；消融三型——留一/递增/替换，选最能验证"组件必要性"的那型。

**风险三类各举例**：技术——"剪枝破坏跨层依赖"→监控逐层激活+梯度重要性；资源——"7B 全量需 8×A100×72h"→先 1.3B 验证再放大；评测——"MMLU 测不出推理退化"→补 GSM8K/HumanEval 思维链。每个主要风险都写明"若发生怎么办"。

写作遵循：
- 面向领域顶级审稿人写——每个论断有支撑、每个设计有理由、主动回应弱点
- **核心洞见陈述法**：明写"核心洞见是 X，它使 Y 成为可能，因为 Z"。洞见≠方法复述——"剪枝让模型更小"是定义；"不同层注意力头对输入长度敏感，使逐层差异化剪枝率成为可能"才是洞见。
- **三贡献法则**：恰列 3 条（1 条不足、2 条不完整、4+ 不聚焦），按强度排主(方法)/次(分析或机制洞见)/辅(数据集或工具)；每条须**可检验**："提出新方法"(不可) vs "X 在 Z 基准提升 Y%"(可)。
- 避免变量混淆：清楚指出哪个是核心贡献，回答"如何确保观测效应来自你声称的创新而非混杂因素"
- **贡献↔实验对齐**：每条贡献都要有验证它的实验——主(方法)对主指标 vs 基线；次(分析/洞见)对消融或机制可视化；辅(数据/工具)对规模与质量统计。写完双向自检：①每条声称都有证据？②有无实验不服务任何声称（多半可删）？把"方法说的"与"实验测的"锁死。
- **问题陈述避三坑**：太宽（"提升 LLM 效率"→"单卡 A100 把 7B 延迟降 ≥40% 且 MMLU 保 ≥95%"）；无基线（"现有方法慢"→"SpecDec 达 2.3× 但需草稿模型"）；缺约束（"更快推理"→"无辅助模型、≤16GB 显存下"）。
- **各段写作要诀**：摘要——单段密集，按"领域+挑战→现有局限→你的方法→验证→预期影响"流；相关工作——叙事呈现领域演进，构造让你的工作显得"必然下一步"的 gap 论证，附范式对比表（非罗列论文）；方法——每个组件按"目的→机制→为何这样设计克服某具体局限"写，配一个示例；评测——按研究问题组织，每问对应实验设计+预期结果+备选结局。*gap 论证示例*：稀疏注意力降复杂度但牺牲长程精度 → 检索增强补长程却引入延迟 → **本工作**用可学习层级稀疏化，不检索而兼顾两者。*方法段示例*（洞见：各层对量化敏感度不同→逐层差异化）：「敏感度探针」目的量化各层精度贡献／机制小校准集测量化后 KL 散度／为何均匀位宽对敏感层欠保护、对鲁棒层浪费——每个组件都按此回扣核心洞见。
- **形式化适度**：定量领域用数学记号、实验领域用精确协议描述——但形式表达后必跟一句直觉解释。
- **引用格式**：`**1. 标题** (年). _作者_. *会议/期刊*. 被引: N. [链接]`；所有技术论断都标来源 [1][2]。
- **目标校准**：定量目标"雄心但现实"——太保守（"略有提升"）不值得做，太激进（"10× 且零损失"）不可信，恰当如"15-20% 提升"（具体、可达）。定性预测也要给（如"长序列增益更大"），验证后强化"你懂为何奏效"的叙事。

## 第 7 步：验证与迭代

在代表性数据上跑实验、验证关键假设。**失败要分类**：实现性失败（接口/超参/数据问题）→ 修复重试；根本性失败（机制不成立）→ 带着新认知返回第 4 步转向，或返回第 1 步换问题。新观察到的失败案例本身可能就是一个新问题（见反直觉规则 2）。

---

## 反直觉规则
1. **选问题 > 设计方案**：选"做什么"比"怎么做"更重要
2. **追新失败案例，而非增量改进**：把现有方法用到新数据/更难输入，找它崩溃的设定——**新失败案例本身就是可发表贡献**（如 NeRF 静态场景有效，用到形变手术视频即失败，定义了新问题）
3. **若已有成熟方案，就换问题**：成熟方案检查四级——①同任务已有好解→换；②跨域相似技术核已被解→换；③仅 1-2 个远域有解→可做（迁移机会，适合新手）；④无任何领域有解→可做（高风险高回报，适合专家）
4. **技术是创造性组合，不是拼接**：简单 A→B 流水线不算贡献；组合前**枚举所有可能再据分析择优**
5. **生成阶段先量后质**：先大量产候选再评估
6. **可行性不是可选项**：精彩但不可行的想法浪费研究周期
7. **相信锦标赛胜过直觉**：排序常带来惊喜
8. **新锤子机会**：出现突破性工具时，把它用到**你路线图的里程碑任务**上，而非在其原基准上改进它（那是与工具创造者竞争、空间拥挤）。公式：突破工具 + 你的里程碑任务 = 高影响论文
