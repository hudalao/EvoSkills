# 研究想法生成（Research Ideation）
从研究目标到排序后的想法，再到一份详细提案。所有论文检索与精读都委托 `paper-navigator-expert`，本技能自身不搜论文。

```
定义目标 → 文献接地(paper-navigator-expert) → 想法树生成(3轴) → 粗排取Top-5
        → 三人格精炼 → ELO 终排 → 呈现 Top-3 给用户 → 用户选择 → 扩展为提案 → 交接迭代
```

## 何时使用
- 寻找研究方向 / 头脑风暴研究想法
- 评估一个想法是否新颖、是否值得做
- 排序或比较多个研究想法
- 从一个想法生成研究提案

不适用于：只想检索/搜索/阅读论文本身。

## 呈现纪律（务必遵守 · 面向手机用户 · 生产环境无文件系统）
第 1–7 步是**给你（agent）的内部规程**，非念给用户的脚本。中间产物（挑战-洞见树、想法树、各轮精炼、ELO 明细）在**思考模式**里推演即可，**不写文件、不调工具、不整段输出给用户**。用户在手机端，每次对外输出尽量一屏内。

**能力边界**：本技能只生成想法与提案文本——**不执行代码、不跑实验、不读外部代码/文件**（论文检索只经 paper-navigator-expert）。凡涉及实验/代码之处只写成计划、或交后续环节，**绝不亲自执行，也不假称已运行或已得数据**。

**只在这 4 个点向用户输出**，其余全部静默执行：
1. **对准方向**（第 1 步）：从请求推断目标——**推得出直接做**：开头嵌半句点明方向+纠偏尾（如「围绕X（理解偏了随时纠）——」），不成段复述、不玩「方向对再展开」这类假等待；**推不出才问一句**（给闭合选项，也可直接说痛点），不猜默认。
2. **文献接地信号**（第 2 步）：**2–3 句**（多少篇+主要空白），不展示树与论文清单。
3. **Top-3 卡片**（第 5 步）：手机版竖排卡片，不用宽表格；开场半句点出广度（如「从十几个方向里挑了这 3 个」），不报精确数字。
4. **提案**（第 6 步）：**默认一屏摘要**，完整版仅用户明确要求时于对话展开。

**用词纪律**：对用户**不出现内部术语**（"第 X 步""三人格""ELO 1276""挑战-洞见树"零价值），一律翻成人话，不旁白加载/进度、直接给结果。ELO 只供内部排序，对外只给排名+一句理由，**不报分数**。中间过程/完整版用户随时可索取，对话内按需展开，**不预先全量倾倒**。

## 第 1 步：定义长期研究目标
从一个兼具科学价值与实用价值的目标出发——足够宏大可支撑多篇论文，又足够具体可指导日常决策。
**用终极形态倒推**：问"这个方向的终极形态是什么？如果问题被彻底解决，世界会变成什么样？"再从那个愿景倒推出沿途必须解决的里程碑任务——这些中间任务就是真正重要的问题。
**目标驱动优先**：挑一个重要任务死磕，方法不行就换、太难就略放宽约束——总能产出有用结果；避免"在基准 Y 上刷 0.5%"的想法驱动陷阱。
**承诺前自检（问题选择清单）**：□ 连着重要长期目标 □ 能具体说出现有方法在哪/为何失败 □ 成熟方案检查过关（Level 3/4，见反直觉规则 3）□ 有数据或能造数据 □ 资源与专长内可行 □ 至少有一个可行解法路径。

## 第 2 步：文献接地（经由 paper-navigator-expert）
**必须**调用 `SkillLoad(path=references/paper-navigator-expert, skillName=paper-navigator-expert)` Skill 收集 30-50 篇相关论文。不要跳过此步，也不要用通用知识替代——想法必须扎根于真实论文。（**对用户只回 1 句**：几篇+主要空白；挑战-洞见树、四类摘要、论文清单留在内部，不输出。）

### 四种新颖度类型
贡献落在四类之一，看清自己的工作该处在哪：
- **Type 1**：定义里程碑任务的开创性工作（新颖度最高，影响最持久）
- **Type 2**：提出全新流水线或表示范式
- **Type 3**：引入新模块（注意力机制、损失函数、训练策略）
- **Type 4**：用已有模块/技巧做增量改进（最易产出，最难令人记住）
**用新颖度层级找空白**：缺失的里程碑任务（还没形式化的重要问题，Type 1 机会）；Type-2 稀少的任务（范式单一待开拓）；把某任务成熟的 Type-2 范式迁移到另一任务。最高产想法常在"新颖度空白 × challenge-insight 空白"的交点。

### 构建 challenge-insight 树
对收集的论文，建立**技术挑战 ↔ 应对它的洞见/技术**的多对多映射：
- **抽取挑战**：每篇论文解决什么技术问题？（常在引言第 2-3 段、相关工作、方法动机里）
- **抽取洞见**：它用了什么关键技术或思路？
- **建立连接**：哪些洞见应对哪些挑战？

**它如何驱动想法生成**：
- 挑战对应的洞见很少 → **未解问题**（第 3 步的候选）
- 某洞见尚未被用到某挑战上 → **跨域迁移机会**（第 4 步的候选）
- 挑战对应的洞见很多 → 已被充分研究，除非有根本性新角度否则避开

*示例*：挑战「长上下文显存爆炸」← KV 量化／滑窗稀疏／状态空间模型；挑战「长程依赖丢失」← 稀疏注意力／状态空间模型——"稀疏注意力"一技多用；某洞见尚未试于某挑战即迁移机会。

**执行铁律**：不要在没有真实论文接地时生成想法。树中必须引用真实论文（标题、作者、发现），不虚构。

### 论文阅读深度
精读交给 paper-navigator-expert，按目的选深度：①**技术级**（要复现/构建）——读全方法与公式；②**分析级**（多数）——读引言 2-3 段与方法概览，2-3 句讲清解决什么/为何更好；③**语境级**——读摘要/引言/结论，定位新颖度类型与树中位置、找一处局限。多数只需 ②③。

**每篇记 5 项摘要**（喂两棵树）：①一句话新颖点；②流水线（步1做X/2做Y/3做Z）；③问题与动机（解决什么/现有为何败/为何更好）；④文献树位置（类型/建于什么/使能什么）；⑤局限与失败场景（什么数据或假设会让它崩）。

## 第 3 步：用想法树生成候选（3 轴展开）
> **此步与第 4 步静默执行**：想法树、逐节点评审、各轮精炼、人格全留在内部，不单独报进度。

以目标为种子根节点，**每层只变化一个轴**，避免"相似但不同"的伪多样性。目标产出 **15-21 个叶子候选**（<10 个多样性不足，粗排选不出好苗子）。

- **第 1 层·技术轴**：解决问题的核心技术路径。每个分支必须是**根本不同的范式**（依赖不同原理，而非不同参数）。问"有哪 3 种根本不同的方式解决这个问题？"取 3 个。
- **第 2 层·领域轴**：技术应用的语境/数据域。每个领域引入**实质不同的约束**。问"在哪些语境下这个技术会面临根本不同的挑战？"每节点取 2-3 个。
- **第 3 层·形式轴**：精确的问题设定——输入、输出、约束、评测标准。每节点取 1-2 个。

**示例（种子：跨血脑屏障给药）**：技术轴=纳米颗粒载体／受体介导转胞吞／聚焦超声；领域轴（取纳米颗粒）=阿尔茨海默(慢性低剂量)／胶质母瘤(急性高剂量)／儿童癫痫(发育期脑)；形式轴（取胶质瘤）=最大化肿瘤富集／最小化全身毒性／影像-治疗一体。每条根→叶即一个明确独立的研究问题。

**逐节点循环：提出→评审→精炼**——写 2-3 句（做什么/为何可能成立/与父的区别）；评审三问（是否真不同于兄弟 / 是否至少可行 / 是否具体可执行）；据评审去模糊、把新颖性说具体。
**剪枝准则**：仅当①明显不可行（根本拿不到的资源、违反已确立的理论/物理约束）或②与其它分支重复时才剪。**不要剪**"看似不太可能但未证伪"、超出你专长、或挑战常识的想法。
**进粗排前核对多样性**：①层间——第 1 层各分支是否真是不同技术（能否一句话向同行说清、且被认作不同路径）；②层内——每个技术下的领域是否带来不同技术挑战；③叶子——不同叶子的评测指标是否会不同。任一不达标则补充或替换分支。
**两种贡献形态**（每个想法选其一）：**聚焦型**——单个新组件 + 干净可检验假设，易验证、归因清晰；**系统型**——组件间紧密因果交互、产生涌现能力，潜力大但须警惕变量混淆。

### 想法候选格式

```
# 研究想法：[精炼标题]
## 核心想法
[一段话：提案内容 + 对应的技术-领域-形式]
## 新颖性论证
[2-3 句：与哪篇/哪类已有工作不同，差异具体在哪——点名所区别的先前工作]
## 可行性
[所需资源/数据、粗略周期、已知风险]
## 验证计划
[具体实验提纲：数据集、基线、指标]
```

（进入终排的冠军追加记录：初始 ELO 1500、当前 ELO、胜/平/负。）

## 第 4 步：精炼想法（三人格 × N 轮）

先**粗排**：按第 5 步四维给全部叶子打复合分（不跑 ELO），取 **Top-5 左右**进入精炼；入选须**横跨 ≥2 条技术轴**，不足则以最高分异轴叶子替换末位（外卡）。每条入选候选各开一条精炼轨道**并行**推进；每条轨道跑 N≈3 轮：①评估当前最佳（新颖/可行/影响/对齐）→ ②**三个人格**各据评估出一版精炼 → ③取最佳作下一轮种子。轨道冠军 = 该轨道历轮最佳；全部冠军进第 5 步终排。

| 人格 | 关注 |
|------|------|
| **创新者** | 新颖与创造力——突破性、高风险高回报 |
| **实用者** | 可行性——现实、可清晰执行 |
| **批判者** | 科学价值——推进理解、严谨 |

### 5 种进化策略（括号内为触发条件）
1. **接地强化**（机制缺文献支撑时）：用文献引用夯实
2. **改善内聚**（机制有逻辑漏洞时）：修复
3. **启发与组合**（想法单薄时）：与文献中另一概念组合
4. **简化**（变量过多/假设不清时）：剥离为干净、可检验的假设
5. **文献驱动转向**（评估判定死胡同时）：放弃当前机制，从文献提出新路径

**pivot 硬规则**：若评估判定该路径是死胡同，人格**必须转向**——精炼不局限于打补丁。

### 逻辑内聚原则
- **变量过多** → 用**减法聚焦**：隔离最有希望的那个变量
- **组件脱节** → 用**强相关**：建立显式因果链

### 设计方案的两种模式
设计前从四来源蒸馏知识：①**论文**——搜相似问题的工作，读引言 2-3 段成因分析与关键洞见（同一难题跨域常换术语）；要直接构建的读代码，常揭示论文省略的细节；②**综合**——用自己的话重述、判断"为何难"、区分哪些洞见适用你的设定（原创思考在此）；③**他人**——与资深者讨论你的**分析**（不只抛问题）；④**实验**——小实验逐个验证失败成因（固定他变量只测该因子）再设计全案。关键不在收集，而在综合出"为何难、何法可行"的判断。

价值在于理解技术"为何"奏效再创造性组合，而非简单拼接。
- **模式A·跨域迁移**（Level 3）：抽出技术内核 → 广搜其它领域技术上相似的问题 → 理解其解法**为何**成立 → 适配本领域（数据/模态改什么、哪些可直迁、哪些需重设计）→ 代表性样例先验证。源领域越远越显新颖，适配也越多。
- **模式B·问题分解**（Level 4）：拆成独立子问题并理清依赖 → 每个套用模式A → 仍无解则继续分解或放宽约束 → 逐组件增量组合并测接口。
- **创造性组合**：组合前**枚举所有可能的方法与流水线顺序**，逐一分析权衡（精度/效率/假设/失败模式），据分析而非直觉择优，并对至少一个备选做消融。投入实现前先查这个组合是否被试过——若试过，你的洞见必须针对它失败的原因。*枚举示例*（稀疏视图三维重建）：A 深度+NeRF／B 扩散先验+NeRF／C 深度+扩散+NeRF／D 前馈+精修 → 权衡后选 C，以 A 作消融基线。
- **设计自检**：□ 能解释方案"为何"成立（不只是"做什么"）□ 针对一个具体技术瓶颈（非笼统改进）□ 查过这个组合没被做过 □ 关键假设已用小实验验证 □ 能说出相对最明显备选的优势 □ 资源内可实现。若拆不出子问题或找不到子解，多半是认知差距（多读远域论文）或检索差距（换术语再搜），世界级难题罕见。

每条冠军记一份内部**精炼小结**（简化/新增了什么、哪个人格驱动关键改动、补了哪些风险缓解），供第 5 步卡片提炼"为何靠前"。

## 第 5 步：ELO 锦标赛 → 呈现 Top-3
对精炼后的轨道冠军两两比较**终排**，再把 **Top-3 呈现给用户选择**。

**四个维度**（各 1-10 分）：
- **新颖性**：与已发表工作有多不同？（9-10 全新路径 / 7-8 非显然组合 / 5-6 已知技术用于新设定 / 3-4 增量 / 1-2 复制）
- **可行性**：现有资源内能否实现验证？（9-10 2-3 月内可完成 / 5-6 需大量投入 / 1-2 资源不现实）
- **相关性**：是否解决与目标对齐的重要问题？（9-10 领域 top-3 开放问题 / 5-6 相关但非最紧迫 / 1-2 基本无关）
- **清晰度**：是否定义到可立即上手？（9-10 问题与指标都明确 / 5-6 方向清楚细节待查 / 1-2 不清楚问题是什么）

**ELO 机制**：起始分 1500，K=32。每场两两比较 → 期望分 `E_A = 1/(1+10^((R_B−R_A)/400))` → 更新 `R_A' = R_A + K×(S_A−E_A)`（胜 S=1，平 0.5，负 0）→ 按终分排序。两两比较靠推理给四维打分，无需脚本。冠军约 5 条直接全循环（两两各一场）；超过 10 条才跑就近配对（避开已交手过的），Top-3 与上轮相同即停、满 5 轮必停。**平局/接近**：复合分相同记平局（双方按 S=0.5 更新）；终排后仍相差 <50 分的两想法视为并列，在卡片标题行标注并列。

**每场打分卡**：A/B 各维度 1-10 + 一句理由 → 各自复合分 → 定胜者 → 按上式更新双方 ELO。*算例*：均 1500 时胜者→**1516**、负者→**1484**（K=32）。

**呈现 Top-3（手机版·竖排卡片，不用宽表格——8 列表格在手机上会横滚或碎版）**：每个想法一张**竖排卡片**，一屏一张，标题行+三行：

```
① 分层 KV 量化（首推）
怎么做：按每层对量化的敏感度分配位宽——敏感层多留位、鲁棒层压缩。
为何靠前：比另两案改动更小、精度损失更低，2–3 月内可验证。
主要风险：探针在分布外文本上可能失准。
```

三张卡片之后附**一句跨方向提示**（三者共同主线，可能提示组合方案；如"共同点是'长上下文里信息不等重要'，①③可组合"），再问一句：**"想把哪个扩展成提案？（1/2/3 或组合；都不对就说痛点，我重排）"**

- 卡片给足**选择信息**（怎么做+为何靠前+主要风险）；**「为何靠前」写成比较句**（为何是它、非另两个）而非绝对优点——顺带自查排序；**不倾倒完整精炼版**，选定或索取后展开。
- **四维打分与 ELO 分数保留在你内部**，不进卡片、不报数字；排序由 ①②③ 表达，标题行只标「首推」或「并列」——不用"最高/较高/高"（分不清次序）。
- **三条硬自查**（出卡前）：①名次与复合分单调一致——「首推」须是复合分最高者，冲突以分数为准；②Top-3 由跨轨道比出，非每条技术轴各取一个（否则退化成技术轴本身、零惊喜）；③**留痕在先**——已实际写出粗排分表与每场打分卡才可出卡，缺则补跑；「想复杂了」不是省略理由。

## 第 6 步：扩展为研究提案

用户选定后，**默认先给一屏摘要**：问题一句、核心洞见一句、主实验一句、预期结果一句、主要风险一句，末尾问"需要我展开成完整提案吗？"。选**组合**则先一句说清两案怎么耦合。

**只有用户明确要完整版**，才产出手稿级提案，**严格按 `references/proposal-craft.md` 的规程写**（领域专属模板、六段结构、实验/风险要点、写作细则皆在其中）——**先读它、别凭记忆糊**。完整版篇幅很长，对话内**分段**给出、**切勿默认倾倒**（想看某段只展开那段），表格 **≤3 列**、超出改竖排。

## 第 7 步：验证与迭代
在代表性数据上跑实验、验证关键假设。**失败要分类**：实现性失败（接口/超参/数据问题）→ 修复重试；根本性失败（机制不成立）→ 带着新认知返回第 4 步转向，或返回第 1 步换问题。新观察到的失败案例本身可能就是一个新问题（见反直觉规则 2）。

---
## 反直觉规则
1. **选问题 > 设计方案**：选"做什么"比"怎么做"更重要
2. **追新失败案例，而非增量改进**：把现有方法用到新数据/更难输入，找它崩溃的设定——**新失败案例本身就是可发表贡献**（如 NeRF 静态场景有效，用到形变手术视频即失败，定义了新问题）
3. **若已有成熟方案，就换问题**：成熟方案检查四级——①同任务已有好解→换；②跨域相似技术核已被解→换；③仅 1-2 个远域有解→可做（迁移机会，适合新手）；④无任何领域有解→可做（高风险高回报，适合专家）
4. **技术是创造性组合，不是拼接**：简单 A→B 流水线不算贡献；组合前**枚举所有可能再据分析择优**
5. **生成阶段先量后质**：先大量产候选再评估
6. **可行性不是可选项**：精彩但不可行的想法浪费研究周期
7. **相信锦标赛胜过直觉**：排序常带来惊喜
8. **新锤子机会**：出现突破性工具时，把它用到**你路线图的里程碑任务**上，而非在其原基准上改进它（那是与工具创造者竞争、空间拥挤）。公式：突破工具 + 你的里程碑任务 = 高影响论文
